# 2.1.162 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Fixed the Bash permission parser's handling of `${…}` expansions that contain quotes, backticks, `$(…)` or line breaks, which it could end at the wrong `}`; ones it can't parse are now treated as too complex to approve automatically.
- 🔴 Tightened how Bash permission checks follow shell variables: `unset` (and the wrapped `unsetenv` form) of `IFS`, `PS4` or other variables that change how commands run now needs approval, unset variables are tracked as empty, and assignments bash doesn't keep (in subshells, earlier pipeline stages, background `&` commands or `VAR=x command` prefixes) no longer count for later commands.
- 🔴 Made git commands ask for approval when the folder's `.git` is a symlink or `gitdir:` file pointing back inside that folder or outside any `.git` folder, where an untrusted archive could have planted it; worktree and submodule layouts are unaffected, and folders that only look like a bare repository get a clearer explanation.
- 🔴 Stopped auto-approving reads and writes of `.vscode` and `.idea` folders inside Claude's memory folders and a background job's temp folder, of any protected folder (such as `.git`, `.claude` or `node_modules`) inside a session's scratchpad (behind a remote switch that's off by default), and of shell, git and package-manager config files such as `.bashrc`, `.gitconfig`, `.npmrc` or `.mcp.json` inside the scratchpad or a job's temp folder.
- 🔴 Fixed Linux symlink handling for `//wsl$/` and `//wsl.localhost/` paths, which no longer bypass resolution as network shares.
- 🔴 Changed the transcript view to show thinking from every turn, hiding only the newest thinking block while a response streams and for 30 seconds after; before, it showed only the current turn's last thinking block, and none during or just after streaming.
- 🔴 Changed "Prompt is too long" for a conversation of a single exchange to stop trying to compact and say why compaction can't help, telling apart a large conversation from a request made large by the system prompt, tools or attachments, followed by " · /clear to start fresh".
- 🔴 Made Read say when requested PDF pages are outside the document, with its page count and a valid range, instead of a generic conversion error.
- 🔴 Made reading a notebook that isn't valid JSON, or has no `cells` array of cell objects, fail with a clear message (for example that the file may be truncated or still being written).
- 🔴 Fixed reads of notebooks with missing or null top-level metadata, using Python for code cells when the notebook doesn't name a language.
- 🔴 Rewrote the NotebookEdit tool's instructions for Claude to describe cells by `cell_id` and the replace, insert and delete modes, and to require reading the notebook first; the old text described a 0-based `cell_number`.
- 🔴 Stopped offering local OAuth for Anthropic-hosted MCP servers (`microsoft365.mcp.claude.com`, `gmail.mcp.claude.com`, `gcal.mcp.claude.com`, adjustable by a remote setting): signing in now explains to connect them under Settings → Connectors on claude.ai, and for a locally configured entry how to remove it with `claude mcp remove`.
- 🔴 Stopped restarting a plugin's local (stdio) MCP server on every launch after it fails to connect: it's skipped for 15 minutes, or until the plugin changes that server's config, with "Skipping connection (recent failure cached; …)" as its error.
- 🔴 Made version ranges on plugin dependencies that live in the same marketplace repository (relative `source` paths) work: Claude Code picks a matching `name--v*` tag from the marketplace's repository and installs that subfolder, falling back to the current copy when no tag matches.
- 🔴 Made `claude plugin validate` report command, hook, agent, skill and workflow paths in the manifest that don't exist ("Path not found: …").
- 🔴 Made `claude project purge` report and exit with an error when it can't remove a project's entry from `.claude.json` (for example "is your config directory writable?"), instead of reporting success.
- 🔴 Reworked the bundled `/design-sync` skill (needs organization policy `allow_design_sync` and a remote switch that's off by default): separate Storybook and package guides, more converter scripts, and preview cards registered from `@dsCard` markers instead of explicit registration.
- 🔴 Made `/design-sync`'s override diagnostics check every local `.design-sync/lib/*.mjs` entry before loading shape-specific scripts, including overrides that are loaded later or aren't used.
- 🔴 Added automatic discovery of installed sibling token or theme packages in `/design-sync` when `tokensPkg` isn't set, plus a warning when more than three referenced CSS custom properties have neither definitions nor fallback values. The warning points to token-package or theme-provider settings.
- 🔴 Changed `/design-sync`'s placeholder-CSS error to point Storybook users to `[CSS_FROM_STORYBOOK]` in the build log, because the build-time CSS fallback should already have run.
- 🔴 Stopped reading sibling Storybook stories and `storiesPattern` in `/design-sync`'s package mode, so those files no longer supply preview names, arguments or source.
- 🔴 Added saved `shape` and `storybookConfigDir` settings to `/design-sync`, letting later syncs keep the chosen package or Storybook mode and find a central Storybook configuration relative to the config file.
- 🔴 Changed `/design-sync`'s `notes` setting from inline project notes to a Markdown-file path, defaulting to `.design-sync/NOTES.md`; the guides now tell Claude to read and update that file.
- 🔴 Changed `/design-sync`'s upload instructions to write `_ds_needs_recompile` before the bundle's other files and again afterward, requesting another rebuild if the project was opened during the upload.
- 🔴 Removed the memory-save check-in that, behind a remote switch that's off by default, asked after Claude wrote a memory file whether to keep it or undo the save.
- 🔴 Accepted `"gateway"` as a managed `forceLoginMethod`: `/login` then warns that this build doesn't include Cloud gateway support, and `claude auth login` exits telling you to use interactive `/login`. An unknown `forceLoginMethod` value now falls back to unset instead of failing settings validation.
- 🔴 Switched progress bars to block characters (█ and ░) in Ghostty, whose ▰▱ glyphs bleed into neighbouring cells.
- 🔴 Made `/ide open` open the project with the chosen editor's own command (`cursor`, `windsurf` or `devin`, `codium` or `code`) instead of always VS Code's `code`, falling back to `code` if that fails.
- 🔴 Added detection of Devin Desktop, Windsurf's new name: its `TERM_PROGRAM`, remote server folder, app and process names, `devin-desktop` command and settings folder (falling back to Windsurf's); the optional new `/init` flow also reads `.devin/rules/` and `.windsurf/rules/`.
- 🔴 Added "tmux session" and "Channels" rows to `/status`; Channels lists the plugins and servers Claude is listening to, or why they're configured but not active.
- 🔴 Added a "Claude Code and Cowork credit" bar to the usage panel when the account has that one-time credit, with its expiry date.
- 🔴 Stopped showing the feature-of-the-week upsell once you've run the featured command.
- 🔴 Blocked cloud-session features (`--remote`, `--teleport`, `/teleport`, `/ultraplan`, `/ultrareview`, `/autofix-pr` and others behind the `allow_remote_sessions` policy) for organizations with HIPAA or ZDR flags when their policy doesn't explicitly set `allow_remote_sessions`, and, for accounts that should have an organization policy, while it can't be loaded; `--remote` and `--teleport` now say so ("Couldn't verify your organization's policy for cloud sessions…"), and with a provider other than the Anthropic API they say cloud sessions need an Anthropic account.
- 🔴 Made `--remote` stop with an explanation when combined with `--print`, a non-interactive run, `--continue`, `--resume`, `--from-pr`, `--teleport`, `claude ssh`, `claude assistant` or a `cc://` URL (for example "--remote cannot be combined with --print"), and likewise `claude --bg` with `--remote`.
- 🔴 Stopped background-session restarts from passing saved `--remote` options and their values to the worker again, leaving prompt text after `--` unchanged.
- 🔴 Made `--remote` show specific session-creation errors, such as rejected requests or malformed responses, before its generic failure message. Cloud-session creation also logs its stage and reports the failure reason in telemetry.
- 🔴 Forwarded `--permission-mode` (other than bypass) to a new `--remote` cloud session, with a notice when it's ignored for an attach or not forwarded.
- 🔴 Made an attached cloud session stream the reply as it's written, and attached cloud and direct-connect sessions show as busy while the remote turn runs; the remote-session limits on the model picker, history search and mode switching now also apply when attached, though a remote that offers a model catalog gets the real model picker.
- 🔴 Added the remote worker's running background-task count to the `cc://` and SSH session footer, with the count cleared when the connection drops.
- 🔴 Made permission dialogs in attached remote sessions follow your theme instead of always dark, and show Edit, Write and NotebookEdit changes against the remote file's contents with absolute paths.
- 🔴 Fixed failed permission dialogs in attached cloud, `cc://` and SSH sessions leaving tool requests waiting: they now deny the request with `Permission dialog failed: …`.
- 🔴 Added the message "Remote Control is not available inside remote sessions." when Remote Control is asked for in a remote-workspace session, `claude ssh` and `cc://` sessions included.
- 🔴 Made requests to an attached cloud session give up after 75 seconds (10 minutes for side questions) instead of waiting forever, so a model switch can report "No response from the remote session — the switch to … may still have been applied".
- 🔴 Made attached cloud sessions show permission denials ("Permission denied: <tool> — <reason>"), made attached cloud, `cc://` and `claude ssh` sessions show local command output and stop showing the remote's post-turn status summaries, and made `cc://` and `claude ssh` sessions say when a message couldn't be sent ("Not connected to the remote session — your message wasn't sent.").
- 🔴 Restarted an idle background session on the updated Claude Code when you attach to it after an upgrade ("job is restarting on the updated Claude Code; retry attach"), behind a remote switch that's on by default.
- 🔴 Treated `claude ssh` and `cc://` direct-connect sessions as remote workspaces like `--remote`: they skip local MCP server configs and warn that servers from `--mcp-config` or agent frontmatter are ignored.
- 🔴 Showed the IDE connection indicator in the footer in fullscreen mode too.
- 🔴 Kept Claude's latest SendUserMessage and SendUserFile messages visible as their own rows when a turn's tool calls are collapsed.
- 🔴 Made cloud-session requests stop with "OAuth refresh token is no longer valid; run /login to re-authenticate" once the saved refresh token has been rejected.
- 🟡 (2.1.314) Changed the `/design-sync` upload approval prompts to read "To project", "From folder" and "Upload N files", with plainer reasons.
- 🟡 (2.1.121) Fixed attached cloud and `cc://` permission dialogs dropping saved permission-rule updates, so the chosen rules and tool-call ID reach the remote worker.
- 🟡 (2.1.295) Stopped a resumed session from adding SessionStart hook context again when the same text is already in the conversation. When earlier SessionStart context exists but the new hook batch has none that differs, the filter also drops the batch's other messages, including fresh hook errors.
- 🟢 Added `waitingFor` to `claude agents --json` for waiting sessions, saying what each is blocked on.
- 🟢 Made `--tools` that lists Grep or Glob provide the dedicated search tools on native builds, which otherwise replace them with embedded `find` and `grep` in Bash; naming them in `--allowedTools` does the same.
- 🟢 Made `/effort` say " (saved as your default for new sessions)" when the chosen level is saved.

- 🟢 Fixed replies sent from the agents view being lost when the session's connection is gone: they're queued ("Reply queued — will be sent when this session restarts"), and a background session that fails to restart keeps its pending prompt too.
- 🟢 Fixed opening a running background session from `claude agents` stalling about five seconds: the background service now answers at once that the session is already running.
- 🟢 Made startup quieter: warnings come first, and session info (debug mode, model source, channels, tmux) and announcements share a single line, with "+N more" pointing to `/status`.
- 🟢 Rewrote startup warnings to be shorter, each ending with its fix (for example "Installed via npm (deprecated) · run claude install to switch to the native version", "Prompt caching off (…), requests will be slower and cost more · unset it to re-enable", and deprecated models as "X now runs as Y · /model to change").
- 🟢 Pinned the deep-link and pre-filled prompt warning below the input ("Prompt from an external link" or "Pre-filled prompt", with its length and a request to scroll through it above 1,000 characters, or "review before pressing Enter" otherwise) until you send or clear the prompt, instead of a one-off message.
- 🟢 Changed failed turns to show one compact warning line instead of a multi-line red error block.
