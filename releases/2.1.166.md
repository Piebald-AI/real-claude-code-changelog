# 2.1.166 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Added `--cloud` for starting a cloud session (`claude --cloud "<task>"`) or attaching to one by session ID or claude.ai/code URL. `--remote` still works as a deprecated alias, and the error messages, the `--bg` hint and `/session` now name `--cloud`.
- 🔴 Made attaching to a cloud session with `claude --cloud <session-id>` let you leave it with ← on an empty prompt (the footer offers "← for agents"), and open the `claude agents` view once you've left.
- 🔴 Made a terminal attached to a cloud session switch back any permission mode change the session refuses, with the "Remote session couldn't switch to … mode" notice (before, only Shift+Tab did that, and other changes got an error message), and show a mode change made elsewhere in the session.
- 🔴 Made a terminal attached to a cloud session reconnect after the computer wakes from sleep (it watches for the clock jumping more than 10 seconds), and reconnect when you send a message, answer a prompt or interrupt after it had given up reconnecting; a message it already shows is no longer added a second time.
- 🔴 Stopped a terminal attached to a cloud session from showing the user messages that session generates itself (marked synthetic), apart from channel messages.
- 🔴 Added the choice a cloud session offers after a flagged message to the terminal attached to it; it closes when it's answered elsewhere or the turn ends.
- 🔴 Reworded the notices shown when safety measures flag a message: they name the topic when it's known (cybersecurity or biology), and end with "Send feedback with /feedback or learn more:" and a support link. The model-switch notice in the conversation is now bold with a tip that `/config` controls switching, and the `switchModelsOnFlag` setting's description now says the session pauses when switching is off.
- 🔴 Stopped automatic model switches after a flagged message when `switchModelsOnFlag` is off and the session can't show the choice (print mode, for example). After you decline a switch, later flagged messages in the same turn no longer ask or switch, and in the SDK a new user message cancels a choice that's still waiting for an answer.
- 🔴 Changed the fullscreen renderer offer from a welcome-screen notice shown up to three times into a one-time "Try the new fullscreen renderer?" dialog: "Yes, try it" saves `tui: "fullscreen"` and restarts in fullscreen, "Not now" dismisses it for good, and neither the dialog nor the reworded `/tui fullscreen` tip appears once `tui` is set. Both stay behind a remote switch that's off by default; `CLAUDE_CODE_FORCE_FULLSCREEN_UPSELL` still forces the dialog, except in background sessions, which never show it.
- 🔴 Added a text version of `/mcp` for Remote Control: with no arguments it counts servers that are connected, connecting, not connected and disabled, and `/mcp reconnect|enable|disable [<server>|all]` acts on the running terminal session. Reconnecting from Remote Control now refuses the IDE connection and servers that are disabled, already reconnecting or pending approval, saying why.
- 🔴 Fixed terminal `/mcp reconnect`, `/mcp enable` and `/mcp disable` commands losing repeated spaces or tabs inside a server name.
- 🔴 Made `/mcp` show a server as connecting while it reconnects and merge repeated reconnects of the same server. `/mcp enable <server>` or `/mcp disable <server>` on a server already in that state now says so instead of switching it the other way, and servers pending approval are skipped by `all` and reported as pending approval when named.
- 🔴 Added checks for newer tokens and client IDs before a failed MCP OAuth refresh clears stored credentials. Sign-in now clears the stored client registration on `invalid_client` or `unauthorized_client` (previously only `invalid_client` saying "Client not found"); refresh now handles both codes too, first using another process's fresh tokens or leaving its newer registration alone.
- 🔴 Kept an MCP server's saved OAuth discovery information and pending requests for extra permissions when clearing its client registration and tokens, instead of deleting that information too.
- 🔴 Marked claude.ai connectors whose tool listing is refused with HTTP 401 or 403 as needing authentication, instead of showing them connected with no tools.
- 🔴 Made subagents on Bedrock keep the main model's `jp.`, `au.` or `us-gov.` cross-region inference prefix, as they already did for `us.`, `eu.`, `apac.` and `global.`.
- 🔴 Extended the check that asks before Git commands run near bare-repository indicators to every parent folder up to the filesystem root; it used to stop at the folder the session started in.
- 🔴 Made Grep reject a pattern, path, glob or file type containing a null byte with a message telling Claude to remove it.
- 🔴 Required the agent and team names the Agent tool and TeamCreate accept (`name`, `team_name`) to start with a letter or digit and use only letters, digits, `_` and `-`, up to 64 characters.
- 🔴 Made the `REPL` tool (on with `CLAUDE_CODE_REPL`, or a remote switch that's off by default) warn when tool calls are still pending as a script ends, naming them, saying their results are discarded and suggesting `await`.
- 🔴 Made a dynamic workflow's `agent()` call return `null` when its subagent ends on an API error after retries, logging "[<label>] failed: <error>", instead of handing back the error text as the agent's answer; the Workflow tool's description now says so.
- 🔴 Changed how the Bash permission checker follows shell variables inside a command: a value built partly from other expansions is kept instead of being treated as unknown, appending to an unset variable leaves it unset, and assigning such a partly known value again no longer marks the variable unknown.
- 🔴 Added `CLAUDE_CODE_ENABLE_DESIGN_SYNC` to turn on `/design-sync` without its remote switch in first-party API sessions; the organization policy that allows design sync still applies. A settings file's `env` can set it without it being treated as a risky variable, so it isn't listed when you're asked to trust a folder or approve managed settings.
- 🔴 Made `/design-sync` look for Storybook configurations in monorepo subpackages instead of assuming they're at the repository root; design sync still needs its organization policy and either its remote switch or the first-party environment opt-in.
- 🔴 Moved Design Sync's converter scripts and dependency installation into an isolated `.ds-sync/` folder so they don't collide with the repository's own files or package manager.
- 🔴 Expanded Design Sync's build troubleshooting with `[BUILD_OOM]`, `[SCHEDULER_MISSING]` and `[PNPM_SELF_PROVISION]`.
- 🔴 Added `DS_CHROMIUM_PATH` to Design Sync's Storybook probe and validator so they can use a system Chromium instead of installing one.
- 🔴 Added `[FONT_MISSING]` warnings when Design Sync's Storybook output refers to a font family it can't find in an included `@font-face` and doesn't recognize as a system font.
- 🔴 Made Design Sync's Storybook route copy fonts to `fonts/` and rewrite their CSS links to that folder, as the package route already did.
- 🔴 Added `extraFonts` support to Design Sync's Storybook builds, so fonts normally supplied by a host page can be included from font files or `@font-face` stylesheets, as the package route already allowed.
- 🔴 Made Design Sync's Storybook route upload `_ds_needs_recompile` before other files, as the package route already did.
- 🔴 Stopped Design Sync's generated React vendor scripts from replacing a host page's existing `React` and `ReactDOM`; Storybook's ReactDOM bundle now imports the page's React.
- 🔴 Redirected `react/compiler-runtime` imports through Design Sync's React shim.
- 🔴 Supplied no-op ReactDOM resource-hint methods in Design Sync bundles when the host's ReactDOM doesn't provide them.
- 🔴 Made Design Sync bundles throw `[SCHEDULER_MISSING]` when a design system's compiled code imports `scheduler` directly.
- 🔴 Changed Design Sync's provider detection to keep only the outermost matching exported component and at most one immediately nested component with a provider-like name, instead of copying the whole matching chain.
- 🔴 Replaced copied object-valued Design Sync provider props with `$hint` summaries of up to five top-level keys. Generated wrappers leave placeholders for the user to fill, and the mount check passes hinted props as `undefined`.
- 🔴 Stopped copying `children` into detected Design Sync provider props.
- 🔴 Stopped resolving `$ref` provider-prop values to design-system exports in Design Sync's generated wrappers.
- 🔴 Matched Design Sync's Storybook stories to exported components through explicit title-map entries first, then component names in import paths, then title segments.
- 🔴 Made Design Sync probe the first Storybook story that matches an exported component for provider detection, instead of taking the first story even when it doesn't match a component.
- 🔴 Added up to three exported story initializers as source examples in each generated Design Sync component's `.prompt.md`, with `[EXAMPLES]` reporting source paths that couldn't be found.
- 🔴 Removed video files from Design Sync's Storybook output and made its file-type filtering ignore extension case.
- 🔴 Removed Storybook assets over 5 MiB from Design Sync uploads unless they're fonts, scripts, CSS, JSON or HTML; `[SB_DROPPED]` names files removed for size.
- 🔴 Made both Design Sync build routes create `_ds_bundle.css` even when styles are generated at runtime, so generated stylesheet links don't point at a missing file. Package validation accepts that marked file as `[CSS_RUNTIME]` instead of rejecting it as a placeholder.
- 🔴 Made Design Sync's Storybook validation accept compound component namespaces and choose a callable export for its mount check, instead of trying to mount a namespace object.
- 🔴 Changed Design Sync's bundle-style check to inspect the deepest rendered element and treat `-apple-system` and `system-ui` as default fonts rather than evidence that styling arrived.
- 🔴 Made Design Sync's Storybook loading checks ignore root children that are only style, script, link, metadata or template elements, so they wait for rendered content.
- 🔴 Added a Design Sync Storybook preview-style check that reports browser-default fonts and fails when more than half the checked stories use them.
- 🔴 Added `DS_VALIDATE_CAP_SECONDS` (600 seconds by default) to stop starting more Design Sync Storybook checks once time is up and report `[VALIDATE_PARTIAL]`, `iframeChecked` and `iframeTotal`; each story navigation has a 15-second timeout.
- 🔴 Made Design Sync stop waiting for Storybook argument-type extraction after 30 seconds instead of letting that metadata probe wait indefinitely.
- 🔴 Made Design Sync's preview server answer `/` with HTML so browser-based checks can establish a same-origin page before mounting components.
- 🔴 Made Design Sync's Storybook builder copy an existing `--storybook-static` directory, or `./storybook-static`, into `_sb/` when its preview HTML is missing.
- 🔴 Made both Design Sync builders resolve relative `--node-modules` paths before use, and made Storybook resolve `--pkg-dir` before discovering types.
- 🔴 Added `dist/` to Design Sync's fallback search for TypeScript declarations when it contains `.d.ts` files.
- 🔴 Made both Design Sync build routes write `_ds_needs_recompile` with `by: "design-sync-cli"`, so the upload identifies the converter as its source without requiring a manually created empty marker.
- 🔴 Updated Design Sync's generated README to tell consumers to mount components in a dedicated child node rather than the host page's own React root.
- 🔴 Made Design Sync's guides build a package's workspace dependencies before building Storybook.
- 🔴 Made Design Sync's guides point `--node-modules` at the design-system package rather than the repository root.
- 🔴 Made Design Sync's guides read previous configuration and notes before starting, and save user corrections immediately in `design-sync.config.json` or `.design-sync/NOTES.md`; the Storybook route now follows that workflow too.
- 🔴 Added to the `/verify` skill that a file path only counts as evidence when the reader can open it, so on remote surfaces with the `SendUserFile` tool it sends the screenshots and recordings.
- 🔴 Updated the `/fewer-permission-prompts` skill's list of commands that never prompt: `find`, `printf` and `test` moved from "any arguments" to "safe flags only", with the flags that still prompt, and `getconf` and `info` were dropped.
- 🔴 Treated Bun's "The socket connection was closed unexpectedly" error as a dropped connection, so API requests and streams that hit it are retried like other connection resets.
- 🔴 Made a background session waiting on the choice after a flagged message show as blocked in `claude agents`, needing "choose: retry on fallback model or edit prompt".
- 🔴 Made the prompt footer's pull-request badge refresh when the pull request's URL changes while its number stays the same.
- 🔴 Made the footer of a session with in-process teammates show "← again for agents" after a first ← on an empty prompt; that layout never showed the hint before.
- 🔴 Added remote switches, off by default, that let Write and Edit change a file that wasn't read first. Write gains read-check telemetry with `wouldHaveResult`, `isPartialView`, `isFilePathAbsolute` and `guardSkipped`, while Edit's existing event gains `guardSkipped`.
- 🟢 Added the `fallbackModel` setting: up to three fallback models (names or aliases, with `default` meaning the default model) tried in order when the main model is overloaded or unavailable. Duplicates and models outside `availableModels` are skipped, `--fallback-model` takes precedence, a higher-priority settings file's list replaces a lower one's, and both now apply to interactive sessions, not just print mode.
- 🟢 Added wildcard tool names to deny and ask rules (`"*"` matches every tool). Allow rules with a wildcard tool name other than `mcp__<server>__*` are skipped with a warning, from settings files and from `--allowedTools`, and deny and ask rules naming no known tool now warn at startup.
- 🟢 Changed messages from other Claude sessions to arrive as "Another Claude session sent a message", with a warning that they carry none of the user's authority and that relaying a peer's denied action is permission laundering; auto mode's classifier gained a rule that such messages never count as user intent and that blocks actions a peer was denied or says it can't do itself.
- 🟢 Made a session with thinking turned off (`MAX_THINKING_TOKENS=0`, `--thinking disabled` or the per-model toggle) tell the Claude API so explicitly, so models that think by default stop thinking; other providers and `CLAUDE_CODE_DISABLE_THINKING` are unchanged.
- 🟢 Made a turn with a fallback model set retry on it when the API returns an error that can't be retried ("Switched to … because … returned an error that could not be retried"). The existing fallback for model-specific 403/404 errors stays unchanged; the new retry still excludes other authentication and permission errors, rate limits, oversized requests, billing errors, too-long prompts, low credit, disabled organizations, fast-mode refusals and connection failures.
- 🟢 Made `claude update` on native installs print "Updating to <version>..." once it knows the version it's installing.
- 🟢 Made a web address typed into the `claude agents` search match the sessions whose prompt contains it.
- 🟢 Fixed a recurring "image could not be processed" error: after the API rejects an image, Claude Code now strips it from the message that actually holds it, including images attached directly to a message, instead of stopping at the nearest meta message.
- 🟢 Fixed cloud sessions getting stuck at startup when worker registration hit a brief backend problem: it now tries 10 times instead of 3 and stops early on a 400, 413 or 422.
- 🟢 Fixed flickering in JetBrains IDE terminals by turning on synchronized output there.
- 🟢 Fixed Shift with a non-ASCII letter (Shift+ä giving Ä) and other non-ASCII keys being dropped in terminals using the Kitty keyboard protocol.
- 🟢 Fixed PowerShell command validation (the PowerShell tool) waiting far past its time limit when the parser's process doesn't exit: each attempt now gives up after its timeout plus up to 10 seconds.
- 🟢 Fixed background-session hosts (`claude --bg-pty-host`) staying alive and busy after their daemon died while connected: the host now pings the background service's connections every 60 seconds (`CLAUDE_PTY_HEARTBEAT_MS`) and drops one that misses three replies.
- 🟢 Fixed voice mode needing `/login` to clear a stale availability check after you turned it on with `/voice`: the check now reruns when the voice setting changes as well as after sign-in.
- 🟢 Fixed an invalid entry in a managed settings file making the whole file fail to load: other policies now stay in force and the bad field is dropped with a warning, bad entries in the MCP server lists are dropped one by one, an invalid `allowedMcpServers` enforces an empty allowlist, an invalid `allowManagedMcpServersOnly` counts as on and an invalid `forceLoginOrgUUID` lets no organization sign in. Print and SDK runs now print these problems to stderr.
- 🟢 Fixed managed `allowedMcpServers` and `deniedMcpServers` entries not matching servers when either side uses `${VAR}` references; commands and URLs are compared after expansion.
- 🟢 Fixed resuming a background session that had moved into a Git worktree failing with "No conversation found": resume by session ID now also looks in the project's other worktrees.
- 🟢 Fixed thinking appearing twice in the transcript view (Ctrl+O) while it streamed: the view no longer adds a separate live thinking block, and thinking shows in place.
- 🟢 Fixed `/doctor` showing a failed "Not inside a remote session" check inside a remote session: its Remote Control section now just says Remote Control is unavailable there and to use it from the local session.
- 🟢 Fixed the cursor sticking at the end of the first line when a multiline prompt wraps in the `claude agents` dispatch and reply inputs.
- 🟢 Fixed blank lines between background agent rows in the task list on terminals without Unicode support, by sizing the status column from the symbols actually shown.
