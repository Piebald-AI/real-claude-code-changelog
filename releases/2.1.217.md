# 2.1.217 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Fixed `printf` commands whose format stacks several length modifiers (such as `%hhhd` or `%lLd`) being auto-approved without the argument checks other numeric formats get; arguments that aren't plain numbers (including ones holding `$(` or backticks) now make such a command ask first.
- 🔴 Updated the background sessions list (`claude agents`): Home/End/PageUp/PageDown move through the list, key hints mention `ctrl+x` to stop or delete, deleting a pinned session also unpins it, and screen-reader labels identify pinned rows and folded finished sessions. In the simple view (`CLAUDE_CODE_FLEETVIEW_SIMPLE` or a remote switch, off by default), selected rows have a pointer, stopped and failed sessions have distinct icons, unnamed rows use "untitled session" or "session you came from", renaming warns about a duplicate name, working and idle counts are separate, folded finished rows name the failed count, an empty list names the logged-out state and `l` starts login, and pressing `q` twice quits; screen-reader mode also stops shortening pending-question and status-detail text. Renaming also gets more room by dropping the duplicate inline save/cancel hint; those keys stay in the footer.
- 🔴 Changed unpinning a background session to also clear its saved manual position in the sessions list.
- 🔴 Added dismissing a page from the footer's row of Artifact page links: select it and press `x`, Backspace or Delete (before, `x` did nothing there). The row only appears with the Artifact feature, which is behind a remote switch that's off by default.
- 🔴 Changed the "Recalled" and "Remembered" lines for memories to start each memory's title with a lower-case letter so it reads as part of the line, except when the title's first word has a capital after its first letter (such as "API" or "iOS"); the agent step of a collapsed tool summary now keeps such words' capitals too.
- 🔴 Added cleanup of empty claude.ai sessions left behind by Remote Control: about 15 seconds after connecting, Claude Code archives sessions it created earlier that were never used and whose process has exited (on by default through a remote switch; skipped when only essential traffic is allowed).
- 🔴 Added a warning when `claude --teleport` brings a Remote Control session into the terminal, saying that new work in this local copy won't show up in the Claude app and that running `/remote-control` in it lets you continue on your phone.
- 🔴 Changed `/import --yes` on surfaces without the picker to require the digest shown with the preview (`/import --yes=<digest>`) and to refuse when the config on disk changed since then; it now works across separate `claude -p` runs.
- 🔴 Added `CLAUDE_CODE_DISABLE_EXPLORE_INHERIT_CAP`, which makes the built-in Explore agent always use your main model instead of being capped at Opus on the Anthropic API.
- 🔴 Added `CLAUDE_CODE_AMBER_ASTROLABE` (or a remote switch, off by default), which gives any model the system-prompt section telling Claude it's working autonomously and shouldn't stop to ask before reversible steps.
- 🔴 Added three system-prompt sections, each behind its own variable or a remote switch, all off by default: `CLAUDE_CODE_BISON_CAIRN` adds a long "Delivering work" section (deliver the full scope under stated assumptions, ask blocking questions only when going on would be unsafe), `CLAUDE_CODE_LARCH_CISTERN` a "Corrections" section (correct only errors that matter, without apologies), and `CLAUDE_CODE_ALDER_WICKET` a short "Delivering work" section (keep to the scope asked).
- 🔴 Added a usage-limit grace window for subagents on the Anthropic API when extra usage is turned off: once a response reports grace-zone usage, a running subagent is told to wrap up and not start subagents or long work, and the rate-limit status carries `rateLimitGraceActive` for SDK hosts (behind remote switches that are off by default).
- 🔴 Added a note to the usage-credits purchase screens saying how many months the credits stay valid, with the confirm screen labelling the line "Usage credits (valid for N mos)" (behind a remote switch that's off by default).
- 🔴 Added a viewer for the memories recalled during a session, opened from a "N memories recalled" footer item, where `g` marks a memory good and `b` marks it bad and deletes its file (behind a remote switch that's off by default).
- 🔴 Added the bundled `/explain-usage` skill for Cowork cloud sessions, which charts where the session's tokens went and explains it in plain words.
- 🔴 Changed `/skill-doctor` (available with `CLAUDE_CODE_LANTERN_PRISM` or a remote switch) to list plugin skills under their plugin-prefixed names and to warn about plugin skills that were loaded but never used, pointing to `/plugin` to disable the plugin.
- 🔴 Truncated MCP text now avoids cutting a UTF-16 surrogate pair in half, and omits a text block when trimming leaves it empty.
- 🟡 (2.1.218) Fixed the pull-request event (`code_change_published`) waiting until the PR link was saved to the transcript, so a session that exited right away could lose it; the event is now sent first.
- 🟢 Added emoji shortcode autocomplete to the prompt input: a complete `:name:` turns into the emoji and a partial one lists up to 20 suggestions; turn it off with the `emojiCompletionEnabled` setting.
- 🟢 Added a pinned warning when transcript writes fail (for example a full disk or a read-only filesystem), and one when transcript saving is off because `CLAUDE_CODE_SKIP_PROMPT_HISTORY` is set or a `CLAUDE_CODE_CHILD_SESSION` marker was inherited, saying how to get saving back.
- 🟢 Fixed truncated MCP tool output keeping the full untruncated text in memory: text shortened by Claude Code's truncation helpers is now copied into a new string instead of pointing into the original.
- 🟢 Fixed worktree isolation for agents and sessions checking only the spelled path, so a working directory or file reached through a symlink could land in the shared checkout; paths are now resolved first, and network-shaped paths (such as `/net/` automounts) and spellings that can't be resolved are refused with their own messages. Shared-checkout checks now ignore letter case even on Linux, while worktree exceptions still require matching case in the resolved paths; a rejected case-only worktree mismatch names the spelling to use.
- 🟢 Fixed auto-compact never triggering for Claude Opus 4.8 on Bedrock, which now gets the default auto-compact window when its context window is under 1M, and fixed Bedrock's "Input is too long for requested model" error not being handled as a prompt that's too long.
- 🟢 Fixed Claude Desktop sessions ignoring proxy, client-certificate, CA-certificate, TLS-verification and OAuth-scope variables from your user and managed settings; only project and local settings are still kept from changing them.
- 🟢 Fixed screen-reader mode's startup announcement being cut off by the first render (rendering now waits up to 3 seconds or until a key is pressed, adjustable with `CLAUDE_AX_STARTUP_QUIET_MS`), and the thinking row re-rendering to update its elapsed time and token count.
- 🟢 Fixed managed OTLP settings being bypassed by per-signal variables: a generic managed endpoint, header, client key or client certificate now removes lower-trust per-signal values for that same setting across traces, metrics, logs and profiles. Managed headers, client keys, client certificates and `otelHeadersHelper` also block lower-trust endpoint overrides for the signals they cover.
- 🟢 Fixed `--resume`, `--continue` and `/resume` failing with a TypeError on a transcript with a malformed attachment entry; such entries are now dropped.
- 🟢 Fixed Remote Control viewers that connect after a permission prompt or dialog appeared not seeing it; pending prompts are now sent when a viewer connects.
- 🟢 Fixed background shells sometimes becoming impossible to stop after the session is sent to the background or exits on a busy machine: the shell's process start time is now looked up a second time when the first lookup fails.
- 🟢 Fixed `paths` frontmatter with many brace groups in `CLAUDE.md` or `SKILL.md` files stalling or running out of memory at startup: expansion now stops at 1,000 results or 4 MB and uses the pattern unexpanded, with a warning.
- 🟢 Fixed the transcript preview shown while attaching to a starting background session sitting flush against the input area; it now leaves a blank line like the live layout.
- 🟢 Made footer PR badge links clickable even when hyperlink support can't be detected; `FORCE_HYPERLINK=0` turns this off.
- 🟢 Changed the login-expiry warning to start 3 days before expiry instead of 5.
- 🟢 Limited the frontend-design plugin tip to 3 showings in total.
- 🟢 Added a limit of 20 subagents running at once (`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` changes it); further launches are refused with a message telling Claude not to retry. Ultracode sessions at xhigh effort aren't limited.
- 🟢 Changed subagents and coordinator-mode workers to no longer start nested subagents by default (the limit was 5 levels); `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` or a remote setting allows more.
- 🟢 Fixed `--max-budget-usd` not limiting subagents: once spending reaches the cap, new agents are refused and print mode stops running background agents with a "Budget limit reached" message; subagents now get the budget and its reminders too.

<summary>10 more for administrators and for authors of plugins, hooks, MCP servers and SDK hosts</summary>

- 🔴 Changed how Claude Code gets skills from an MCP server (behind a remote switch, off by default): it now uses paged `skills/list` requests instead of reading `skill://index.json`, and the content-address field is `uri` rather than `url`. Servers still need to advertise `io.modelcontextprotocol/skills`; the reader takes up to 100 valid skills over at most 20 pages and skips names, addresses or digests longer than 4,096 characters.
- 🔴 Limited the skill-name part of MCP skill cache directory names to 64 characters, keeping the server prefix and server/URI hash (behind the same default-off remote switch as MCP skills).
- 🔴 Made MCP tool calls inside REPL scripts (`CLAUDE_CODE_REPL`) throw on failure instead of returning `{error}`, with the tool error in `e.message` and, when it's a JSON object or array, the parsed body in `e.detail`; a declined URL elicitation throws with the URL it needed (remote switch, on by default). Failed MCP promises returned without an explicit `await`, directly or as top-level object fields, now produce values marked `mcpToolError: true`, with `toolName` when available and parsed `detail` when available for object fields.
- 🔴 Added the org policy `allow_plugin_skill_search` for the claude.ai plugin and skill search tools, always off for HIPAA organizations; when it denies or can't be checked, the tools return the policy's reason or "Plugin and skill search is unavailable right now". The tools can now also turn on in Claude Desktop and local-agent sessions on the Anthropic API, through a remote switch that's off by default.
- 🔴 Added `--apply-target user|project` to `/auto-mode-setup --apply-file`: proposals now record their scope answer, and applying refuses one whose scope doesn't match the target (user for `scope=all`, project for `scope=project`); entries still go to the user settings file. `/auto-mode-setup` is behind a remote setting that's off by default.
- 🔴 Added server-launched workflows for cloud sessions: a `workflow_launch` event points to a workflow bundle in the session's file store, which is checked against its size and SHA-256 and run once per session through a hidden `/workflow-launch-exec` command; such events are accepted only from the server's event stream, not from stdin. When `CLAUDE_CODE_REMOTE_SESSION_ORIGIN=review`, these workflows bypass the organization's `allow_workflows` policy, but managed `disableWorkflows` and `CLAUDE_CODE_DISABLE_WORKFLOWS` still stop them.
- 🔴 Fixed refreshing one MCP server's tools and commands affecting another server's: tools are now matched by the server they came from, and the server's `server:`-prefixed commands (such as skills it serves) are replaced along with its `mcp__` ones.
- 🔴 Renamed skills loaded from memory stores from `memStore::<name>` to `memories::<name>`, and reloaded them after each sync of the stores instead of only at startup.
- 🔴 Changed memory recall from the auto-memory folder to skip hidden files and folders and the top-level `logs`, `sessions` and `proposals` folders, and to recognise the `team` folder in any letter case.
- 🔴 Added `CLAUDE_CODE_TRANSCRIPT_LOCAL_GC` (or a remote switch, off by default) for cloud sessions resumed through `--sdk-url`: it rewrites the transcript without entries the summary replaced after compaction and initially after another 20 MB has been written. Files under 5 MB are left alone; when a rewrite frees less than 10%, the next growth-triggered check waits twice as many bytes, up to 160 MB.
