- Feedback and usage
  - 🔴 Changed `/context`'s MCP attachment estimates to use the current session and permission context when deciding which server instructions apply.

  - 🟢 Changed `/stats` to give the terminal time to respond while it reads and counts entries in long session logs.
  - 🟢 Fixed Claude Code using an expired rate-limit rejection to suggest waiting after the reset time has already passed.
  - 🟢 Changed the terminal's rate-limit options to appear only on an actual API error rather than on matching text in a normal reply.
- Terminal input and dialogs
  - 🔴 Routed the composer’s history search shortcut to the history picker in interactive fullscreen sessions.
  - 🔴 Changed Ctrl+R prompt history search to skip nonmatching and duplicate entries during the scan, including entries whose collapsed pasted text doesn't match.
  - 🔴 Changed the prompt-history picker to reuse the previous matches as you extend the query, including matches inside collapsed pasted text.
  - 🔴 Sped up word navigation and editing in long terminal inputs by reusing wrapped text measurements and checking nearby text before breaking the whole input into words or characters.
  - 🔴 Changed `/terminal-setup` for Zed to print a copyable Shift+Enter binding even if the linked keymap is missing, while still leaving symbolic links alone.
  - 🟢 Fixed a delay on paste when links or relative paths with a folder name ended in an image filename; bare image filenames, absolute paths and Windows paths in WSL still work.
  - 🟢 Changed unsuccessful clipboard image pastes on local Linux desktops to suggest `wl-clipboard` on Wayland or `xclip` on X11 when the corresponding clipboard command is missing.
- Voice dictation
  - 🔴 Changed voice cancellation so Escape or Ctrl+C still stops an active recording, but doesn't intercept those keys for voice processing when the composer is hidden.
  - 🔴 Added a 20-second connection timer when tap-to-dictate opens or retries a voice stream, separate from the 60-second timer for no new words once connected.
  - 🔴 Fixed voice dictation to ignore microphone callbacks from an earlier recording and stop a microphone that finishes starting after dictation has already ended.
  - 🟢 Extended toggle dictation's recording limit from two to ten minutes; when there's a transcript, the stop notice now says `dictation stopped at its 10m limit`.
  - 🟢 Extended toggle dictation's idle timeout from 15 seconds to one minute without new words; when there's a transcript, the stop notice now says `dictation stopped after 1m with no new words`.
  - 🟢 Allowed tap-to-speak to resume from the end of an untouched voice draft, without making users clear the draft first.
  - 🟢 Kept a tap-to-speak draft in the composer when recording ends because the composer is hidden or a blocking dialog takes over, instead of sending it automatically.
  - 🟢 Changed tap-to-dictate to stop when the prompt loses focus, the terminal detaches, or the prompt text is changed or sent, and finish processing the recording it already captured.
- Terminal rendering
  - 🔴 Changed the terminal renderer to reuse more of the previous screen while scrolling and paint only text lines in view.
  - 🔴 Improved terminal navigation and clipping around Unicode text by checking more character boundaries without splitting a combined character.
  - 🔴 Reduced the cost of showing large syntax-highlighted diffs when the terminal width changes, by reusing the highlighted lines before wrapping them again.
  - 🔴 Fixed the terminal's Markdown and code highlighting caches carrying over into a different transcript by clearing them when the first message changes and the main loop is idle.
  - 🔴 Made the composer account for the actual height of personal and managed status lines when laying out the footer.
- 🔴 Fixed the terminal's working indicator disappearing early when an active turn's streaming preview is held back.
