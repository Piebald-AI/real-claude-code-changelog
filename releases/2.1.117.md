# 2.1.117 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Removed `/autocompact` (the auto-compact window picker and its print-mode form); the `autoCompactWindow` setting and `CLAUDE_CODE_AUTO_COMPACT_WINDOW` still work, `/context` no longer points to the command, and the notice after an auto-compaction at a lowered window now says to set `autoCompactWindow` in settings.json.
- 🔴 Made more Bash commands ask before running instead of passing as read-only: `cd` with two or more directory arguments (zsh's `cd OLD NEW`), `find` whose `-delete`, `-exec` or similar action is disguised with quotes or backslashes, ambiguous `sed -i` arguments that could hide another script, `git ls-remote` with a URL or more than one argument, `git reflog` subcommands other than `show` and `list`, `man` with a file path outside its keyword searches or with `-l`, `test` with `-v`, `-R`, `-a`, `-o` or an argument containing `[`, `date --iso-8601` followed by an argument, `rg -z`, `file -z`/`--uncompress`, and `file` in the PowerShell tool.
- 🔴 Tightened Bash path and rule checks: a plain redirect to a numeric file name (`> 5`) is checked as a file write, quotes are no longer stripped from paths before checking, writes through a `..` that follows a directory ask (they may follow a symlink out of the working directory), a heredoc followed by a pipe or `&&`/`||` with nothing after it is treated as a parse error, the `acceptEdits` file-command check now checks every part before approving a compound command, a command too complex to parse is allowed only by a rule whose text equals the whole command, and blank lines are kept when comment lines are stripped before rule matching. `cd` path checks now skip flags and the `--` separator before choosing the directory, instead of including them in the path.
- 🔴 Stopped slash-command and skill arguments from running shell commands: before an argument goes into the prompt, a `!` next to a backtick is split from it with a space and a `!` at the start of a word gets a backslash, so the argument can't form a `` !`…` `` block.
- 🔴 Fixed dollar sequences such as `$&` and `$$` in skill, slash-command, and prompt/agent hook arguments being expanded as JavaScript replacement patterns instead of reaching the prompt unchanged.
- 🔴 Made plugin installs refuse unsafe input: copying a plugin skips broken symlinks and symlinks that point outside it, and points internal links into the installed copy rather than the source folder; git refs and commit hashes that start with `-` are rejected, archive entries with a path segment of `..` followed by a space (and then only spaces or dots) are refused, and a version of `.` or `..` can't escape the plugin cache; the native installer likewise refuses version strings with path characters. Adding a marketplace also keeps only letters, digits, `-` and `_` in the name of the folder it works in, so a repository or package name can't put path characters there.
- 🔴 Stopped assuming Opus 4.5 supports effort levels on Bedrock and Vertex; it keeps that default support on the Anthropic API, Claude Platform on AWS, Foundry and Mantle. Explicit model-capability overrides and `CLAUDE_CODE_ALWAYS_ENABLE_EFFORT` still take priority.
- 🔴 Changed Sonnet 4.6's context-window override from an on/off 1M switch to a positive token count sent with the account's client data; that override also adds the 1M-context request header.
- 🔴 Fixed default-branch detection returning the branch `origin/HEAD` names when that remote branch doesn't exist; it now falls back to `main` or `master`.
- 🔴 Made GitHub repository detection fall back to `git config remote.origin.url`, and try again later after a failure instead of remembering it for the rest of the session.
- 🔴 Made a cloud session opened from the terminal work more like a local one: `/btw`, `/context`, `@` file suggestions and the thinking toggle ask the remote session, `/rename` renames it, skills and prompt commands can be sent to it, Bash-mode input keeps its `!` prefix, `/clear` also clears the local view, and attaching first checks the session: an archived one stops with "Remote session … is archived and cannot accept new messages", and one whose status can't be fetched stops with the fetch error. Model and effort switching and rewind say they aren't available there yet, and `/ultraplan` (behind a remote switch) is turned off there.
- 🔴 Made Esc stop the active turn while viewing a cloud session from the terminal.
- 🔴 Made `/ultraplan` show a cloud-session creation failure's server message instead of status plus raw JSON, when the command's remote switch is enabled.
- 🔴 Added a tip naming skills and commands that teammates committed to `.claude/skills` or `.claude/commands` in the last 7 days ("New from your team: /name (author)"), behind a remote switch that's off by default.
- 🔴 Let `/schedule` create routines that run once at a set time (`run_once_at`) as well as on a cron schedule, and renamed scheduled remote agents from "triggers" to "routines" in its prompt, the tool description and links (claude.ai/code/routines). `/schedule` sits behind a remote switch that's off by default.
- 🔴 Made scheduled tasks run in the session that created them, even when another session holds the project's scheduler lock; the lock holder takes over another session's tasks only after that session's process has exited.
- 🔴 Changed `/ultrareview`'s errors: outside a git repository it suggests `git init`, a missing GitHub remote gets setup steps, a branch name that doesn't exist is refused, and a failed cloud-session start shows the server's reason. The system prompt now tells Claude that `/ultrareview` is user-triggered and billed, so it shouldn't try to start one. The command and that prompt line sit behind a remote switch that's off by default.
- 🔴 Added retirement notices for Claude Opus 4 and Claude Sonnet 4 (dates per provider) and an "updated to the latest Opus" notice for Opus 4 and Opus 4.1 on the Anthropic API and Claude Platform on AWS, which takes the place of Opus 4's retirement date there unless `CLAUDE_CODE_DISABLE_LEGACY_MODEL_REMAP` is set. Warnings now use the model family, including models named through `modelOverrides`, and the deprecation warning now also appears right after picking a model in `/model`.
- 🔴 Made picking an MCP resource template in an `@` mention insert the filled-in part and keep suggesting the next argument, with arguments URL-decoded. Template completion now compares the servers' cleaned MCP names when choosing the connection.
- 🔴 Changed the notice for `ultrathink` from "Effort set to high for this turn" to "Deeper reasoning requested for this turn".
- 🔴 Changed the hint under truncated tool output from "(ctrl+o to see all)" to "(ctrl+o to expand)", and lists of hidden files, tool uses, models and IDEs now read "… +N files" and so on.
- 🔴 Changed `/color`'s argument hint to list the available colours.
- 🔴 Fixed terminal rendering dropping bold when dim styling next to it ended (or the reverse), stopped cursor show/hide sequences in one frame cancelling each other out, and made a resumed main-screen terminal repaint from scratch.
- 🔴 Improved how text with escape sequences, such as coloured command output, is parsed for display: PM and SOS strings and sequences cut off by CAN or SUB are dropped, a malformed 256-colour or RGB code no longer turns its numbers into other styles, and an ESC reset now clears text styles. An ESC inside an unfinished OSC, DCS or APC string now starts a new escape sequence instead of swallowing the following output. It also drops text inside `ESC k … ESC \` terminal-title strings instead of displaying the title as output.
- 🔴 Redrew agent-team messages (plan approval and rejection, shutdown requests, task assignments, waiting for team lead approval), "Plan to implement", Cloud Authentication and permission-rule details with one shared titled card, which keeps their look apart from dropping the top and bottom padding inside shutdown requests and rejections, task assignments, and plan approvals and rejections; "Learn more" lines are links, error lines in several dialogs no longer start with "Error: ", and a few empty-list messages are laid out slightly differently.
- 🔴 Rebuilt the bundled image-processing and audio-capture native modules so they need glibc 2.17 instead of 2.25.
- 🔴 Updated the Bun runtime from build `1.3.13+743d2a40e` to `1.3.13+6db6c97be` (about 528 KB more machine code, no sections added or removed); it now needs glibc 2.17 instead of 2.25, gives `bun test` new `--parallel`, `--isolate`, `--shard` and `--parallel-delay` options (plus an internal `--test-worker`), adds eight `BUN_` variables for `bun test` workers, streaming `bun install` and feature switches, and its built-in JavaScript changes `node:http2` trailer handling and `bun test` sharding and worker reporting.
- 🟡 (2.1.89) Made `showThinkingSummaries: true` also request summarized thinking in interactive sessions when thinking is enabled and `--thinking-display` isn't given.
- 🟢 Replaced the native build's Glob and Grep tools with the embedded `bfs` and `ugrep`, reached as `find` and `grep` through Bash, in every session except the Agent SDK and `local-agent` entrypoints (before, only when `EMBEDDED_SEARCH_TOOLS` was set).
- 🟢 Switched on forked subagents in interactive sessions with `CLAUDE_CODE_FORK_SUBAGENT=1` (or a remote switch, off by default): the Agent tool forks the whole conversation when no `subagent_type` is given and is always loaded, and `/fork <directive>` starts such a background agent directly.
- 🟢 Loaded an agent's frontmatter `mcpServers` for the main session under `--agent`, listed in `/mcp` as "Active agent MCPs". `--strict-mcp-config` or an enterprise MCP configuration disables this; plugin-only customization accepts only plugin agents, and startup warns when policy blocks servers.
- 🟢 Made `/model` choices stick when project settings pin another model (it also writes `.claude/settings.local.json` and explains the pin), and the startup header shows "Using <model> (from …) · /model to change" when the model comes from project or managed settings.
- 🟢 Made Opus 4.7 count its 1M-token context window for `/context` and auto-compaction without the `[1m]` suffix, unless `CLAUDE_CODE_DISABLE_1M_CONTEXT` is set. Skills that override the model now inherit the 1M window from an Opus 4.7 main session too.
- 🟢 Changed the default effort for Pro and Max subscribers from medium to high, including Opus 4.6 and Sonnet 4.6 (Opus 4.7 stays at xhigh).
- 🟢 Made `/resume` check for a stale, large session and offer to summarize it first, as `--resume` already did (behind a remote switch that's off by default).
- 🟢 Connected `--mcp-config` servers and claude.ai connectors at the same time on every startup (it used to need a remote switch).
- 🟢 Labelled the advisor dialog "Advisor Tool (Experimental)", added a recommended-setup line, blog link and startup notice when the advisor is enabled for the session, and retried requests refused with "Advisor tool result content could not be processed" without the advisor results.
- 🟢 Extended the `cleanupPeriodDays` cleanup to `~/.claude/tasks/`, `~/.claude/shell-snapshots/`, `~/.claude/backups/` and `~/.claude/dump-prompts/`.
- 🟢 Fixed claude.ai-login sessions ending with "Please run /login" when the access token expired mid-session: a 401 now refreshes the token and retries, giving up after two refreshes that leave it unchanged.
- 🟢 Fixed `/login` having no effect in a session started with `CLAUDE_CODE_OAUTH_TOKEN` (or a token file descriptor): the new token now replaces it.
- 🟢 Fixed `WebFetch` hanging on very large pages: HTML is capped at about a million characters before conversion to Markdown, with "[Content truncated due to length...]".
- 🟢 Fixed an empty or malformed response from a proxy (such as HTTP 204) failing with a `TypeError`; it now says "API returned an empty or malformed response … check for a proxy or gateway intercepting the request".
- 🟢 Fixed prompt-input undo doing nothing right after typing and skipping a state on each step.
- 🟢 Fixed text that arrives in one chunk and happens to spell a key name ("escape", "return", "tab") triggering that key in prompt suggestions and several dialogs, as could happen over slow connections.
- 🟢 Fixed file reads by a subagent on a different model getting the malware reminder meant for the main model; the reminder now follows the model that did the read.
- 🟢 Fixed a re-render every second while background tasks were listed but none was running.
