# 2.1.176 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Changed fork subagents (`CLAUDE_CODE_FORK_SUBAGENT` or a remote switch, off by default) to start only with `subagent_type: "fork"`: leaving `subagent_type` out now starts a fresh general-purpose agent, an `Agent(fork)` deny rule refuses them, and `isolation: "remote"` is refused for a fork. Resuming a custom agent named `fork` now uses that agent's own definition instead of the built-in fork's prompt and tools.
- 🔴 Added automatic sign-in for HTTP and SSE MCP servers at `https://api.anthropic.com`: on the Anthropic API with a claude.ai login, Claude Code sends your claude.ai token itself (refreshing it once after a 401) instead of an MCP OAuth flow, unless the server config sets its own `Authorization` header, and `/mcp` stops offering to authenticate them; a refusal reads "api.anthropic.com rejected your claude.ai login" with a `/login` hint.
- 🔴 Fixed SSE MCP connections dropping transport-provided headers, including the negotiated MCP protocol version, when those headers arrive as a `Headers` object.
- 🔴 Replaced the silent Claude in Chrome auto-enable with a one-time startup question, "Claude in Chrome extension detected" ("Yes, use my browser" / "No, keep browser tools off"), whose answer becomes your default; it isn't asked in SSH, remote, teleported, safe-mode, bypass-permissions or teammate sessions (remote switch, off by default).
- 🔴 Stopped Claude in Chrome turned on by your saved default from making startup fail with "You cannot dynamically configure MCP servers when an enterprise MCP config is present": with an enterprise MCP config, a `deniedMcpServers` entry for it or `--safe-mode`, the session now starts without Chrome, and `--chrome` with a denied server warns "MCP server blocked by enterprise policy".
- 🔴 Made the bundled `claude-in-chrome` skill available in every session that sets up Claude in Chrome (it was only offered in the remote auto-enable variant), and turned it off again when managed policy blocks the Chrome server.
- 🔴 Fixed `/config` showing "Claude in Chrome enabled by default" as on when you had never set it; Claude in Chrome stayed off in that case.
- 🔴 Stopped reporting a missing local Claude in Chrome extension as a setup issue when a paired browser is registered.
- 🔴 Widened Bash's dangerous `rm`/`rmdir` check, which always asks and can't be allowed by rules, to globs that would empty the working folder, an added working folder or a parent of either (`rm -rf *`), targets behind symlinks (including a symlinked home folder), relative globs in commands chained with `;`, `|` or `&` or after a `cd` it can't follow, and globs built from variables, `~`, `..` or `//`; path spellings such as `/bin/rm` and `/usr/bin/env rm` now count too.
- 🔴 Escaped transcript tags and normalized line separators in auto mode's safety-classifier tool inputs, added the same escaping to user messages when its JSON-line transcript format is enabled, and escaped `<user_claude_md>` tags in the CLAUDE.md it reads.
- 🔴 Made signing in again from `/upgrade` or `/usage-credits` refresh the session as `/login` does (permissions, fast mode, account caches, trusted-device enrollment) instead of only swapping the credentials.
- 🔴 Added a `<total_tokens>` budget note for Claude, set by `CLAUDE_CODE_TOTAL_TOKENS_REMINDER` or the `totalTokensReminder` setting (remote default off): `infinite`, `fixed` (5,000,000) or `countdown` (tokens left in the context window), in the system prompt and after each tool result.
- 🔴 Kept pasted text available while its paste-cache write is pending, used a memory cache for failed writes that holds up to 10 million characters and drops the oldest entries first, and made prompt history show "[Pasted text #N — content no longer available]" when a recalled entry's pasted text is gone.
- 🔴 Made `/team-onboarding` and its guide sharing follow a new organization policy, `allow_team_onboarding`, which defaults to off for HIPAA organizations (an explicit server policy can still allow it).
- 🔴 Made TaskUpdate accept `id` or `task_id` for `taskId` and `active_form` for `activeForm`, also when the task list is rebuilt from a transcript.
- 🔴 Stopped writing session metadata (titles, PR links, agent name and color, worktree state, Remote Control link, speculation timing) to the transcript file when session persistence is off (`--no-session-persistence`, `CLAUDE_CODE_SKIP_PROMPT_HISTORY`, or a child session).
- 🔴 Changed the error for a Glob or Grep call in sessions without those tools to tell Claude to use `find` or `grep` through Bash, and stopped showing such calls from a transcript as unknown tools.
- 🔴 Changed `/context` to count Messages as the last response's reported input minus the other categories plus an estimate for messages added since, ignoring responses that report no input, instead of the larger of a full estimate and the last report.
- 🔴 Extended the Projects tool (sessions bound to a claude.ai Project, policy `allow_projects_tool`): `project_info` lists file uploads and synced sources, `project_read` returns text extracted from uploaded PDFs and documents, `project_delete` refuses file uploads, and the session's project summary lists them too.
- 🔴 Changed the Artifact tool (remote switch, off by default; Team and Enterprise logins): its description and WebFetch's say artifact pages can be read with WebFetch through your claude.ai login, and behind a second remote switch it refuses to overwrite an artifact this session hasn't read since its last change unless `force: true` is passed.
- 🔴 Changed coordinator mode's instructions (`CLAUDE_CODE_COORDINATOR_MODE`) to keep a question or small task that needs only a handful of tool calls in one worker instead of fanning it out.
- 🔴 Updated the bundled `/design-sync` skill with a `column` card mode for components wider than a grid cell, a `[GRID_OVERFLOW]` check that flags them, clipping inside grid cells, and card-layout overrides that no longer force re-grading. Existing layouts changed too: grid cards use the full width when there are few stories, the default single-story card loses its outer padding while per-story captures keep it, and both rebuild paths warn about an invalid `cardMode`.
- 🔴 Changed the bundled `/claude-api` skill to add server-side refusal fallbacks (`fallbacks` with the `server-side-fallback-2026-06-01` beta, Opus as fallback) to Fable 5 code by default, with language-specific guidance and client-side middleware where the API option isn't available.
- 🔴 Added a system-prompt line for Fable 5 and Mythos 5 telling Claude to write object and array tool parameters as single JSON values without parameter-tag markup (remote switch, off by default).
- 🔴 Made `claude -p` and SDK sessions restore a resumed session's background tasks, remote agent tasks and MCP tasks, as interactive resumes already did.
- 🔴 Fixed `claude -p` stream output dropping a `result` message held back while background tasks were running once another result was sent.
- 🔴 Made `claude -p` and SDK prompt suggestions also respect the `promptSuggestionEnabled: false` setting.
- 🔴 Stopped cloud-session transcript downloads (including resuming a session by URL) from replacing a local transcript with the server's copy when that copy has no user or assistant messages.
- 🔴 Made the agents view (`claude agents`) wait for a background session to finish starting before attaching, showing "opening…" on its row, and let moving the selection cancel the pending attach; while an attach is pending, keys other than the cancel keys, Esc and Ctrl+C are ignored.
- 🔴 Stopped the agents view and `claude agents --json` from marking a job the background service still holds as failed once it's more than 5 seconds old; it keeps its saved state.
- 🔴 Let Ctrl+C, Ctrl+Z and Ctrl+B d detach while the agents view is still connecting to a background session.
- 🔴 Kept the last output of a background `--exec` run that ends while no window is attached, and showed it on the next attach.
- 🔴 Showed a background `--exec` run that hasn't printed anything as idle instead of leaving its first state in place.
- 🔴 Made `claude agents --json` strip control characters from session names and use a background session's intent when it has no name.
- 🔴 Changed the prompt footer's teammate row (agent teams) to take arrow-key focus only when every running background task is a teammate or one is being viewed, kept the same teammate selected when the list changes, and fixed it marking the wrong teammate as viewed after re-sorting.
- 🔴 Fixed the footer's PR badge keeping a stale pull request after repeated GitHub fetch failures turned PR checks off.
- 🔴 Moved notification settings in the regrouped `/config` into a Notifications page that cycles the channel and holds both push switches (remote switch, off by default).
- 🔴 Made `availableModels` checks match `modelOverrides` values regardless of letter case.
- 🔴 Counted files read through Bash with `nl`, `bat`/`batcat` (`-n`, `-p`) or a single-file `rg` search as read, as `cat` already was, so Claude can edit them without reading them again.
- 🔴 Changed the PowerShell tool (`CLAUDE_CODE_USE_POWERSHELL_TOOL` off Windows) to report a command cancelled before it started as interrupted, "Command aborted before execution", instead of a launch failure.
- 🔴 Stopped treating `--debug`, `--debug-file` and `--debug-to-stderr` after `--` on the command line as Claude Code's own options, and ignored a `--debug-file` path that starts with two slashes, except WSL shares (`//wsl$/…` or `//wsl.localhost/…`).
- 🔴 Changed precomputed background compaction (remote switch, off by default): auto-compaction at its threshold now uses a background summary when one is ready, and when the compaction window comes from `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, the `autoCompactWindow` setting or a model default, the summary starts at the precompute buffer and is skipped for windows under 200,000 tokens.
- 🔴 Made cloud sessions that get their session token only from `CLAUDE_SESSION_INGRESS_TOKEN_FILE` identify as remote sessions, as sessions given the token directly already did, so their commits and pull requests carry the session's claude.ai link instead of the usual Claude Code attribution.
- 🟡 (2.1.232) Added `fable` to `/advisor`'s choices and limited the list in its hint and error message to models you can use as an advisor.
- 🟡 (2.1.319) Made sed auto-approval ask first for sed commands with shell expansions, here-documents it can't validate, unusual quoting, redirections that carry their own content, or more text than can be checked, and stopped a leading redirection (`>out sed …`, `<<<`) from hiding a sed command from the check.
- 🟡 (2.1.229) Fixed terminal renderers (tables, boxes, trees, usage bars and padded rows) that could crash with "Invalid count value" when a computed padding came out negative.
- 🟢 Made session titles follow the language of the conversation when no `language` setting is set, adding that instruction and a Korean example to the title prompt.
- 🟢 Added the `footerLinksRegexes` setting (user, flag and managed settings only): a regex match in tool results or Claude's replies adds a clickable footer badge built from named groups, with https, http and editor or workspace link schemes, at most 5 badges, cleared by `/clear`; the detected PR now shows as the first badge, using `prUrlTemplate`.
- 🟢 Cached Bedrock credentials from `awsCredentialExport` until five minutes before their `Expiration` (at least one minute) instead of a fixed hour.
- 🟢 Made `/fast` refuse with "Opus 4.8 is not in your organization's allowed models" when `availableModels` doesn't allow Opus and the current model isn't an allowed Opus 4.6, 4.7 or 4.8, and, under `enforceAvailableModels`, checked alias picks against the model `ANTHROPIC_DEFAULT_*_MODEL` points them to.
- 🟢 Fixed auto mode on Fable 5 and Mythos 5 for organizations without Opus 4.8: on the Anthropic API the classifier, and the background agent naming and status requests, use the first of Opus 4.8, 4.7, 4.6 and 4.5 that `availableModels` allows, unless `ANTHROPIC_DEFAULT_OPUS_MODEL` is set.
- 🟢 Fixed hook `if` conditions on file paths for Read, Edit and Write, now matched relative to their root like permission rules (`Edit(src/**)`, `Read(~/.ssh/**)`, `Read(.env)`), and gave NotebookEdit the same matching, where such conditions never matched before.
- 🟢 Fixed the Linux sandbox failing to start when `.claude/settings.json` (or `settings.local.json`) is a symlink: the sandbox now protects the files the links point to.
- 🟢 Fixed copying to the system clipboard inside tmux: Claude Code now always tries `tmux load-buffer -w` (before, it skipped `-w` under iTerm2) and retries without `-w` for tmux older than 3.2.
- 🟢 Fixed Remote Control clients on web or mobile switching the terminal's model on connect: the session now reports its current model and permission mode for them to adopt.
- 🟢 Fixed Remote Control disconnect notices showing a bare close code instead of a reason such as "auth token expired (code 401)", and stopped disconnects and connection failures from also adding a line to the transcript.
- 🟢 Fixed Remote Control staying connected after `/login` (or the `/upgrade` and `/usage-credits` sign-ins) switched to a different account; it now disconnects and says "Login successful. Remote Control disconnected."
- 🟢 Fixed `/cd`, entering or leaving a worktree, and resuming a session into its worktree leaving the footer on the previous folder's git branch; a failed EnterWorktree now also returns to the original folder.
- 🟢 Fixed going back in one `claude agents` window detaching other windows attached to the same session: the detach goes to the window that last typed, and only a transfer to Claude Desktop detaches all of them.
- 🟢 Fixed a session sent to the background with `/bg` mid-turn showing "Working" forever when nothing was left to continue; it now waits with "send a prompt to start".
- 🟢 Fixed background sessions' PR search: background sessions now record the links (and pull requests) their transcript gains while blocked or idle, so they show up in `claude agents` search.
- 🟢 Fixed the `claude agents` search box showing no text cursor in full-repaint mode, which `claude agents` turns on under Windows Terminal (including WSL) or `CLAUDE_CODE_ALT_SCREEN_FULL_REPAINT`.
- 🟢 Fixed `claude --bg` reading combined short flags and flag values (`-cn <name>`, `--name -c`, `--rc <name>`, `-r<id>`) when building a background session's command line, so `-cn <name>` names the session.
- 🟢 Neutralized network paths (starting with two slashes or backslashes, except WSL shares such as `//wsl$/…` or `//wsl.localhost/…`) in background sessions' saved state and respawn arguments, warning that "background sessions do not support Windows network (UNC) paths" when they're used.
- 🟢 Fixed background-session respawn using malformed resume IDs from damaged state files: an invalid session ID now gets a fresh one instead of being turned into a transcript path.
- 🟢 Reworded the background service's refusal of a window without its control key to say the window is likely an older Claude Code left open across an update and to restart it (or retry, for a wrong key), and explained version skew in `claude daemon status`.
