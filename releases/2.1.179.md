# 2.1.179 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Moved in-process agent-team teammates into the background tasks panel, where each row shows "idle", "awaiting approval" or "stopping", the current turn's time, tokens and queued messages. Removed the old teammate views: the tree under the spinner with message previews, the footer's teammate pills and Teams dialog (end, shut down, prune idle, hide or show panes), Shift+↑/↓ selection and Ctrl+Shift+O previews; stopping all background agents now also stops running teammates.
- 🔴 Changed Ctrl+C while viewing a subagent or teammate to stop that agent (and, for a subagent, the subagents it started), or dismiss it once it has finished, instead of stopping every running background subagent; it still cancels the main turn if one is running.
- 🔴 Changed the default `teammateMode` from `auto` to `in-process`, so agent-team teammates run inside the session even inside tmux or iTerm2 unless `teammateMode` is set to `auto` or `tmux`.
- 🔴 Made the spinner follow the agent you're viewing: subagents and teammates now show their own requesting, thinking, responding and tool-input states and turn time instead of the main conversation's.
- 🔴 Stopped agent-team actions from failing when the team file can't be written; the failure is logged instead.
- 🔴 Made results of tools that finish while the model is still streaming appear as soon as they finish, not only when the next part of the response arrives.
- 🔴 Changed the Fable 5 usage-credit consent check to switch models only where Claude Code can ask: in `claude -p` without streaming input, or under an SDK host that doesn't offer the consent prompt, a Fable 5 request or compaction is no longer moved to a fallback model before it's sent.
- 🔴 Allowed `/model default` in an attached remote session, and saving Default in the inline model picker, even when the local default resolves to Fable 5 and its usage-credit consent hasn't been given.
- 🔴 Made `/model` in print and SDK sessions refuse Fable 5 until its one-time usage-credit consent is given ("Fable 5 uses usage credits and needs a one-time consent · pick Fable from /model in an interactive session to set it up").
- 🔴 Changed `/config` so picking Fable 5 before its usage-credit consent applies to the current session only, without saving it as your default (" · this session only — /model to set up"), and stopped it from being set as the teammate default model.
- 🔴 Changed the model fallback chain to skip fallback models that resolve to the model that just failed, where it used to switch to that same model under a "Switched to …" notice; when only that model is left after an overload or server error, the request is sent to it again without a switch notice, and the notice now names the model actually used.
- 🔴 Stopped Fable 5 requests over 200K tokens that run on usage credits from marking Fable as needing usage-credit consent, as `[1m]` requests already didn't.
- 🔴 Gave Claude Mythos Preview (`claude-mythos-preview`) a 1M-token context window by default on Anthropic's own API (without a custom base URL), Claude Platform on AWS and Mantle.
- 🔴 Changed `availableModels` checks on the Anthropic API, Claude Platform on AWS and gateways so a listed legacy Opus 4 or 4.1 model id that `ANTHROPIC_DEFAULT_OPUS_MODEL` redirects to another model is allowed only if that model is allowed too, as alias picks already were.
- 🔴 Changed auto mode to always deny a tool call, with retry guidance, when its classifier is unavailable; a remote switch could previously fall back to the normal permission prompt.
- 🔴 Changed sandboxed network access to be denied whenever the network classifier is unavailable; a remote switch could previously allow it.
- 🔴 Updated auto mode's classifier rules: read-only access you authorize to a target now covers later read-only commands on it (production reads too, once you've named the target), a "yes" or "go ahead" after a block counts as consent to that blocked action unless a rule needs you to name the target of irreversible or mass destruction, and a new rule blocks adding a new kind of sensitive content to a live-shared artifact unless your messages show you know it's shared.
- 🔴 Changed `sed` permission checks to ask before running a command with an unquoted `*`, `?` or `[`, which the shell would expand into file names.
- 🔴 Changed Bash permission checks to treat zsh `typeset`/`declare`-style commands with a `-m` or `+m` flag (pattern assignment) as too complex to approve automatically, and added `PPID`, `ARGC`, `ZSH_SUBSHELL`, `TTYIDLE` and `status` to the integer shell variables whose risky writes (unsetting them, writing them with commands such as `read`, using them as loop variables, or assigning a value that could run code) always need approval.
- 🔴 Stopped sandboxed Bash commands containing `${` followed by a space or `|` from being approved automatically.
- 🔴 Narrowed the Bash tool's rewrite of Windows-style `> NUL` redirects to `/dev/null`: commands containing `<`, `$` or a backtick are left as written, and a `NUL` on the next line no longer counts.
- 🔴 Removed `Get-EventLog` from the PowerShell tool's read-only commands, stopped counting `git` with the global options `--help`, `-h` or `--shallow-file` as read-only there, and made it check a comma-separated argument as a whole as well as piece by piece.
- 🔴 Stopped recognizing git remote URLs whose owner or repository name has characters other than letters, digits, `.`, `_` and `-`, starts with `-`, or is `.` or `..`.
- 🔴 Fixed nested instruction files (`CLAUDE.md`, `CLAUDE.local.md` and unconditional `.claude/rules` files) not loading when a file inside the project was read through a symlinked path.
- 🔴 Stopped the Edit tool from opening files on network shares (`\\server\…` or `//server/…` paths) to match quotes and whitespace in an edit; WSL paths (`\\wsl$\…`, `\\wsl.localhost\…`) still are.
- 🔴 Fixed reading a missing or unreadable PDF giving an "unknown" PDF error instead of the usual file error.
- 🔴 Stopped the native build from importing command completion specs from `@withfig/autocomplete` at run time; only the specs built into Claude Code are used.
- 🔴 Blocked `import()` in code run by the REPL tool (`CLAUDE_CODE_REPL`), which now fails with "import() is not available in REPL code."
- 🔴 Stopped a dynamic workflow script from running code through a getter or proxy on an `agent()` call's options when Claude Code reads their `schema`.
- 🔴 Made the team-skills tip's `git log` run only in a trusted folder, and without the repository's fsmonitor, hooks, pager or signature checks.
- 🔴 Added a check, while installing a plugin pinned to a commit, that the checkout really is at that commit; otherwise the install stops with "SHA pin verification failed … Refusing to install."
- 🔴 Changed the bundled `code-review` dynamic workflow to verify every candidate finding (no early merging of look-alike findings and no cap of 25 verifications), ask finders for each bug's user-visible consequence, and have the final step keep and merge findings by number, appending verified ones it left out while there's room.
- 🔴 Changed `/ultrareview` (`/code-review ultra`) to check a pull request's size with `gh pr view` before starting and refuse one over the limit ("PR #N is too large for ultrareview …"), lowered the default limit from 50,000 to 8,000 changed lines when the server's review settings don't give one, and stopped suggesting a PR number when a local diff is too large.
- 🔴 Fixed `ExitWorktree` failing when the folder you started in had been deleted: the session now moves to the kept worktree, your home folder or the temporary folder, and says so.
- 🔴 Changed `/compact` to report its known failures (a PreCompact hook blocking it, no summary produced, a conversation that can't get small enough, media over the size limits) as the command's output instead of an error.
- 🔴 Changed `--json-schema` to stop with "Error: --json-schema is not valid JSON: …" instead of a raw parse error, and to refuse valid JSON that isn't an object with "Error: --json-schema must be a JSON object".
- 🔴 Stopped OpenTelemetry exporters from sending an explicitly set `localhost`, `127.x.x.x` or `::1` endpoint through the proxy, made each signal's own `OTEL_EXPORTER_OTLP_<SIGNAL>_ENDPOINT` decide, and stopped the first exporter's proxy choice from applying to all of them; unset endpoints still go through the proxy.
- 🔴 Added `CLAUDE_CODE_OTEL_DIAG_STDERR` to also print OpenTelemetry's diagnostic errors on stderr; it's kept out of the environment of commands Claude Code runs.
- 🔴 Added AltGr typing in Windows Terminal, including WSL: Ctrl+Alt with a printable character that isn't a letter or digit is typed as text, and `CLAUDE_CODE_ALTGR_AS_TEXT` turns this on for every printable character, or off.
- 🔴 Limited each upward or downward cursor jump the terminal renderer makes between frames to the terminal's height, so a frame that changes by more lines than the screen holds can't move the cursor off screen.
- 🔴 Changed commit and pull request attribution in cloud sessions to keep the usual attribution (`Co-Authored-By`, "Generated with Claude Code" or your `attribution` settings) and add the session link, as a `Claude-Session:` trailer in commits; before, the session link replaced it.
- 🔴 Made Remote Control wait for a fresh login when refreshing its OAuth token fails: it tries again up to 3 times with growing delays ("OAuth refresh failed — waiting for a fresh login (1/3)"), then says to re-authenticate and re-enable Remote Control. Conversation messages produced during a 401 or connection-initialization recovery are now queued for the replacement connection.
- 🔴 Removed the red "/rc failed" Remote Control item from the footer; the item now shows only while Remote Control is connected or reconnecting, and failures still raise a notification.
- 🔴 Changed compaction while Remote Control is on (or `CLAUDE_CODE_ENVIRONMENT_KIND` is `bridge`) to wait until a request overflows the context window, as other local sessions do, instead of compacting ahead of time. It also allowed these sessions to prepare compaction summaries in the background, when the default-off background-compaction switch is on and `precomputeCompactionEnabled` (on by default) isn't turned off.
- 🔴 Added a `precomputeCompactionEnabled` setting (on by default) and a "Precompute compaction" switch in `/config` that stop Claude Code preparing a compaction summary in the background, and let a remote table set when that preparation starts by context window and session type; all of it applies only when the feature's remote switch is on (off by default).
- 🔴 Added a startup notice for organizations in HIPAA mode: "HIPAA · some features are restricted · /status for details".
- 🔴 Changed `companyAnnouncements` to skip empty entries and keep the same randomly picked announcement for the whole session (until `/clear`).
- 🔴 Reworded the Claude Design tip to "Use Claude Design to mock up screens before you build · claude.ai/design".
- 🔴 Fixed the "Included with your plan until …" date for Fable 5 showing a day off in some time zones; it's now read in UTC.
- 🔴 Changed project MCP servers to be read from the `.mcp.json` files in the folder the session started in and its parents, rather than in the current working folder, which can change during a session.
- 🔴 Added a built-in `claude_design` MCP server (`https://api.anthropic.com/v1/design/mcp`) for sessions in Anthropic API mode, including a custom `ANTHROPIC_BASE_URL`, but not the Bedrock, Vertex, Foundry, Claude Platform on AWS or Mantle modes; it's turned on by `CLAUDE_CODE_ENABLE_DESIGN_MCP` or a remote switch that's off by default.
- 🔴 Added share-aware publishing to the Artifact tool: it checks who can see a page before publishing, the permission prompt names the audience ("a page shared with your organization on claude.ai (viewers see updates immediately)", "a private page on claude.ai" and others), live-shared redeploys no longer reuse the session's earlier automatic approval, and auto mode sees them marked (remote switch, off by default; the Artifact tool itself sits behind a remote switch for Team and Enterprise plans).
- 🔴 Changed Artifact publishing to allow direct upload under its remote switch from every entrypoint rather than only cloud sessions, to retry a direct upload once after HTTP 429 (waiting up to 30 seconds), and to send the cloud session's ID.
- 🔴 Changed WebFetch in cloud sessions to send an `anthropic-version` header to its proxy and to include the proxy's error message when it rejects a request.
- 🔴 Changed `/usage` (`/cost`) in print and SDK sessions to say you're using your subscription only when Claude Code knows your plan; with a sign-in token that carries no plan details it shows the session's cost instead.
- 🔴 Stopped new worktrees from getting `core.hooksPath` set to the main repository's `.husky` or `.git/hooks` folder; only a relative `core.hooksPath` from the main repository is now rewritten as an absolute path.
- 🔴 Made keeping or removing a worktree finish even when Claude Code can't change back to the original folder, logging the problem.
- 🔴 Changed `/model`'s confirmation in a session attached to a remote one to "Reset model to the workspace default" when the model is reset.
- 🟡 (2.1.187) Added a "Not used recently" section to `/plugin`'s installed list, with "not used in N days" on enabled plugins and "Last used" in plugin details (remote switch, off by default; not shown under `strictKnownMarketplaces`, which now also hides the existing tip naming plugins you haven't used in a while).
- 🟡 (2.1.187) Fixed resumed subagents reaching the nesting limit one level too early after their original run was synchronous; their task now saves the same depth as the running agent.
- 🟢 Fixed mid-stream connection drops: a reply cut off by a dropped connection keeps its finished part, with "API Error: Connection closed mid-response. The response above may be incomplete." (or "Connection closed while thinking, before producing a response. Try again."), and other lost connections show "API Error: Connection to the API was lost (CODE). This is usually temporary — try again."
- 🟢 Fixed mouse-wheel scrolling in WSL: mouse tracking is no longer turned off there when none of the usual terminal variables (such as `WT_SESSION` or `TERM_PROGRAM`) are set.
- 🟢 Fixed a large sandbox read or write list swelling the Bash tool description: each list now shows at most 50 entries, then "... and N more (truncated for prompt size)".
- 🟢 Fixed the feedback survey taking a typed digit as a rating: it now waits 2 seconds after a turn ends and stays hidden while you're typing.
- 🟢 Fixed the welcome screen showing more than one promotion: the feature-of-the-week nudge and the fullscreen downsell now share the single notice slot with the other announcements, the chosen notice stays for the session, and "seen" counts go up once per session.
- 🟢 Fixed Ctrl+O showing the main conversation instead of the subagent you're viewing.
- 🟢 Fixed clicking the prompt not clearing a selected footer or subagent-panel item.
- 🟢 Fixed SDK and cloud sessions looking busy between turns while background agents run: the session now reports idle while it waits for them and running again when a queued message starts, and it waits a limited time for a finished task's completion notice before ending.
- 🟢 Changed cloud sessions' download of organization plugins to stream to disk and give up only after 60 seconds without data (`CLAUDE_CODE_SYNC_PLUGINS_DOWNLOAD_STALL_MS`), rather than holding the whole archive in memory under a 60-second limit; `CLAUDE_CODE_SYNC_PLUGINS_BUFFERED_DOWNLOAD` restores the old download.
