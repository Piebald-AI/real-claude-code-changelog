# 2.1.182 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Added `/migrate` and `claude migrate [codex|gemini] [--dry-run] [--yes]`, which imported OpenAI Codex and Gemini CLI setups (MCP servers, permission mode, subagents, skills, slash commands and `AGENTS.md` or `GEMINI.md` instructions) through a checkbox picker, or without one when given `--yes`; `/init` offered it when it found such config. `--yes` imports only user-level items with no warning, leaving project config, permission-mode changes and other warned-about items for individual selection in the terminal picker; migration was removed again in 2.1.183.
- 🔴 Added a 60-second limit on waiting for response headers to a streaming API request: a request that gets none is aborted with "Request timed out: no response headers after 60s" and retried. `CLAUDE_CODE_CONNECT_TIMEOUT_MS` sets the limit, and 0 turns it off.
- 🔴 Made `claude -p` give up after 10 minutes of waiting for background subagents or workflows at the end of a run, stopping them and any background shell commands with a note on stderr; `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS` sets the limit, and 0 waits indefinitely.
- 🔴 Changed `/diff` to show a branch's changes since it left the default branch, titled "Branch changes (vs <branch>)", when there are no uncommitted changes.
- 🔴 Fixed slash-command suggestions jumping back to the first row when the list refreshes without a change to the input; the highlighted command now stays selected if it's still present.
- 🔴 Added Fable usage-credit help for claude.ai plans where Fable now needs usage credits: a "Fable now runs on usage credits." startup notice, a "Switch to <model>" choice in the rate-limit menu, a hint to switch models under Fable limit messages, and a disabled Fable row in `/model` for Team members without billing rights whose organization hasn't turned usage credits on.
- 🔴 Pointed Team and Enterprise usage-limit messages at `/usage-credits`, and offered members "Ask your admin for more usage" in the rate-limit menu even when their organization's credits are used up or turned off.
- 🔴 Made auto mode retry its safety classifier up to four more times within the same time limit when the reply can't be read, before blocking the action as unevaluable.
- 🔴 Raised the auto mode classifier's sampling temperature from 0 to 1 when it runs on a model that accepts one, such as Sonnet 4.6 or Opus 4.6; by default the classifier uses the session's model.
- 🔴 Made more Bash commands ask for approval: builtins such as `exit`, `return`, `shift`, `set` and `print` whose operands are only known at run time (a command substitution's output or a variable whose value isn't known in advance), as `declare`, `export` and `local` already did; `printf` operands known only at run time even without a `[`; the same checks for `bye` and `logout`; and redirect targets built from several parts. A backslash before a line break inside a word now counts as a line continuation.
- 🔴 Fixed Bash redirect filename checks to interpret escaped characters inside words and double quotes, so approval checks use the path the shell will open.
- 🔴 Handled the API error "input length and `max_tokens` exceed context limit" like a prompt that's too long: it now shows "Prompt is too long" and no longer moves the request to the fallback model.
- 🔴 Fixed requests failing with a 400 about a missing `thinking.signature` field: Claude Code now drops the thinking blocks and retries, as it already did for other rejected thinking blocks.
- 🔴 Stopped a resumed session from switching back to the model it last used when a model is already set for this run (`--model` or `ANTHROPIC_MODEL`) or the provider is a third party such as Bedrock, Vertex or Foundry.
- 🔴 Added a clearer error when the Linux sandbox's network bridge has died: "Linux sandbox SOCKS bridge socket is missing (socat may have died). Restart to retry." (or HTTP).
- 🔴 Expanded the bundled claude-api skill: the C#, Go, Java, PHP and Ruby references are split into topic files, Go, Java, PHP and Ruby gain Managed Agents references, and new material covers per-platform feature availability, API shapes models tend to misremember, a C# fast-mode example, task budgets and every SDK's exception classes; mid-conversation `system` messages are now described as needing no beta header on Opus 4.8.
- 🔴 Changed `/claude-api` guidance to write SDK code from its language references and fix compiler errors before spending more turns researching missing type names, using the same local-reference approach when fetching docs fails.
- 🔴 Added `/claude-api` guidance for setting up Workload Identity Federation, including the four activation variables, token exchange and automatic refresh, and clearing API-key, auth-token and profile variables that take priority.
- 🔴 Corrected `/claude-api` computer-use guidance to put the desktop environment and action execution in your application rather than on Anthropic's servers.
- 🔴 Added `/claude-api` recipes for declaring the built-in Bash and text-editor tools without an `input_schema`, executing their calls locally, and limiting file operations to the chosen project folder.
- 🔴 Added `/claude-api` instructions for enabling Messages API skills with `container.skills`, the skills and code-execution beta headers, and the code-execution tool.
- 🔴 Added `/claude-api` guidance to pair every server in `mcp_servers` with a matching `mcp_toolset` in `tools`.
- 🔴 Added `/claude-api` advisor guidance listing allowed executor/advisor model pairs and where each model ID belongs in the request.
- 🔴 Added C# `/claude-api` examples for listing and retrieving models with `client.Models`.
- 🔴 Added C# `/claude-api` guidance for streaming 128,000-token outputs on Claude 4+ models without an output beta header.
- 🔴 Added C# `/claude-api` guidance to use structured outputs instead of assistant prefill on Fable 5, Opus 4.6–4.8 and Sonnet 4.6, where prefills return a 400.
- 🔴 Corrected Java `/claude-api` document examples to construct sources with `Base64PdfSource`, `UrlPdfSource` and `BetaFileDocumentSource` builders, then pass them through `.source(...)`.
- 🔴 Corrected Java `/claude-api` advisor-tool guidance to wrap `BetaAdvisorTool20260301` through the `BetaToolUnion` factory instead of passing it directly to `.addTool(...)`.
- 🔴 Corrected C# `/claude-api` built-in tool examples to wrap each tool explicitly in `new ToolUnion(...)`.
- 🔴 Corrected Go `/claude-api` memory-tool guidance to use `BetaMemoryTool20250818Param` with `client.Beta.Messages.New`.

- 🔴 Changed the detail line of a working background job in `claude agents` to show Claude's latest text when there is some, instead of the last tool call.
- 🔴 Showed "input JSON failed to parse — N bytes" in tool call lines and tool summaries when a tool's input couldn't be parsed, where they showed nothing or "input failed to parse".
- 🔴 Dropped the closing sentence "These measures let us bring you Mythos-level capability in other areas sooner, and we're working to refine them." from the general refusal notice.
- 🔴 Fixed a possible crash when the message list holds an empty entry; it's now skipped and reported once.
- 🔴 Made the startup trust dialog and the bypass-permissions warning ignore further key presses once an answer is chosen or Claude Code is exiting.
- 🔴 Added small "·" and "~" marks beside Clawd, the mascot, while it crouches in its jump animation.
- 🟡 (2.1.183) Tightened auto mode's rules for discarding work unless you asked for it: `git restore .`, `git clean -fd` and `git stash drop` or `clear` join `git reset --hard`, `git checkout -- .` and `git clean -fdx`, with the working tree presumed to hold uncommitted changes; `git commit --amend` on a commit this session didn't make and `terraform`, `pulumi`, `cdk` or `terragrunt` `destroy` are now blocked too.
- 🟡 (2.1.183) Added exceptions to auto mode's local Git destruction rule: reset/checkout/restore can clear it for a requested rebase, force-push, re-sign or retry after a merge, or after the work was just stashed or backed up. An agent-created worktree or scratch clone also clears local Git checks, but the worktree exception doesn't cover stash deletion, and the backup exception doesn't cover `clean` or stash deletion.
- 🟡 (2.1.183) Added a warning on stderr in print mode when the requested model, including an agent's model, is remapped to a newer one, retired or due to retire, and based the interactive notice on the requested model too; its remap wording now names the model used and the `CLAUDE_CODE_DISABLE_LEGACY_MODEL_REMAP=1` opt-out.
- 🟡 (2.1.183) Added `attribution.sessionUrl`: `false` leaves out the claude.ai session link (the `Claude-Session` trailer and the PR-body link) in web and Remote Control sessions.
- 🟡 (2.1.183) Extended `/config key=value` to theme, notification channel, output style, language (any language name or ISO code), model and default teammate model, with argument completion; `/config --help` lists every key with its values, and a Fable choice that still needs usage-credits consent is refused.
- 🟡 (2.1.183) Changed `/config` and `/skills` so Enter changes the highlighted item like Space, and Esc closes keeping the changes; before, Enter saved and closed, and Esc undid `/config` changes or discarded `/skills` changes.
- 🟡 (2.1.183) Removed the startup "setup issues" warning; its counts of settings, MCP, LSP, plugin, install, Chrome, sandbox and status line problems now go to the debug log with a pointer to `/doctor`.
- 🟡 (2.1.183) Fixed 400 errors when a disabled-thinking setting carries extra fields such as `display`: Claude Code now strips them before sending the request.
- 🟡 (2.1.183) Fixed WebSearch's inner search request: it now always forces the `web_search` tool with thinking off, where a remote switch decided before and the caller's thinking setting carried over otherwise.
- 🟡 (2.1.183) Fixed the native terminal cursor landing in the wrong place when part of the screen is reused from the previous frame; the renderer now records positions inside reused parts, which mouse clicks also use.
- 🟡 (2.1.183) Stopped fullscreen mode from using terminal scroll regions in Windows Terminal, detected by `WT_SESSION`, which WSL sessions also see.
- 🟡 (2.1.183) Added one automatic follow-up when a reply ends with thinking and no visible text, asking Claude to continue with a visible answer.
- 🟡 (2.1.183) Fixed skills listed twice when a plugin's skill is the same file as a user skill in `~/.claude/skills` or as another plugin's skill.
- 🟡 (2.1.183) Stopped MCP servers that need sign-in from giving Claude their sign-in tools in print mode and SDK sessions.
- 🟡 (2.1.183) Changed agent teams' tmux backend to launch each teammate by respawning a placeholder pane with its command, in panes that open without taking focus, instead of typing the command into a shell; the iTerm2 backend clears typed input before running it.
- 🟡 (2.1.183) Stopped killing the background shell commands of a teammate or background subagent when its turn ends; commands it moves to the background mid-run now count too and get the subagent time limit.
- 🟡 (2.1.183) Marked messages from scheduled triggers, webhooks and routines arriving through Remote Control, and scheduled prompts sent to in-process teammates, as task notifications instead of typed input; messages not typed by a person no longer count as your prompt for the rewind list, resuming an interrupted turn and similar checks.
