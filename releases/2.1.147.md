# 2.1.147 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Made `/logout` and `claude auth logout` revoke the saved claude.ai refresh token with Anthropic before signing out (5-second limit; if that fails, sign-out continues locally). Sessions on other providers and background sessions skip it.
- 🔴 Made Claude Code wait up to 5 seconds at startup for the organization's policy limits to load when none are cached yet, instead of loading them in the background; this covers API-key users and Team or Enterprise claude.ai sign-ins on Anthropic's API, but not `claude auth` commands.
- 🔴 Removed the Max-plan restriction on auto mode for Opus 4.6 and Sonnet 4.6 in Anthropic API sessions.
- 🔴 Changed `/resume` and `claude --resume` with no sessions in the current project to open the picker with "No conversations found in this project." and Ctrl+A to show all projects, instead of stopping at "No conversations found to resume."
- 🔴 Kept the 1M-context version of the model when resuming a session: if the current model setting is the `[1m]` variant of the model the session used, the restored model keeps `[1m]` instead of falling back to the standard window.
- 🔴 Added `/plugin configure <plugin>` (or `config`) to set a plugin's options; cancelling the form now says "Configuration cancelled." and saving nothing says "No configuration changes."
- 🔴 Changed the plugin options form to ask for every option that has no value, optional ones included (before, only missing required or invalid ones), and to open when you install a plugin that's already installed but has unset options; an optional field left empty that had no saved value is no longer saved, and "Run /reload-plugins to apply." appears only when something changed.
- 🔴 Made a session that restarts itself into a new process (after `/update`, a background-session respawn or moving it to the background) turn Remote Control back on at startup when the old process had a full Remote Control connection; before, the new process turned Remote Control on only when a flag or the `remoteControlAtStartup` setting asked for it.
- 🔴 Made the `claude agents` view respect the `tap` voice mode: holding Space on an empty prompt or reply no longer starts push-to-talk there, and the "hold space to speak" hint is hidden.
- 🔴 Changed auto mode's classifier rules: the hard block on getting around safety checks, renamed "Auto-Mode Bypass", now also covers jailbreaking the classifier and retrying a denied action another way, and drops the clause that blocked whenever the stated reason was a classifier outage or false positive; adding or widening allow rules the user didn't ask for now counts as self-modification.
- 🔴 Stopped auto mode from setting aside allow rules of the form `Bash(python -m package.module *)`, as it already kept `Bash(python -m package.module:*)`.
- 🔴 Stopped a file Claude edited earlier that can no longer be read (for example, permission denied) from breaking the rebuild of Claude's file-read state when resuming; the file is skipped.
- 🔴 Made resumed sessions tell Claude about skills that weren't in the session's earlier skill list; before, resuming suppressed the next skill listing entirely. New sessions record which skills were listed; older transcripts behave as before.
- 🔴 Changed `/compact` with too few messages to report "Not enough messages to compact." as its normal result instead of an error.
- 🔴 Fixed Cloud gateway sign-ins whose token refresh comes back with `refresh_token: null`: the reply was treated as malformed and the refresh kept failing; now the saved refresh token is kept.
- 🔴 Changed the agent-teams instructions to tell Claude to address active teammates by name and to resume a completed background agent by the `agentId` from its spawn result, instead of "never by UUID".
- 🔴 Added personal memory sync, which syncs a repository's auto-memory files with your account (matched by its github.com remote), leaving out team memory, logs, sessions and proposals, and refusing files that look like they contain secrets ("Memory is synced to your account"); behind a remote switch that's off by default.
- 🔴 Removed the "Searching past context" section (search the memory folder, then session transcripts as a last resort) from auto memory's instructions; it was behind a remote switch that's off by default.
- 🔴 Fixed `-p` sessions with text or JSON output throwing an uncaught error when a query ends without a result message; they now print "Error: No messages returned from query" and exit with code 1.
- 🔴 Changed voice input in the agents view and reply pane to check the current recording state before saving where to insert the transcript, instead of using the state from the last render.
- 🔴 Added `CLAUDE_BG_MEMORY_TOGGLED_OFF=1` handling for background sessions, which switches auto memory off at startup and carries that state through child sessions and restarts. The `/toggle-memory` command itself is disabled in this build.
- 🔴 Stopped URL-based plugin marketplace downloads from using hosts under `anthropic.com`, `claude.ai` or `claude.com`; the external-download client now refuses those hosts.
- 🔴 Changed team-memory path checks to normalize Unicode to NFC and ignore letter case, including the secret check before a file write or edit.
- 🟡 (2.1.108) Added the "Switch model?" confirmation to `/model <name>` when switching mid-conversation would lose the prompt cache ("Your next response will be slower and use more tokens"), as the `/model` picker already asked.
- 🟡 (2.1.105) Fixed sessions containing a text block whose text is missing, left by an interrupted stream: such blocks are dropped when a transcript loads or messages are merged, and token estimates no longer fail on them.
- 🟢 Made pinned background sessions in `claude agents` stay alive when idle, restart in place when Claude Code has been updated, and be retired under memory pressure only after unpinned sessions.
- 🟢 Rewrote the bundled `/code-review` (also `/simplify`) to look for correctness bugs in the current diff, or a given PR, branch or path, and report them without editing code (posting them as inline GitHub PR comments with `--comment`), where it used to clean up and fix the changed code. The level you pass (`low` to `max`) now sets how many review angles and findings it uses and runs the command at that effort (with no level, the review follows the session's effort, or medium), and passing one in an interactive session also stops Opus 4.7 from using its default effort over your saved `effortLevel`.
- 🟢 Stopped prompt history from recording a prompt identical to the previous one in the same project and session, unless pasted content is involved.
- 🟢 Fixed `&`, `<` and `>` in `!` command output showing as `&amp;`, `&lt;` and `&gt;` (in stderr especially); the output is escaped consistently in what Claude sees and unescaped for display.
- 🟢 Fixed unknown slash commands doing nothing in print and SDK sessions: they now return "Unknown command: /name" (with a suggestion when one is close) as the command's output and result.
- 🟢 Fixed `/help` on small terminals outside fullscreen, where its tab header broke and it showed only one command per page.
- 🟢 Fixed the shell snapshot leaving out shell functions whose names start with a single underscore (such as scm_breeze's `_safe_eval`), which broke aliases that call them.
- 🟢 Fixed agent definitions that list several `Agent(...)` entries in `tools` keeping only the last one; all listed agent types now count, and empty names are ignored.
- 🟢 Fixed the PowerShell tool losing output from commands that rely on PowerShell's default formatting, by ending with `$host.SetShouldExit` instead of `exit` in full language mode (the tool is opt-in on Linux with `CLAUDE_CODE_USE_POWERSHELL_TOOL`).
- 🟢 Made a PowerShell allow rule whose text matches the whole command count even when the command runs a script or external program, so a rule saved for a script invocation applies on later runs.
- 🟢 Fixed `/effort` opening with the slider on the wrong level; it starts at your current effort.
- 🟢 Fixed pasted text sent to a running agent or a teammate arriving as a `[Pasted text #N]` placeholder; the pasted content is now included.
- 🟢 Fixed a plugin's skills and commands being listed twice, doubling its counts, when its manifest names paths that overlap its default folders.
- 🟢 Fixed slash commands followed by a tab or a new line being treated as unknown commands; the name now ends at the first whitespace and arguments are trimmed.
- 🟢 Fixed spacing and text wrapping in the `/plugin`, `/status`, `/mobile`, `/sandbox` and `/permissions` screens.
- 🟢 Changed the note Claude gets when the API couldn't process an image or document: it now says the file may be unsupported or corrupt, not to read it again, and to use a shell command to inspect it, instead of "Re-read the original file if you need its contents."

- 🔴 Let async hooks that wake Claude (`asyncRewake`) put a `rewakeSummary` in their JSON output, used as the summary of the hook feedback Claude gets (cut at 300 characters); only hooks from plugins in Anthropic's own marketplaces get this.
- 🔴 Changed team memory sync (behind a remote switch, off by default): it stops syncing when the team memory folder or a `CLAUDE_MEMORY_STORES` mount resolves, through a symlink for example, outside its expected place; it drops pending deletes of entries changed on the server meanwhile; and a `CLAUDE_MEMORY_STORES` value that yields no stores counts as unset.
- 🔴 Updated the bundled axios HTTP library from 1.13.6 to 1.15.2: when no `HTTPS_PROXY` or `HTTP_PROXY` is set, its own proxy lookup no longer reads `npm_config_*_proxy` or `npm_config_no_proxy` (only `*_proxy`, `all_proxy` and `no_proxy`); it also limits form data nesting to 100 levels and checks Unix socket paths.
