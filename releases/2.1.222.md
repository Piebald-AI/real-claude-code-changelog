# 2.1.222 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Added a notice when a `/btw` side question, or an agent forked from one, is answered by a fallback model after a flagged message: "… This response was generated by <model> instead. Your session model is unchanged." It shows above the answer, stays in `/btw` history and starts the forked agent's result; SDK hosts get it as a `refusal_fallback` field on the side-question reply, and SDK model-switch messages gained a `scope` field (`"session"` when the main session switched).
- 🔴 Fixed the main session's model-switch notice being lost when a fallback chain ended with an API error before producing a reply.
- 🔴 Changed subagent result collection to skip discarded replies and whitespace-only text, using the latest remaining answer instead of returning discarded or blank output.
- 🔴 Added a note to `/status`'s Model row and `/model`'s current-model line while the session runs on the model it switched to after a flagged message: "(automatically switched from <model> after a message was flagged — run /model to switch back)".
- 🔴 Stripped all terminal escape codes from tool error messages before showing them (before, only underline codes were removed), and from auto mode denial reasons.
- 🔴 Made Remote Control rebuild its connection when presence heartbeats keep failing while messages still arrive (three or more failures spanning at least 30 seconds), at most three times an hour before stopping with "presence heartbeats to the server kept failing after repeated reconnects" (remote switch, on by default).
- 🔴 Kept a Remote Control session marked as waiting on you while a permission or question prompt sent to it is pending, instead of switching it to running when queued messages go out, and reported it as waiting again after a reconnect.
- 🔴 Made Remote Control tell the sending device when it drops a message without a valid device signature ("This message arrived without a valid device signature … and was not executed."), with a hint to re-pair or re-enrol the device. It deduplicates recent message IDs and sends up to ten warnings a minute followed by one notice that further warnings for the burst are suppressed, instead of warning only in the terminal.
- 🔴 Added `x` to `/artifacts` to remove an attached artifact from the session's list ("Dismissed … from this session's list"), and marked attached rows "attached".
- 🔴 Changed the footer's artifact strip to label hidden artifacts "+N more" and to add "/artifacts to see all" when names don't fit.
- 🔴 Added an optional footer indicator whose text comes from account data the server sends, shown after a filled diamond and cut to six columns; nothing appears unless the server sends one.
- 🔴 Changed Artifact comment auto-replies to answer the human comments viewers sent to Claude, including existing comments sent again, and marked those comments "sent to you" or "awaiting reply" in the Artifact tool's comment list, which now lists their threads first (`CLAUDE_CODE_ARTIFACT_COMMENTS_AUTOREACT` or a remote switch, off by default).
- 🔴 Changed the claude.ai plugin and skill list and search tools to return an empty result for a 403 response with the expected error object (not entitled), instead of failing; malformed responses still fail.
- 🔴 Cleaned and capped agent-team message summaries, recipients and failure reasons at 200 characters in message previews and normal display, and capped summaries in the receiving agent's message headers; verbose inbox display can still show the full summary. Teammate names in headers now use letters, digits, `.`, `_` and `-`, shorten to 20 characters plus an ellipsis, and fall back to "teammate" or "agent" when empty; only the eight subagent colors pass into a message.
- 🔴 Listed `claude import` in `claude --help` for everyone; while its remote switch is off it prints "`claude import` is not yet available in this build. …", and it now accepts global options before `import`.
- 🔴 Made `/import` from Codex skip skills that wouldn't load or would act as plugins: SKILL.md files over the size limit or starting with `---`, and skill folders containing `hooks`, `agents`, `monitors`, `workflows` or other plugin folders. The import also skips subagents with an unfinished shell-execution marker or a mix of argument placeholders and text that could form one; it's behind a remote switch that's off by default.
- 🔴 Changed the terminal attached to a cloud session to show the session's tool results for every viewer, not only read-only ones, and dropped its separate "Permission denied: …" lines.
- 🔴 Changed background sessions' shell handoff to link eligible output files into the receiving project's temporary folder, with a copy fallback limited to 64 MiB. It drops shells when an output resolves outside the permitted task-output tree or the copy fallback would exceed that limit.
- 🔴 Changed Codex imports to report nonempty `[skills]` tables with no `config` key and malformed `[features]` values for manual review, instead of quietly skipping them (remote switch, off by default). A malformed `project_doc_fallback_filenames` now triggers the unsupported-settings notice instead of being dropped quietly.
- 🟡 (2.1.287) Fixed a successful empty MCP tool refresh being treated as still unauthorized after an earlier discovery failure, so tools the connector removed now disappear from the session.
- 🟡 (2.1.288) Fixed Remote Control reporting a failed connection when its transport closed during a scheduled token refresh; it now finishes the refresh before deciding whether the close still needs recovery.
- 🟢 Extended worktree checks to every session type: file edits and Bash/PowerShell working directories are checked against the main checkout, Bash git redirects into it are rejected, and worktrees are checked before entry, resume or adoption. Resuming into a deleted worktree continues without isolation and says so; one that can't be checked aborts a print-mode resume.
- 🟢 Stopped a PreToolUse hook's "allow" from skipping the tool restrictions of background forks such as summaries, compaction and session renames.
- 🟢 Fixed `/usage-credits` on Team and Enterprise treating a dismissed earlier request as still pending, which blocked sending a new one.
- 🟢 Made the startup connectivity check use the configured proxy and give up after 10 seconds, pointing to the network settings docs when a proxy was in use.
- 🟢 Stopped reporting a cut-off response when the connection closed after the response had already finished.
- 🟢 Changed `/usage` to count an MCP server's share only from the request that consumed its tool result, not every later turn.
- 🟢 Added pull-request linking for branches pushed before their pull request existed: Claude Code checks again on the next five successful foreground git, gh, glab or curl commands in that folder, unless only essential network traffic is allowed. Commands sent to the background no longer trigger pull-request linking.
- 🟢 Changed subagents and agent-team teammates whose model alias (such as `opus`) isn't allowed by `availableModels` to try the newest allowed model of that family before falling back to the parent's or the default teammate model.
- 🟢 Extended the raw-byte stream watchdog to gateways and custom endpoints configured with `ANTHROPIC_BASE_URL` or, for Claude Platform on AWS, `ANTHROPIC_AWS_BASE_URL`, so keep-alive pings count as activity there.
- 🟢 Changed claude.ai connectors to distinguish a rejected session token when a 401 can't be resolved by refreshing to a different token: they show "connected · session token rejected" in `/mcp`, or fail with "claude.ai rejected the session token … Run /login.", instead of being marked as needing authorization. When the retry with a refreshed token fails, it now reports that error instead of replacing it with the original 401.
- 🟢 Fixed tool errors not rendering when the tool is no longer available, for example after its MCP server was removed.
- 🟢 Changed `SendMessage` to cut summaries longer than 200 characters instead of rejecting them; recipients must be a single line.
- 🟢 Sent `SendMessage` calls through auto mode's permission classifier instead of allowing them outright.
- 🟢 Fixed a subagent's spinner showing the session's effort level; it now shows the subagent's own effort for its own model, following model switches.
- 🟢 Fixed crashes when the file watcher hit an error with no listener, or closed a watcher that never started.
- 🟢 Made screen-reader mode (`--ax-screen-reader`) echo only the deleted characters for deletions at the end of the line instead of rereading the line.
- 🟢 Told Claude, when a skill has `disable-model-invocation`, to ask the user to run it and not to recreate its workflow by other means.
- 🟢 Ran the git diffs behind `/diff`, the workspace diff sent to Remote Control and SDK hosts, and file-edit diffs in cloud sessions with `--no-ext-diff --no-textconv`, so configured diff tools and textconv filters no longer change them.
- 🟢 Stopped `remoteControlAtStartup: true` in project or local settings from starting Remote Control (it's ignored with a debug note); `false` there still turns it off.
