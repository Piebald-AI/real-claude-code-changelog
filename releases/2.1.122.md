# 2.1.122 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Fixed resumed sessions losing their earlier messages when the transcript names a parent message that isn't in the file: the loader now reads the whole file in that case instead of stopping at the gap, and tool results are no longer saved pointing at an assistant message that was never written.
- 🔴 Saved the title Claude Code generates for a session (the one it puts in the terminal tab) into the transcript and used it wherever you haven't named the session: the `/resume` list, its search and autocomplete, `--resume <title>`, the session name shown where "/rename to add a name" used to appear, and the status line's `session_name`. A name generated when you accept a plan is now stored the same way instead of as a custom name. Sessions started with an agent type no longer get a generated title (the terminal title falls back to the agent type), and a title that arrives after you've switched to another session is dropped.
- 🔴 Made `--resume` refuse a session that's currently running as a background agent, with "Use `claude agents` to find and attach to it, or add --fork-session to branch off a copy."; in print mode, `--continue`, `--resume` and `--teleport` also clear cached session state before loading.
- 🔴 Made the Bash read-only check ask about more commands: `test`, `[` and `[[` with `-t` or arithmetic comparisons whose operands aren't plain numbers, `-v`/`-R` and `find` arguments built from variables or command substitution, and docker's read-only commands given `-H`/`--host`, `-c`/`--context`, `--config` or a TLS flag, or (for `docker ps` and `docker images`) an argument built by command substitution, which also stops those calls running in parallel or speculatively. It also recognizes more `find` options that take a value, such as `-files0-from` and `-xattrname`, so their values aren't mistaken for actions. And it stopped mistaking literal `-v…` or `-R…` arguments for combined flags in `test`, `[` and `[[`, so an existing allow rule now covers them without an extra prompt.
- 🔴 Made `CLAUDE_CODE_BLOCKING_LIMIT_OVERRIDE` trigger auto-compaction and the context warning as soon as its limit is reached, even when that limit is below the usual warning and compaction thresholds.
- 🔴 Changed how `serverUrl` patterns in `allowedMcpServers`/`deniedMcpServers` and entries in `allowedHttpHookUrls` match: scheme, host, port and path (with any query) are compared separately, so a `*` can no longer stretch from the host into the path, and a pattern with no path or query, such as `https://example.com`, matches every path on its host.
- 🔴 Made whole-tool `Bash` and `WebFetch` deny and ask rules (ones without a pattern in parentheses) and hook matchers also apply to `mcp__workspace__bash` and `mcp__workspace__web_fetch`, the tools of a `workspace` MCP server supplied by an SDK host.
- 🔴 Cleared a saved OAuth refresh token once the server rejects it as `invalid_grant`, for claude.ai sign-ins and for workload identity user sign-ins kept in a token file, so the dead token isn't offered again.
- 🔴 Made the `awsAuthRefresh` command run once for concurrent requests and not again within 30 seconds of a refresh; changing settings resets that wait.
- 🔴 Made the cloud environment lookup used when starting a cloud session refresh the claude.ai sign-in and retry once after a 401, instead of failing.
- 🔴 Made an atomic file write delete the half-written file when its fallback copy fails on a full disk, a quota or an I/O error (`ENOSPC`, `EDQUOT`, `EIO`, `EFBIG`), instead of leaving a truncated copy.
- 🔴 Made `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` (or `false`) keep the simpler system prompt off even when a remote switch would turn it on.
- 🔴 Added a double press of Ctrl+L or Cmd+K to run `/clear` in fullscreen mode ("Press … again to /clear"), with Cmd+K bound to a new `chat:clearScreen` action; in iTerm2 and Apple Terminal, a screen the terminal wiped by itself is now detected, repainted and counted as the first press.
- 🔴 Made the cursor treat `[Pasted text #N +M lines]` and `[...Truncated text #N +M lines...]` placeholders as single units when moving, selecting and deleting, as it already did for `[Image #N]`; before, only Backspace right after one removed it whole.
- 🔴 Changed Bash and PowerShell to tell Claude "[Request interrupted by user for tool use]" only when you cancelled the command; a command stopped because a parallel tool call failed, or because it moved to the background, now reads as an ordinary failure.
- 🔴 Changed a shell that can't start a command to report an ordinary failure (exit code 1 with the error) instead of an interrupted command with exit code 126.
- 🔴 Made the REPL tool (on with `CLAUDE_CODE_REPL`) pass up to 8 images from its inner `Read` calls back to Claude as images, with the text beside them capped at 100,000 characters by default.
- 🔴 Fixed a skill's added messages being tied to the first Skill call of a response when Claude ran more than one skill in the same response.
- 🔴 Added an "investigate before asking" instruction for Claude Opus 4.7 that tells it to spend up to a minute on read-only investigation before asking a clarifying question, with a `compact` form that also shortens the "Executing actions with care" guidance; it's off by default and set with `CLAUDE_CODE_INVESTIGATE_FIRST` (`additive`, `compact` or `off`) or a remote switch. The remote switch is ignored while the simpler system prompt is on; an explicit `CLAUDE_CODE_INVESTIGATE_FIRST` choice still takes precedence.
- 🔴 Removed a remote experiment (`tengu_pewter_ledger`, off by default) that replaced plan mode's final-plan instructions with shorter plan formats.
- 🔴 Let a remote switch (`tengu_new_init`, off by default) turn on `/init`'s newer flow, which creates CLAUDE.md files plus optional skills and hooks and which only `CLAUDE_CODE_NEW_INIT` turned on before.
- 🔴 Raised the bar for Claude's end-of-task offer to `/schedule` a follow-up agent from 70% to 85% odds that you'd accept (the offer sits behind a remote switch that's off by default).
- 🔴 Added `CLAUDE_COWORK_MEMORY_INDEX_CONTENT`, replacing `CLAUDE_COWORK_MEMORY_SKIP_DEFAULT_ENTRYPOINT`: unset loads `MEMORY.md` as before, an empty value skips it, and any other value is used as the memory index instead of the file.
- 🔴 Made cloud session creation itself check the organization's `allow_remote_sessions` policy, failing with "Remote sessions are disabled by your organization's policy."
- 🔴 Made teleport refuse a branch name from the remote session that isn't a safe git ref name (one starting with `-` or `/`, containing `..`, or using characters other than letters, digits and `/._+@-`), with "Invalid branch name from remote session".
- 🔴 Fixed caching a plugin marketplace failing when its download folder and its cache folder are the same folder on disk; the folder was deleted before the rename.
- 🔴 Made cloud sessions, and Remote Control's newer bridge, try registering their worker three times with a short backoff before failing; before, the first failed attempt ended their start.
- 🔴 Changed `claude --bg` to add piped stdin to the prompt (cut after 1,048,576 UTF-16 code units, with a warning), report "(idle — attach to send a prompt)" when started without a prompt, refuse bypass permissions or auto mode unless their opt-in is already set (for example by accepting them once interactively, by the permission-prompt settings, or for auto mode by an administrator's `permissions.defaultMode: auto`), and recognize more flags as taking a value, such as `--name`, `--max-turns`, `--plugin-dir` and `--tools`.
- 🔴 Made background sessions keep `/add-dir` folders and permission-mode and model changes across worker restarts and resume the right conversation; a crashed worker now shows "[worker crashed (…) — respawning…]", and one that ignores SIGTERM is killed after 5 seconds.
- 🔴 Made a background worker whose saved state still says starting, resuming, adopted or crashed report itself running and idle once its terminal interface is ready, unless it's active or blocked, and stopped the background classifier from starting a second auto-naming request for a job while one is pending.
- 🔴 Made Ctrl+Z detach from an attached background session, recognized Ctrl+Z and Ctrl+B in the kitty and `modifyOtherKeys` key encodings, and on detach also switched off terminal modes the session turned on while you were attached (mouse reporting, focus events, bracketed paste), not only those that were on when you attached.
- 🔴 Changed `claude agents` to group sessions by local repository folder instead of remote repository name and show a working session's latest output line, with failed tool results marked ✗; the Space hint now says "reply", and reply errors appear under the row; when a requested job isn't listed, the view selects its normal default row and follows the job or group chosen that way.
- 🔴 Made the background service report a spawn failure it used to miss and remove stale socket files. A claimed pre-warmed worker is now resized to the launching terminal at once (200 by 50 when no size is given), a respawned session that claims one reconnects to its Remote Control session with the same variables a fresh worker gets, and the daemon stops an existing spare once pre-warming's remote switch is turned off. The daemon also saves a claimed pre-warmed worker in its worker list even when reading the process's start time fails, so a daemon restart can still find it. Socket setup no longer counts toward a spare's two-second lifetime check, so slow preparation doesn't get a spare that crashes at once replaced automatically.
- 🔴 Made background-session commands wait up to 1.5 seconds (was 0.3) for remote settings before deciding whether the feature is on, and changed the refusal to "'<command>' is not enabled. If this is unexpected, retry in a moment."
- 🔴 Added `DISABLE_BRIEF_MODE_STOP_HOOK` to turn off the stop hook brief mode adds to the main conversation.
- 🔴 Added a "Daemon" section to `/debug`'s prompt with the background daemon's lock and status files, the last 20 lines of its log and where its worker roster and job state live. In the existing session debug log section, a missing log now reads "No log file exists yet." instead of saying logging was just enabled, and other read failures no longer say "of debug log".
- 🔴 Reworded the `/model` note for a session-only model to "Currently using X for this session only." (it said "(set by plan mode)").
- 🔴 Rearranged the right side of the prompt footer so notifications sit above the Remote Control indicator and mode labels.
- 🔴 Showed the fast mode tag on the coloured banner line above the prompt; before, the tag didn't show while a banner was displayed.
- 🔴 Made the memory survey close itself after 60 seconds, reported as a "timeout" in its telemetry and in the OpenTelemetry `feedback_survey` event.
- 🔴 Added the task id to the title of an MCP server's input request when the request belongs to a task.
- 🔴 Fixed the Skill permission dialog showing no skill name when the Skill input can't be parsed; it now falls back to the command's name.
- 🔴 Stopped `n` from going back in the `/plugin` screens; only Escape does now, and a custom `confirm:no` binding there follows the "Settings" keybinding context.
- 🟡 (2.1.141) Made claiming a pre-warmed background session fall back to starting a fresh one instead of failing with "The pre-warmed session wasn't ready — press Enter to try again".
- 🟡 (2.1.128) Reserved the MCP server name `workspace`: `claude mcp add` refuses it, and a server with that name in a config file is skipped with a warning unless an SDK host supplies it.
- 🟢 Added `ANTHROPIC_BEDROCK_SERVICE_TIER`, sent as the `X-Amzn-Bedrock-Service-Tier` header on Bedrock requests and shown in `/status`.
- 🟢 Made a pull request URL pasted into the `/resume` search find the session that created that pull request.
- 🟢 Added claude.ai connectors hidden by a manually added server with the same URL to `/mcp`, with advice for removing the duplicate that depends on where it's configured.
- 🟢 Reworded the messages shown after an MCP server's browser sign-in when the server is still unauthorized, rejects the new credentials or can't reconnect.
- 🟢 Changed OpenTelemetry `api_request`, `api_error` and `api_retries_exhausted` events to send their numeric attributes as numbers rather than strings.
- 🟢 Added an OpenTelemetry `at_mention` event carrying a mention's kind and resolution status, for file, agent and MCP-resource resolution and successful directory reads. Some skipped attachments and failed directory reads don't emit it.
- 🟢 Fixed `/branch` copying messages from rewound timelines into the fork, which made the fork fail with "tool_use ids were found without tool_result blocks"; it now copies only the current conversation.
- 🟢 Fixed Bedrock application inference profiles using the wrong model capabilities and request effort by saving their backing-model lookup, now with an 8-second timeout. The model picker starts this lookup for a selected name containing `application-inference-profile`, even outside Bedrock, but can keep showing "Effort not supported" after it finishes until you switch the selection or reopen the picker.
- 🟢 Stopped sending a structured-output `format` where it isn't supported (Bedrock, Vertex, Claude 3 models, `claude-opus-4-0`, `claude-sonnet-4-0`), which Bedrock and Vertex rejected with "Extra inputs are not permitted"; session titles, prompt-type hooks and other structured-output requests now go without it there.
- 🟢 Fixed token counting on Vertex behind a proxy gateway failing with 400 errors: betas token counting doesn't take are now filtered out on every provider, and the OAuth beta is kept.
- 🟢 Made `spinnerTipsOverride` with `excludeDefault: true` also hide the built-in tips that depend on context and time, such as the `/clear` and `/btw` suggestions.
- 🟢 Fixed ToolSearch and tool lookups missing MCP tools that connected after the session started.
- 🟢 Fixed `!exit` and `!quit` in bash mode quitting Claude Code instead of running as shell commands.
- 🟢 Lowered the image size limit for Claude Opus 4.7 from 2576 to 2000 pixels per side.
- 🟢 Fixed Remote Control redrawing its idle status line over and over.
- 🟢 Fixed assistant messages appearing blank when a saved brief-only view stayed on after brief mode became unavailable.
- 🟢 Fixed a malformed `hooks` value or hook event in a settings file discarding the whole file; only the bad entry is dropped now, with a warning.
- 🟢 Made keybindings to Caps Lock (`capslock`, `caps`, `caps-lock`, `caps_lock`) an error, since terminals don't deliver it.
