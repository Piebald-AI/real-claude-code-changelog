# 2.1.140 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Stopped sandbox cleanup from deleting a `hooks` or `config` file or folder created at the top of the working directory, and from recursively deleting a newly created `HEAD` directory. It still removes new `HEAD` files and new `objects` or `refs` paths (which could make the folder pass for a bare git repository), now also removes a newly planted `.git` file, and blocks writes to an existing `.git` file.
- 🔴 Made shutting down the sandbox close its network proxies' open connections and force-stop its Linux bridge processes after 1.5 seconds instead of 5, so a lingering proxy connection no longer holds the shutdown open.
- 🔴 Fixed the agents view skipping a later automatic relaunch when an update was ready before the six-hour delay after its previous relaunch had ended: it now rechecks that delay hourly while the terminal is unfocused, and still waits for an hour without input.
- 🔴 Made relaunching Claude Code (switching the terminal renderer, reattaching a Remote Control session, opening the agents view) replace the running process instead of starting a child process, falling back to a child process if that fails.
- 🔴 Made the context estimate for messages since the last API response count one token per 3 characters instead of 4 on any model outside a list of older ones (Claude 3 through the 4.6 generation and Haiku 4.5), such as Opus 4.7 or a model name Claude Code doesn't recognise, so auto-compaction and the hard context-limit stop both come a little sooner on them.
- 🔴 Added a progress bar with an estimated percentage under the spinner while a conversation is being compacted, on terminals wide enough to show it.
- 🔴 Started preparing a recovery-compaction summary in the background on one-million-token models with the default compaction window, at the earlier of 90% of the effective window or the ordinary compaction threshold, behind two remote switches that are off by default; the conversation itself isn't compacted at 90%. `CLAUDE_CODE_BLOCKING_LIMIT_OVERRIDE` also no longer starts that preparation before the compaction threshold.
- 🔴 Showed the full text of ordinary teammate messages in the main conversation, not just in transcript view, and rendered their Markdown.
- 🔴 Stopped counting ongoing `/loop`, routine and scheduled-task sessions as completed in the agents view after a successful turn, and stopped putting them in the pull-request review group.
- 🔴 Made the agents-view heading follow the folder selected for new work, including an `@repository` choice, instead of always showing the launch folder.
- 🔴 Added submitting the prompt by double-tapping the voice key after a hold-to-talk dictation that didn't submit itself.
- 🔴 Added `CLAUDE_CODE_RESUME_PROMPT` to replace the "Continue from where you left off." message sent when a session resumes an interrupted turn.
- 🔴 Made Remote Control enroll the device as a trusted device with your login when your organization requires trusted devices and the device isn't enrolled, before refusing to connect, unless automatic enrollment is turned off.
- 🔴 Changed auto mode's Self-Modification rule to list the config it covers (such as `.claude/settings*.json`, `CLAUDE.md`, `.mcp.json` and the `.claude/` folders for rules, hooks, commands, agents and skills) and to treat files under `.claude/worktrees/` as ordinary project files.
- 🔴 Added the user's name (from `GITHUB_ACTOR`, `USER`, `USERNAME`, or the part of git's `user.email` before the @) to auto mode's classifier, so rules about `$USER/...` branches can tell this user's branches from other people's.
- 🔴 Changed the Agent tool's "Do not spawn agents unless the user asks" instruction to apply to every Pro subscriber, where a remote switch that's off by default or `CLAUDE_CODE_AGENT_COST_STEER` used to decide; the variable no longer does anything.
- 🔴 Moved the guidance on when to delegate to a subagent or fork from the system prompt into the Agent tool's description in the shorter system prompt (`CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT` and the models that use it by default).
- 🔴 Changed the result of a Bash or PowerShell command that Claude sends to the background to tell it that it will be notified when the command finishes and can read the output file in the meantime; a command you background yourself keeps the old result.
- 🔴 Added `docs.getdbt.com` to the sites WebFetch can read without asking.
- 🔴 Reserved the marketplace name `anthropic-agent-skills` for Anthropic's GitHub repositories (it auto-updates by default and its plugins count as official), and reserved the name `skills-dir`.
- 🔴 Made `claude plugin` install, uninstall, enable, disable and update, and `/plugin`, refuse plugins loaded with `--plugin-dir`, explaining how to stop loading them; `enabledPlugins` entries left over from `--plugin-dir` plugins (marketplace `inline` or `skills-dir`) are now ignored instead of being reported as missing plugins or as blocked by a marketplace policy.
- 🔴 Made `/tasks` open while Claude is responding.
- 🔴 Stopped closing the `/tasks` dialog from adding a "Background tasks dialog dismissed" line to the conversation.
- 🔴 Changed `/ultrareview` to stop with a message that it's unavailable on third-party providers whenever Claude Code isn't using the Anthropic API (Bedrock, Vertex, Foundry, Claude Platform on AWS or a gateway), where it used to ask for a Claude.ai login or go ahead.
- 🔴 Changed Claude FM (the `/radio` command, behind a remote switch that's off by default) to open `https://clau.de/radio` instead of a YouTube live stream.
- 🔴 Added a coloured health dot after plugin names in `/plugin`, from a skill-health service behind a remote switch that's off by default.
- 🔴 Changed the bundled Bun runtime from `1.3.14+99ab292b9` to `1.3.14+d29891451`: about 1 KB more native code, no new sections or command-line options, a new `BUN_CONFIG_HTTP_IDLE_TIMEOUT` variable, and changes to Bun's built-in `node:http` client request code (when `finish` and `close` fire, 304 handling, and starting the request after the first write).
- 🟡 (2.1.85) Fixed enabling a built-in plugin that an organization disabled in managed `enabledPlugins` settings.
- 🟡 (2.1.144) Made `claude --continue` and `claude --resume` carry on with the model of the conversation's last reply when no model is set by `--model`, the agent, `ANTHROPIC_MODEL` or the `model` setting (which `/model` saves), as long as it's a model Claude Code offers, on the Anthropic API, Claude Platform on AWS and gateways.
- 🟡 (2.1.142) Added `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE`, which keeps fast mode on Opus 4.6 even when `CLAUDE_CODE_ENABLE_OPUS_4_7_FAST_MODE` is set.
- 🟢 Made the Agent tool try Unicode, case and separator normalization when a `subagent_type` doesn't match an available name as written: a full-name match still wins, and otherwise several normalized matches are refused with their names.
- 🟢 Changed the blue, purple, orange and pink that tell subagents apart in the default dark and light themes to softer shades; the ANSI and colour-blind themes keep theirs.
- 🟢 Made `/goal` refuse with a clear message when hooks are turned off by `disableAllHooks` or `allowManagedHooksOnly`, in settings or by policy, instead of setting a goal whose hook can't run.
- 🟢 Made `claude --bg` hold the background service open while it hands a session over, so the dispatch no longer fails with "connection dropped mid-request" when the service was about to exit for being idle; a service that's still starting is now reported as "service still starting" instead of a missing socket.
- 🟢 Gave the background service 20 seconds instead of 10 to become reachable when it starts.
- 🟢 Made fetching remote managed settings retry once with a refreshed login after a 401.
- 🟢 Made a marketplace's `autoUpdate` from `extraKnownMarketplaces` settings get saved to the installed marketplace record at startup and shown in `/plugin`, whose toggle now refuses to change it when managed settings, `--settings` or an `--add-dir` directory sets it.
- 🟢 Changed the `/loop` self-pacing instructions to tell Claude not to schedule short wakeups to poll for background work that will notify it, and to set a long fallback of 20 minutes or more instead.
- 🟢 Made numeric tool inputs written as text accept surrounding spaces and a leading plus sign, including the Read tool's `offset`.
- 🟢 Fixed the terminal's own cursor not staying at the input caret when the terminal loses focus; it's now hidden only while Claude Code draws its own cursor there.
- 🟢 Added plugin notes for a default folder (`commands/`, `agents/`, `output-styles/`, `themes/`) that plugin.json overrides, with a fix suggestion, shown in `/plugin`, `/doctor`, `claude plugin list` (a `notes` field in its JSON), the SDK's init message and the debug log; plugin.json's field descriptions now say a set path replaces the folder.
- 🟢 Fixed settings hot-reload reporting an edit to one settings file as a change to another when that other file is a symlink to it, which ran `ConfigChange` hooks for the wrong settings source.
