# 2.1.157 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Added a silent retry after a safety-filter refusal for sessions on the default Opus model, turned on by a server-side setting (`convolute_arcades` in the account's client data): the message is sent again on the same model, without switching models or showing the fallback notice, and later requests in the session carry an `x-is-refusal-fallback: true` header.
- 🔴 Changed history navigation in the prompt: up or down on the first or last line now goes straight to the previous or next prompt instead of first moving through wrapped rows, and a recalled prompt puts the cursor at its end rather than its start; `k` and `j` in vim normal mode work the same way. Before, a remote switch that was off by default turned this on.
- 🔴 Added a "History N/M" label to the prompt's border while you browse this project's earlier prompts, behind a remote switch that's off by default.
- 🔴 Made submitting a prompt reset history browsing right away, so pressing up while a slash command or `!` shell command is still running starts from your newest prompt instead of carrying on from wherever you'd browsed to before submitting.
- 🔴 Added a feature-of-the-week offer, configured remotely and off unless Anthropic sets it: the welcome screen shows "Feature of the week: /<command> — …" with the usage credits you get for running it, a redeem-by date and a link to the promotion terms, and a spinner tip mentions it; the offer can name any command, where the credit claim used to cover only `/loop`, `/review` and `/security-review`.
- 🔴 Stopped a slow feature-of-the-week eligibility refresh from overwriting newer cached information, such as a claim's unavailable result, so an earlier response can't make the command look eligible again.
- 🔴 Moved the guest-passes promotion ("3 guest passes at /passes", or the usage credits you can earn by sharing) from the welcome screen to the startup notices, shown at most three times and not while a feature-of-the-week offer is live.
- 🔴 Stopped the welcome screen and company announcements from showing the name and organization of a saved claude.ai account while you're signed in another way.
- 🔴 Hid notices that a background task was killed and left subagents out of the footer's background-task indicator in interactive sessions, behind a remote switch that's on by default; before, only fork-subagent mode (`CLAUDE_CODE_FORK_SUBAGENT` or a remote switch that was off by default) did this.
- 🔴 Let project and local settings set `autoMemoryDirectory` once you've accepted the workspace trust dialog, and in non-interactive sessions; managed settings and `--settings` still win, and user settings come after.
- 🔴 Made git commands ask for permission when the working directory or a parent folder has a `.git` file larger than 4 KB, counting it as a sign of a bare repository like the layouts these checks already catch.
- 🔴 Added `.envrc` files and `.cargo` folders to the paths whose edits always ask for permission, alongside files such as `.bashrc` and folders such as `.git`.
- 🔴 Changed the Bash permission analysis to treat `declare`, `typeset` and `local` with `-E` or `-F` as too complex to approve (like `-n`, `-i`, `-a` and `-A`), to treat more shell variables that change on their own (`pipestatus`, `BASH_SOURCE`, `DIRSTACK`, `GROUPS`, `BASH_ARGV`, `BASH_ARGC`, `BASH_SUBSHELL`, `BASH_LINENO`) as unknown, to count variables set in a `while` loop's condition as changing between iterations, and to recognise a `#` comment that starts a later line after any whitespace, not only spaces and tabs.
- 🔴 Stopped treating `ss -r` and `ss --resolve` (which look addresses up in DNS) as read-only, and made `man`'s check treat arguments after a lone `-` as possible file paths.
- 🔴 Kept Bash commands that mention `/proc/…/environ` out of the sandbox's automatic approval even when quotes or backslashes break up the path, so they get the normal permission check.
- 🔴 Changed PowerShell permission checks to decode backtick `` `u{…} `` escapes, compare paths with Unicode-aware lowercasing, count a path value attached as `-Name:@…` as one it can't check (before, only `@{…}`), stop treating `git` and `docker` commands as read-only when an argument starts with an en dash, em dash or horizontal bar, and block `Remove-Item` in a command that can't be parsed whenever a protected system path appears anywhere in it.
- 🔴 Stopped following CLAUDE.md `@` imports at paths that start with two slashes or backslashes (network-share paths), except WSL paths, and stopped NotebookEdit's preview from reading a notebook at any such path.
- 🔴 Stripped terminal escape sequences from the tool input that permission prompts show for tools the local client doesn't know, in remote and direct-connect sessions.
- 🔴 Stopped falling back to OAuth for HTTP and SSE MCP servers that have an `Authorization` header configured, and hid `/mcp`'s authenticate options for them: a 401 or 403 now fails the connection with "Server rejected the configured Authorization header … OAuth fallback is disabled when headers.Authorization is set."
- 🔴 Made the event-stream request of HTTP MCP servers use your proxy settings (`HTTPS_PROXY`, `HTTP_PROXY` or their lowercase forms) and certificate options, as the connection's other requests already did; Claude Code now adds them to every request the connection makes.
- 🔴 Changed plugin suggestions in `/plugin` Discover to say why a plugin is suggested ("suggested for `<command>` commands", "suggested for <host>", "suggested for <file>", "suggested from <manifest>" or "suggested for this directory"), using the commands and hosts seen in the session, and to suggest each plugin this way only the first time Discover shows it.
- 🔴 Removed the bundled `autopilot`, `bugfix`, `dashboard`, `docs` and `investigate` dynamic workflows, which only cloud sessions had.
- 🔴 Added rules to auto mode's safety classifier for changes to persistent configuration (forwarding rules, sharing grants, webhooks, account security settings), messages and submissions that reach other people, destinations that appear only in page or tool content, and low-information actions such as clicks, which it now reads through what the agent just said it would do.
- 🔴 Changed the bundled `claude-api` skill's migration guide and tool-use notes to recommend tool descriptions that say when to call the tool, which they say helps Opus 4.8 and other recent Opus models.
- 🔴 Made `/commit` and `/commit-push-pr` escape the commit attribution text, and `/commit-push-pr` also the PR attribution and the instructions you add, so a `!` in them can't run a shell command when the prompt is built.
- 🔴 Made a failed worktree creation remove the half-made worktree, and dropped git's progress lines from worktree error messages.
- 🔴 Made fast mode report "Checking fast mode availability" and stay off until your organization's fast-mode status has loaded, instead of counting as available meanwhile. A `fastMode: true` in `--settings` skips that wait and keeps fast mode available when the status check fails with a network or unknown error, and with nonessential traffic off the status now comes from the last saved organization setting.
- 🔴 Changed the automatic start of Claude in Chrome, which a remote switch turns on: it now needs a claude.ai login, is skipped when an enterprise managed MCP configuration file exists, and also happens when Claude Code has paired with a Chrome extension before, even if the extension isn't detected on this machine.
- 🔴 Changed selection lists whose options have descriptions to cut labels longer than 60% of the terminal width short with "…", so the descriptions stay visible.
- 🔴 Turned on reduced motion automatically in VS Code's integrated terminal and other xterm.js terminals, behind a remote switch that's off by default.
- 🔴 Made Claude Code recognise WSL from the `WSL_DISTRO_NAME` or `WSL_INTEROP` variables, not only from `/proc/version`.
- 🔴 Fixed the elapsed time in the detail views of subagents, background tasks and teammates continuing to count after they finished.
- 🔴 Fixed `/compact`, automatic compaction and summarizing part of a conversation from the message selector using an error message as the new summary when the summary request failed with an error whose text doesn't start with "API Error", such as "Request timed out" or "Credit balance is too low"; compaction now fails with that error instead.
- 🔴 Added `CLAUDE_CODE_LOOP_KEEPALIVE` (or a remote switch) to arm a 20-minute fallback wakeup when a self-paced `/loop` turn ends without Claude scheduling the next one; self-paced loops are themselves behind a remote switch that's off by default.
- 🔴 Labelled built-in commands as "command" and workflows as "workflow" in `claude agents`' dispatch suggestions, instead of calling everything a skill.
- 🔴 Made `/code-review ultra` and `claude ultrareview` refuse pull requests in the `anthropics/anthropic` repository, pointing to the automatic review there and to `/bughunter`.
- 🔴 Made the file-edit preview for `sed -i` commands resolve a relative file path against the session's working directory, both for the preview and for the edit it applies.
- 🔴 Stopped the PushNotification tool from holding notifications back as "user present" (the terminal had focus or you'd typed recently) in cloud sessions and remote workspaces.
- 🔴 Made the "/goal active" indicator's pulsing colour use fewer distinct shades in VS Code's integrated terminal and other xterm.js terminals.
- 🟡 (2.1.154) Collapsed line breaks and repeated spaces in MCP tool titles, and cut long tool descriptions (1,000 characters) and parameter descriptions (200) short in `/mcp`'s tool detail view.
- 🟢 Added `claude plugin init <name>` (alias `new`) to scaffold a plugin in `~/.claude/skills/<name>/`, which loads as `<name>@skills-dir` from the next session; options set the description, author and extra components, and `--force` overwrites an existing `.claude-plugin/`.
- 🟢 Added automatic loading of plugins from your user and project `.claude/skills` folders, with no marketplace: each subfolder holding a `.claude-plugin` folder loads as `<name>@skills-dir`, a project's plugins wait for the trust dialog and load as soon as you accept it, their MCP servers wait for the same startup approval as `.mcp.json` servers, and a folder that's a plugin you've turned off in `enabledPlugins` no longer loads as a plain skill. They're skipped with `--bare` and when managed settings (`strictKnownMarketplaces`, `blockedMarketplaces` or `strictPluginOnlyCustomization`) rule them out.
- 🟢 Added completion for `/plugin` arguments in the prompt: subcommands, installed plugin names for `enable`, `disable` and `uninstall`, plugins from your marketplaces for `install`, and marketplace names.
- 🟢 Made `claude agents` dispatch sessions with the `agent` from your settings, with a new `--agent <name>` to override it; the defaults row shows the agent as `@<name>`.
- 🟢 Made EnterWorktree switch into another Claude-managed worktree with `path` from a session that's already in one, and from subagents whose working directory was set at launch, where the switch moves only that subagent and gives it write access to the new worktree; the main checkout, unregistered or prunable worktrees and worktrees in use by another running agent are refused.
- 🟢 Left Claude-managed worktrees unlocked once the agent, workflow or background job that used them finishes, so `git worktree remove` and `prune` can clean them up.
- 🟢 Fixed background jobs' worktrees under `.claude/worktrees/` being left behind by the job retention sweep; the sweep now removes them when that's safe.
- 🟢 Fixed `--resume` not telling Claude about background subagents that were running when the previous Claude Code process exited; each is now reported as failed, with a reminder to check its worktree or output.
- 🟢 Fixed the date in Claude's context and the "date changed" notice disagreeing in long-running sessions, such as background sessions re-attached after sleep; both now use the same recorded date.
- 🟢 Fixed images that can't be processed (empty or corrupt) in pastes, MCP results and other attachments failing the request; they now become an "[Image could not be processed: …]" note.
- 🟢 Fixed copying to the clipboard inside tmux with `set-clipboard on`, such as copy-on-select in `claude agents`: the plain OSC 52 sequence is now sent as well as the passthrough one.
- 🟢 Fixed right-click pasting the clipboard a second time in VS Code's integrated terminal and other xterm.js terminals, such as Cursor's and Windsurf's.
- 🟢 Improved image paste on WSL: alt+v pastes an image (ctrl+v still does too), an empty paste reads the image from the Windows clipboard, the clipboard is read through Windows Forms (for Windows 11 screenshots), and pasted or dragged Windows paths to images are converted with `wslpath`.
- 🟢 Fixed the `--resume` session picker leaving its contents on screen after you leave it in fullscreen mode; it now runs in the fullscreen view.
- 🟢 Fixed `--worktree`, with or without `--tmux`, started inside a linked worktree working from the main checkout instead of the current worktree.
- 🟢 Fixed the `/model` picker's "Newer version available" hint for custom model IDs: it now appears only when the family's current model is newer, and other custom entries show the family's description with the model ID, or "Custom model (<id>)" outside the Sonnet, Opus and Haiku families. A session pinned to Opus 4.7 now gets that hint in place of its own "Opus 4.7 · Legacy" row.
- 🟢 Fixed Markdown markers (backticks, asterisks) showing literally in text written during a collapsed group of read and search calls; that text is now rendered as Markdown.
- 🟢 Fixed the terminal freezing after you approve the server-managed settings dialog at startup; the dialog now clears itself instead of unmounting the interface that's already running.
- 🟢 Fixed a rare duplicate line in scrollback after a full redraw: the renderer now counts rows that scrolled off the top whenever the output is taller than the terminal, not only when the cursor sits below the last row.
- 🟢 Sped up long and resumed conversations: each message's tool lookup is reused when the tool list changes, and loading a transcript no longer records a trace span for every line.
- 🟢 Made `/terminal-setup` in VS Code, Cursor and Windsurf also turn off the integrated terminal's GPU acceleration (`terminal.integrated.gpuAcceleration` set to `off`, after backing up `settings.json`) to prevent garbled text.
- 🟢 Moved the feature-of-the-week credit-claim messages to the notification area.
- 🟢 Changed `claude agents`' dispatch suggestions to match anywhere in a name, listing names that start with what you typed first.
- 🟢 Fixed Esc not cancelling a slow "opening…" in `claude agents`, which left the list unresponsive; the row now says "esc to cancel".
- 🟢 Fixed finished background sessions in `claude agents` not shutting down while only background shell commands, in-process teammates or dream tasks were still running in them.
- 🟢 Removed the "Your bash commands will be sandboxed. Disable with /sandbox." startup notice.
- 🟢 Removed the "/ide for <IDE>" hint shown a few seconds after start.
- 🟢 Made backspace right after a highlighted workflow keyword ignore the keyword for that prompt, like alt+w, instead of deleting a character.
- 🟢 Added a "Workflow keyword trigger" switch to `/config` (setting `workflowKeywordTriggerEnabled`, on by default) to stop "workflow" or "workflows" in a prompt from asking for a dynamic workflow.
