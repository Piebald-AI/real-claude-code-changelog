# 2.1.202 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Brought back the silent same-model retry after a refusal, missing from 2.1.181 through 2.1.201: when the account's `convolute_arcades` client data is on and the session runs the default Opus model, a refused response is retried on that same model without the model-switch notice, and an interactive main session continues from at least 80 characters of partial text for the first such retry in the session, unless the response stopped inside a tool call. With the switch on, requests to Anthropic's API and to Claude Platform on AWS after a refusal fallback carry the `x-is-refusal-fallback` header.
- 🔴 Added `stop: true` to the ScheduleWakeup tool so Claude can end a self-paced `/loop` at once, cancelling its pending wakeups; the loop instructions now ask Claude every turn whether another iteration is worth running instead of always rescheduling. Self-paced `/loop` is behind `tengu_kairos_loop_dynamic`, which defaults off.
- 🔴 Added Mermaid diagrams to Markdown artifacts: fenced code blocks marked `mermaid` render as diagrams in light or dark colors on the published page, and the code stays visible when a diagram fails to render. It's behind `tengu_artifact_mermaid_diagrams`, which defaults on.
- 🔴 Added a hidden live watch on artifacts published from interactive and SDK sessions: when another session republishes the page, Claude is told its copy is stale and to fetch the latest. It's behind `tengu_slate_lantern` (off by default), isn't armed in cloud sessions, stays out of task lists, doesn't keep SDK turns busy, and stops if it can't connect within 30 seconds.
- 🔴 Removed the connector-grant notes from the Artifact permission prompt and tool row: redeploying a page that carries a stored connector grant, or one whose grant couldn't be read, no longer says so, though it still asks for approval.
- 🔴 Collapsed Write and Edit calls to the scratchpad folder into summary rows that count the edits and show lines added and removed.
- 🔴 Changed `/code-review low` on Sonnet 5 to aim for one finding per changed file, up to four, with a second pass when it finds fewer; `high`, `xhigh` and `max` reviews on Sonnet 5 now start with two to eight finder agents picked from the diff's size.
- 🔴 Changed `/permissions` so a rule that comes from `--settings` or a slash command says it's read-only and can't be changed there, and a failed deletion says the rule is unchanged.
- 🔴 Changed the built-in Claude Code help skill to give you documentation links without the trailing `.md`, so they open the rendered page; it still fetches the `.md` files itself.
- 🔴 Let Bedrock, Mantle and Claude Platform on AWS sessions whose credentials come from the desktop app use AWS access keys, or an AWS config or credentials file (with `AWS_PROFILE` if set), passed in the environment, where they used to fail unless a bearer token or API key was set or authentication was skipped; Vertex sessions under the desktop app now use the Google credentials in the environment instead of failing, without running the local refresh step. When nothing usable is passed, the error explains that background agents and teammates can't use that credential kind.
- 🔴 Protected more provider variables when a host app manages the provider (`CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST`): a settings file's `env` block can no longer override AWS keys, profiles and credentials files, Google Cloud credentials and project, cloud metadata and container-credential variables, the AWS region or `AWS_ENDPOINT_URL*`, and background workers and daemons drop inherited AWS keys and provider credential paths unless the job sets its own.
- 🔴 Added the `totalTokensReminderAfterUserTurn` setting and `CLAUDE_CODE_TOTAL_TOKENS_REMINDER_AFTER_USER_TURN`: with the token reminder on, Claude also gets the remaining-tokens note after each regular prompt, and the padded countdown restarts from its full budget at every prompt. It's off by default; `tengu_lapis_anchor_user_turn` can also turn it on.
- 🔴 Made Monitor refuse a WebSocket to a private, link-local or cloud-metadata IP address written as a literal when it connects, as it already did for hostnames resolving there, so the block holds even when no permission prompt runs.
- 🔴 Reduced plan-file name clashes: before the workspace trust prompt is accepted, new plan names are now checked against the default plans folder, and names are checked again when the plans folder changes; a plan path already in use keeps its name and logs a warning.
- 🔴 Checked Remote Control permission replies before applying them: a malformed reply is ignored, a malformed list of rule updates is dropped while the allow or deny still applies, and an empty replacement input no longer replaces the tool's input.
- 🔴 Stopped restoring `bypassPermissions` from a remote session's saved mode when settings or policy disable it or the session wasn't started with it available; the session falls back to the default mode.
- 🔴 Made the Agent SDK reject an `apply_flag_settings` request whose `settings` isn't an object (null, an array, a string) with an error naming what it got.
- 🔴 Stopped failures while saving permission rules or approvals from surfacing as unhandled promise rejections; they go to the error log.
- 🔴 Fixed the scrolling message list reading past the end of the conversation when its cached item keys or visible range lag behind a shorter message list.
- 🔴 Made trimming of old tool results reuse earlier normalized messages, keep a tool's full result when its storage cleanup fails, and tolerate malformed Read results.
- 🔴 Started loading a custom theme earlier at startup when the theme setting names one, and stopped overlapping theme loads from running at the same time.
- 🔴 Capped cached session transcript previews at 40, and let a failed preview fetch be retried at once instead of being treated as fresh for three seconds.
- 🔴 Kept idle in-process teammates from expiring while their background shell commands or monitors are still running, restarting the expiry timer when that work ends.
- 🔴 Made stopping an in-process teammate wait until it's removed from the saved team membership.
- 🔴 Added a session link to PR descriptions written in upload-only Remote Control sessions; commit trailers still leave those sessions out.
- 🔴 Added a GitHub-only mode to the cloud agent proxy, turned on by `CLAUDE_CODE_AGENT_PROXY_GIT_CONFIG` or `CLAUDE_CODE_AGENT_PROXY_GH_SHIM`: it routes github.com through the session relay with entries in the session's own Git config and can put a `gh` wrapper on `PATH`, while other traffic, GitHub Enterprise hosts and `gh` runs carrying a real token keep the machine's own connection. In this mode the proxy skips its system-wide certificate, AWS and tool setup.
- 🔴 Made the cloud agent proxy read the current session token each time it opens or retries a tunnel, instead of reusing the one read at startup; an explicit `AGENT_PROXY_AUTH_TOKEN` still wins.
- 🔴 Gave the cloud agent proxy's version-2 tunnels 10 seconds instead of 1.5 to finish closing, and stopped socket errors and an overfull pending buffer from cutting that close short.
- 🔴 Stopped background workers from restarting over and over when their socket folder belongs to another user; they now stop as crashed and say why.
- 🔴 Fixed a short-lived background command missing a terminal that attached while its final output was being saved, by listening for the connection before the save starts.
- 🔴 Let a background terminal host start without its stderr log when the log's folder is missing (`ENOENT`), as it already did for a full disk or a permission error.
- 🔴 Stopped Escape from also cancelling Claude's turn while a dialog is open.
- 🔴 Kept the built-in browser view and its state when forking a conversation; switching to another session still closes it.
- 🔴 Added a specific error for a PDF whose page tree reports zero pages, instead of an unknown extraction failure.
- 🔴 Reworded auto mode's publishing checks so an unknown repository visibility is never by itself a reason to block, replacing "fail open on visibility" in the data-exfiltration and out-of-place-publication rules.
- 🔴 Told auto mode's classifier that an earlier call's `ok` outcome only records that it ran: pushing, shipping or running what that call produced is judged on its own content.
- 🔴 Escaped special characters in automatic folder permission rules, so brackets, parentheses, `|`, `+`, `^`, `$`, `*`, trailing spaces or a leading `!` or `#` in a folder name match literally; approval summaries show the plain folder name.
- 🔴 Checked the JSON that async hooks return before using it: a malformed response no longer breaks the hook, recognized fields of the right type are still delivered, and a hook's message or added context reaches Claude only when it's text.
- 🔴 Recorded which agent started each nested agent in that agent's saved metadata, and kept that link when the agent resumes.
- 🔴 Updated terminal hyperlink detection: Alacritty (`TERM=alacritty`) now counts as supporting links, and so does Windows Terminal (`WT_SESSION`) running a tmux older than 3.4; Ghostty and Windows Terminal outside tmux already counted. Empty `FORCE_HYPERLINK`, `CI`, `TERM_PROGRAM` and similar variables are treated as unset, so an empty `FORCE_HYPERLINK` no longer forces links on.
- 🔴 Stopped compaction from adding another copy of a skill's instructions when the kept conversation still holds them in its invoked-skills reminder, and saved the shortened copy so a later re-invocation knows it was cut.
- 🔴 Changed prompt editing to handle `[Audio #N]` as one token for cursor movement and deletion, including when it's typed as ordinary text.
- 🟡 (2.1.233) Added a server-controlled list of model names (`tengu_vellum_ash`, empty by default) that turns off TodoWrite, the task tools and their reminders for matching models.
- 🟢 Added a "Dynamic workflow size" choice to `/config` (unrestricted, or small, medium and large for under 5, 15 and 50 agents) that's sent to Claude as a guideline rather than a cap, including a note when you change it mid-session; workflow tips now mention it.
- 🟢 Added `workflow.run_id` and `workflow.name` to OpenTelemetry events and to request and tool spans from workflow agents, passed on to the agents they start; a custom or edited workflow's name is reported as `custom` unless `OTEL_LOG_TOOL_DETAILS` is on.
- 🟢 Fixed accepting or cancelling a Ctrl+R history search while it was still reading the history file: the search now stops as soon as it's accepted, cancelled or replaced.
- 🟢 Fixed a name given with `/rename` being lost when a background job restarts, by saving it into the job's state and restart arguments.
- 🟢 Fixed client certificate rotation being disrupted when settings are re-applied: connections are reset only after comparing the certificate and key paths and the newly loaded files.
- 🟢 Fixed commands sent from Remote Control being rejected as unknown, by giving the stand-in command the original command's enabled check.
- 🟢 Fixed Remote Control messages that carry only attachments being dropped, and added "[attachment could not be downloaded]" when every attachment fails.
- 🟢 Made sign-in and MCP authorization links, including the URLs printed by `claude auth login` and `claude mcp login`, single hyperlinks even when link support can't be detected, while respecting the `hyperlinks` setting and `FORCE_HYPERLINK`.
- 🟢 Fixed `claude agents` mistaking its own worker registration for another background process when opening a session.
- 🟢 Fixed `\u` escapes in a workflow script's strings being turned into raw characters before the script is parsed, and made parse errors show the offending line with a caret.
- 🟢 Fixed voice capture failures restarting the recorder endlessly: failures before any audio arrives now count toward the existing limit that pauses voice input.
- 🟢 Fixed Remote Control showing the wrong permission mode, by sending the mode when a session connects or reconnects and whenever it changes, never reporting bypass mode.
- 🟢 Made finding sessions across many git worktrees faster and lighter by scanning project folders once and reading at most 32 transcript headers at a time.
- 🟢 Added up to three attempts for update manifest and binary downloads when the connection drops, with a message about networks and proxies after repeated drops.
- 🟢 Stopped re-invoking an already-loaded skill from adding another copy of its unchanged instructions: the copy is replaced by a short pointer to the one already in context, while new arguments, new dynamic output or an earlier copy cut by compaction bring the full text with a short note.
- 🟢 Reworked `/workflows` agent rows: wider titles, a separate elapsed-time column, one model name, and no tool-call counts or long failure text.
- 🟢 Improved the MCP configuration error for a server with a `url` but no `type`, suggesting `"type": "http"` (or `sse` or `ws`).
- 🟢 Changed `/review <pr>` back to a single-pass review without forced medium effort; `/code-review` keeps the multi-agent review.
