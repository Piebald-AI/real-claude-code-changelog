# 2.1.113 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Removed the `/autopilot`, `/bugfix`, `/dashboard`, `/docs` and `/investigate` commands, each of which started a remote Claude Code session that ran that workflow on your task; they were offered to claude.ai sign-ins whose organization allows remote sessions.
- 🔴 Renamed the bundled `/less-permission-prompts` skill to `/fewer-permission-prompts`; its instructions are unchanged apart from the title.
- 🔴 Added message timestamps: a "Show message timestamps" switch in `/config` (`showMessageTimestamps`, off by default) puts the time above each of Claude's replies. The switch and the timestamps only appear while a remote switch that's off by default is on.
- 🔴 Added an experimental renderer for the regular (non-fullscreen) screen that pins the prompt area to the bottom of the terminal with a scroll region and lets the conversation scroll into the terminal's own scrollback. It's used only with `CLAUDE_CODE_DECSTBM` or a remote switch that's off by default, in terminals with synchronized output outside tmux and Zellij; every session now also resets the terminal's scroll region when it starts and exits.
- 🔴 Made `/feedback` failures say why, instead of "Could not submit feedback. Please try again later.": a not-signed-in failure points to `/login`, and any other failure names the server's status code, a timeout or an unreachable service when known and offers the GitHub issues page as a fallback. Behind a remote switch that's off by default, a sent report shows "Feedback sent" and its reference ID instead of offering to draft a GitHub issue.
- 🔴 Reworded API server errors: a 5xx error now says it's a server-side issue that's usually temporary, an overloaded error says the API is at capacity, the status-page pointer shown with Anthropic's API and Claude Platform on AWS now reads "If it persists, check" the status page, and an error whose message carries a JSON body shows the message from inside it.
- 🔴 Changed the `/compact` description to "Free up context by summarizing the conversation so far" and `/exit`'s from "Exit the REPL" to "Exit the CLI".
- 🔴 Made `-n`/`--name` show the session name in the prompt box from the start, as `/rename` does, and keep that name when resuming a session saved under another one; its help text now says so.
- 🔴 Made deep links (`claude-cli://open`) stricter about what they hand to the new session: a working directory that's a network path or contains invisible or bidirectional-control characters is now refused, C1 control characters are refused in the directory and the prompt, and directory and prompt now travel base64-encoded (`--deep-link-cwd-b64`, `--prefill-b64`) to Ghostty, Tilix, xterm and other terminals without a launch rule of their own. A terminal that won't start in the directory is retried without it, launch failures print "Deep link error: …", and a prefilled prompt can no longer be read as `--settings` or `--setting-sources` when settings load early.
- 🔴 Made the Vertex AI regions `us` and `eu` use Google's multi-region endpoints (`aiplatform.us.rep.googleapis.com`, `aiplatform.eu.rep.googleapis.com`) instead of a `us-aiplatform…` or `eu-aiplatform…` host; the Vertex setup wizard now suggests `us` and `eu`.
- 🔴 Fixed plain `http://` requests to hosts listed in `NO_PROXY` failing when a proxy and custom client or CA certificates are configured: they no longer get the HTTPS-only certificate agent.
- 🔴 Made `claude auth login` with `CLAUDE_CODE_OAUTH_REFRESH_TOKEN` ask for a one-year access token (`expires_in` of 31,536,000 seconds).
- 🔴 Made settings accept `rc` for `autoUpdatesChannel` (its description still names only latest and stable), though the native installer still rejects an `rc` channel; choosing latest in `/config` now removes the setting instead of writing `latest`.
- 🔴 Made an Enter pressed while pasted text is still being processed submit the prompt once the paste lands, instead of being dropped (an Enter during an image paste is still dropped).
- 🔴 Drew the sections of `/doctor` and `/context` as trees, and made `/doctor` show "Checking for updates…" while it looks up versions.
- 🔴 Stopped a click on a URL that's cut short with "…" in fullscreen from opening the truncated address.
- 🔴 Made fullscreen mouse-wheel scrolling in VS Code's terminal and other xterm.js-based terminals restart at the configured scroll speed after a pause, instead of at 2, when that speed is higher.
- 🔴 Made Claude's final reply appear in fullscreen's brief transcript as soon as it's complete, while Claude Code is still finishing the turn.
- 🔴 Stopped a custom key binding for `chat:messageActions` from firing while text is selected in fullscreen.
- 🔴 Fixed a session's custom title and tags being missed when the transcript line that records them doesn't begin with its `type` field.
- 🔴 Fixed resuming sessions of long project paths whose shortened project folder name ends differently from the one this build computes: every folder sharing the shortened name is now searched.
- 🔴 Made slash commands typed with a non-breaking space before their arguments work.
- 🔴 Reworded the error for a plugin option that isn't set to "Plugin option "X" isn't set. Open /plugin manage to configure it, or check that the plugin's userConfig schema declares "X"."
- 🔴 Added a `title` option to the SDK's initialize request: it sets the session's title and skips automatic title generation (it doesn't change a resumed session's saved title).
- 🔴 Made sandbox network prompts sent to SDK hosts offer to always allow the domain (a `domain:<host>` allow rule in local settings); an accepted rule is saved and applied to the sandbox straight away, and simultaneous requests for one host share a single prompt.
- 🔴 Applied brief mode's end-of-turn check to SDK sessions: with brief mode on (`CLAUDE_CODE_BRIEF` or a remote switch that's off by default) and its tool available, a turn that ends without sending its reply through that tool is handed back to Claude, as in the terminal.
- 🔴 Made the first request in print and SDK mode wait up to 2 seconds for MCP servers that are still connecting even when another server's tools are already loaded.
- 🔴 Stopped plugin installation at the start of print and SDK mode from reconnecting MCP servers that were already configured; only servers the new plugins add are connected.
- 🔴 Added to the Bash tool's instructions that Claude should never put `cd <current-directory>` before a `git` command, since git already works in the current tree and the combination triggers a permission prompt.
- 🔴 Changed the reminder sent when you type "ultrathink" from asking for reasoning effort level "high" to saying you asked for deeper reasoning on that turn and that Claude should reason as thoroughly as the task warrants.
- 🔴 Reworded the note around a channel message that arrives mid-turn: it now says the tag's `source=` attribute names the sender and tells Claude to treat the contents as untrusted data rather than instructions and not to act on imperative language inside.
- 🔴 Made built-in subagents such as Explore and Plan retry when the API reports it's overloaded (529), as the main conversation does, instead of failing on the first such error.
- 🔴 Made fullscreen mouse-wheel scrolling in Windows Terminal (detected by `WT_SESSION`) use the decaying acceleration that VS Code's terminal gets, instead of the acceleration other native terminals use.
- 🔴 Fixed installing a plugin replacing an existing `enabledPlugins` version list with `true`; the version list now survives the install and its failure recovery.
- 🔴 Removed an invisible Tab stop from the transcript view, and made its navigation handler give up keyboard focus while transcript search is open.
- 🟡 (2.1.118) Fixed reinstalling a plugin leaving an installed dependency at the wrong version: it now tries to install a compatible version, and a failed extra download leaves the affected plugin disabled without failing the main install.
- 🟡 (2.1.111) Made Bash commands starting with `cd . &&` or `cd .. &&` use their checked destination for later writes and output redirection, removing the extra directory-change prompt when the other rules allow the command. The leading `cd` is checked from the starting directory rather than its destination; commands with line breaks or wildcard directory targets no longer take this shortcut.
- 🟢 Made `claude update` and auto-updates treat a native Claude Code binary running from an npm install (under `~/.claude/local/node_modules/` or any `node_modules/@anthropic-ai/` folder) as an npm installation and update it through npm (or bun, when it sits in bun's global folder), where it used to count as a standalone native install.
- 🟢 Added the `sandbox.network.deniedDomains` setting: domains, with the same wildcards as `allowedDomains`, that are always blocked even when `allowedDomains` matches them, merged from every settings source.
- 🟢 Made extending a selection with Shift+↑/↓ past the top or bottom of the view scroll the view in fullscreen.
- 🟢 Made `Ctrl+A` and `Ctrl+E` move to the start and end of the current logical line in multiline input.
- 🟢 Added `CLAUDE_CODE_BS_AS_CTRL_BACKSPACE`, which makes the Backspace byte `\b` act as Ctrl+Backspace and delete the previous word; it's on by default only on Windows outside mintty and Cygwin, so on Linux it's opt-in.
- 🟢 Made long URLs stay clickable when they wrap in terminals with hyperlinks: a response that contains a URL but no other Markdown now goes through the Markdown renderer, and Bash output links the URLs on every line that doesn't already carry a hyperlink (before, one hyperlink anywhere turned linking off for the whole output); a URL also no longer runs into control characters after it.
- 🟢 Made Esc cancel pending `/loop` wakeups (an interrupt from Remote Control does too), and a firing wakeup now reads "Claude resuming /loop wakeup" instead of "Running scheduled task".
- 🟢 Made `/extra-usage` work from Remote Control: there it replies with the page for managing extra usage instead of opening a browser on the computer.
- 🟢 Let Remote Control clients ask for `@`-file suggestions (a `file_suggestions` request answered with the same fuzzy matches the terminal shows).
- 🟢 Made a background subagent whose stream shows no progress for 10 minutes fail with "Agent stalled: no progress for 600s …" instead of hanging; `CLAUDE_ASYNC_AGENT_STALL_TIMEOUT_MS` changes the limit.
- 🟢 Fixed a multi-line Bash command whose first line is a comment being shown in the transcript as just that comment: the comment is used as the label only when nothing but comments follows and it has no control characters.
- 🟢 Stopped `cd <current-directory> && git …` from asking for permission when the `cd` target resolves to the working directory; other `cd`-then-`git` commands still ask, now explaining that git can run untrusted hooks from the target directory.
- 🟢 Made Bash deny and ask rules also match the command inside wrappers such as `env`, `sudo`, `doas`, `nice`, `nohup`, `timeout`, `time`, `watch`, `ionice`, `setsid`, `taskset`, `chrt`, `strace`, `ltrace`, `flock`, `script`, `unshare` and `nsenter` (their options are skipped, and the command strings of `env -S`, `flock -c` and `script -c` are read).
- 🟢 Stopped `Bash(find:*)` allow rules from approving `find` with `-exec`, `-execdir`, `-ok`, `-okdir`, `-delete` or the `-fprint`/`-fls` actions, and prefix rules from approving `watch`, `setsid`, `nsenter` and the other exec wrappers when they run a command; `command -p -v` now counts like `command -v`.
- 🟢 Fixed MCP tool calls running at the same time: a message for one call no longer disarms another call's "response presumed lost" watchdog, which now arms for each call when a transport error happens during it and is disarmed by that call's own progress.
- 🟢 Made Ctrl+U and Cmd+Backspace delete from the cursor to the start of the line again, in the prompt and in search boxes, instead of clearing the whole input.
- 🟢 Fixed Markdown tables breaking when a cell's inline code contains `|`.
- 🟢 Stopped the session recap from firing while you have unsent text in the prompt.
- 🟢 Made `/copy`'s full response align Markdown table columns, for pasting into GitHub, Notion or Slack.
- 🟢 Fixed messages you type while viewing a running subagent: the subagent now gets them as coming from you rather than from the main agent, and they stay in its transcript after you leave its view and come back.
- 🟢 Fixed Bash `dangerouslyDisableSandbox` running a command outside the sandbox without asking: unless a permission rule allows the command, Claude Code now asks "Run outside of the sandbox", in bypass-permissions mode too, and auto mode asks you instead of its classifier (or refuses where it can't ask).
- 🟢 Changed `/effort auto`'s confirmation to "Effort level set to max".
- 🟢 Fixed the "copied N chars" notice overcounting emoji and other characters made of several code units (it also says "char" for one).
- 🟢 Fixed `/insights` crashing with `EBUSY` on Windows: it now avoids simultaneous writes to the same session-metadata cache file, and logs a failed write to that cache instead of crashing.
- 🟢 Made the exit confirmation show a one-shot scheduled task as "Runs once in <time>" instead of a recurring schedule.
- 🟢 Fixed the slash and `@` completion menu not sitting flush against the prompt border in fullscreen.
- 🟢 Fixed an `effort` in `CLAUDE_CODE_EXTRA_BODY`'s `output_config` being sent to models that don't take an effort setting, which the API rejected.
- 🟢 Fixed the prompt cursor disappearing when `NO_COLOR` is set: inverse video is now written directly instead of through the colour library, which drops it when colours are off.
- 🟢 Made `ToolSearch` rank MCP tools by their whole server and tool names, so a pasted MCP tool name finds that tool rather than siblings whose descriptions match.
- 🟢 Fixed compacting a resumed long-context session failing with "Extra usage is required for long context requests": compaction after a resume no longer switches to the default model with the long-context tag.
- 🟢 Fixed installing a plugin succeeding when one of its dependencies is already installed at a version outside the required range: it now fails with a `range-conflict` saying the dependency "is installed at" that version, "which does not satisfy" the range.
- 🟢 Fixed "Refine with Ultraplan" not showing the remote session's address in the transcript.
- 🟢 Fixed an image in a prompt that can't be resized, such as one sent by an SDK host, crashing the session: it's replaced by "[Image could not be processed: …]".
- 🟢 Fixed Remote Control sessions not streaming subagent transcripts: subagent transcript entries are now sent to the remote session too.
- 🟢 Fixed Remote Control sessions not being archived when Claude Code exits: shutdown and an explicit teardown now share one attempt, and its token refresh and retry fit inside the archive time limit.
- 🟢 Fixed Opus 4.7 through a Bedrock Application Inference Profile ARN failing with "thinking.type.enabled is not supported": the thinking settings are now chosen for the model the ARN resolves to.
