# 2.1.154 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Added an `ultracode` effort level wherever dynamic workflows are on and the model supports xhigh: it sets xhigh effort and tells Claude to run a Workflow for every substantive task, with reminders while it's on and no workflow usage prompt. It lasts for the session and is set with `/effort ultracode`, the `/effort` slider, the effort control of the model picker opened by its shortcut or from `/config`, the `ultracode` setting (for example through `--settings`) or the SDK's `apply_flag_settings` request; `/model` lists it too but ignores the choice.
- 🔴 Changed the one-time "Auto mode is now Claude Code's default permission mode" announcement from a dialog you dismiss with Enter to a notice added to the conversation shortly after a session starts in auto mode by default.
- 🔴 Added a Remote Control section to `/doctor` that checks each requirement in turn (first-party API, not inside a remote session, `disableRemoteControl`, a claude.ai subscriber login with the `user:profile` scope and an organization, feature-flag evaluation, the account switch), and gave clearer reasons when Remote Control is unavailable: flags turned off by `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`, `DISABLE_TELEMETRY`, `DO_NOT_TRACK` or `DISABLE_GROWTHBOOK`, an unreachable flag service, or an account not enabled yet (suggesting `claude auth login` or `claude doctor`). When no flags have arrived this session, it fetches them once more before giving a reason.
- 🔴 Made `claude remote-control` skip sessions and work whose environment the server has already removed, and explain when the environment was cleaned up while the machine was offline, listing the worktrees it kept and suggesting `claude remote-control` for a fresh environment.
- 🔴 Moved organization announcements (`companyAnnouncements`, "Message from <organization>:") and the model launch notice from the welcome banner into the startup notices below it, showing one of them at a time; an organization announcement takes priority over the Opus 4.8 launch notice.
- 🔴 Expanded the "Using flicker-free rendering" notice with tips: scrolling with the trackpad, wheel or PageUp/PageDown, copying by selecting text (`/config` turns it off), clicking to move the cursor or expand collapsed results, and `/tui default` to go back, saved to your preferences.
- 🔴 Made an existing claude.ai login take precedence over an `ant auth login` profile that Claude Code finds on its own in `~/.config/anthropic`; set `ANTHROPIC_PROFILE` to use the profile instead.
- 🔴 Made the claude.ai connector list fetch try up to three times after server errors, failed DNS lookups and dropped, refused or timed-out connections, skipping another retry if its delay plus a five-second request would pass 12 seconds.
- 🔴 Showed HTTP and SSE MCP servers whose OAuth discovery metadata fails validation after an authentication challenge as needing authentication, with the reason ("Server OAuth metadata invalid: …") in `/mcp`, instead of as failed.
- 🔴 Stopped MCP servers from being reconnected or replaced when their configuration changes only in key order, plugin source, a recorded configuration error, or a stdio server's `type` or `args` being left out.
- 🔴 Wrote agent-team inbox files atomically, so a teammate reading its inbox during a write no longer sees a half-written file; an inbox that can't be parsed is still read as empty but is no longer reported as an error.
- 🔴 Reported plugins in skills folders that don't load because an installed plugin, a `--plugin-dir` or `--plugin-url` session plugin or managed settings already uses their name ("Not loaded — the name … is already taken by …"), instead of skipping them silently.
- 🔴 Limited automatic write permission in agent-memory and auto-memory folders to `.md` files; other files there now ask like any other path.
- 🔴 Limited the files a background session may read and write without asking to a new `tmp/` subfolder of its job folder (`$CLAUDE_JOB_DIR/tmp`, deleted with the job), and told the session to keep temporary files there. The job-folder comparison now ignores letter case, including on Linux.
- 🔴 Changed `/agents`' Running tab to list only running subagents: agent-team teammates, dynamic workflows and remote agents no longer appear there, and the task detail view it opened was removed.
- 🔴 Made the Workflow tool refuse with an explanation when dynamic workflows aren't enabled for the session, report bad scripts as "Invalid workflow script: …" with a reminder that scripts must be plain JavaScript, and tell Claude to pass scripts inline and `args` as JSON values rather than strings; the tool's own error display is gone, so its errors show in the standard tool error style.
- 🔴 Told background sessions set to work in place to skip `EnterWorktree` unless you ask for a worktree; before, they were told never to call it.
- 🔴 Told the `claude-code-guide` agent to say when it can't reach the documentation and to flag answers from memory as possibly out of date, instead of answering silently from what it remembers.
- 🔴 Extended the `cleanupPeriodDays` cleanup to old subagent and workflow transcripts in session folders whose main transcript is gone, and to old entries in `~/.claude/skills/.staging`.
- 🔴 Lowered prompt-based hook evaluators' conversation target from 70% to 50% of the context window, and added one retry targeting 25% when the request is still too long. The newest message group is always sent whole, even if it exceeds that target.
- 🔴 Added labels for more pull-request actions in the activity lines for `gh` commands ("marked draft", "enabled auto-merge on", "disabled auto-merge on"), and stopped counting `git push --dry-run` or `-n` as a push; "committed <hash>" now shows git's own abbreviation (usually 7 or more characters) instead of the first 6 characters.
- 🔴 Stopped cloud session creation from bundling or checking the local repository for "byoc" environments, which now need a GitHub remote, and added errors for environments that accept only the Anthropic monorepo.
- 🔴 Showed "Switching back to the classic renderer…" in place of the fullscreen "what made you switch back?" question once you answer or skip it, while Claude Code switches renderers.
- 🔴 Reworded the first-run safety note to say you're responsible for Claude's actions and should review them, especially when it runs code.
- 🔴 Made Esc after a successful login in the `/login` dialog finish the login (its hint now reads "continue") instead of reporting it as cancelled.
- 🔴 Made `claude agents` and `--bg` start the background service from the newest installed version in Claude Code's versions folder when the usual executable paths can't be started.
- 🔴 Reworded `claude agents`' empty-state text and input placeholder ("describe a task for a new session"), and made the highlighted row of the session you came from show its folder name while it waits for its first prompt, with a plain → in place of "→ to return".
- 🔴 Adjusted the welcome screen's mascot art in every theme, stacking its lines in a column, and moved two lines of the dark-theme Apple Terminal version one space left.
- 🔴 Removed the cursor repositioning after full alternate-screen repaints (`CLAUDE_CODE_ALT_SCREEN_FULL_REPAINT`) that 2.1.153 added to keep IME windows at the caret.
- 🔴 Made the feature-of-the-week credit offer fetch the organization's eligibility from the server, skip the claim once that answer says the organization isn't eligible or credits aren't available, and show the server's amount and currency; it stays off unless Anthropic configures it.
- 🔴 Added a bundled `claude-code-docs` skill that answers questions about Claude Code by checking a "Current Build" summary (commands, custom skills and agents, MCP servers, settings keys, recent release notes) and the live documentation before recommending anything, behind a remote switch that's off by default; `CLAUDE_CODE_DISABLE_CLAUDE_CODE_SKILL` keeps it from being registered.
- 🔴 Told the auto mode classifier that a destructive step isn't user-requested just because it's one way to reach the goal: cleaning up a repository doesn't authorize `git clean -fdx`, and getting a deploy working doesn't authorize a rollback migration.
- 🔴 Stopped background workers from being restarted from a half-downloaded update in the versions folder after their own executable was removed: temporary files, invalid names and empty files are skipped and the newest version is picked by version number.
- 🔴 Made the spinner's stall-warning pulse use coarse colour steps in every terminal, not only in xterm.js ones.
- 🔴 Corrected the bundled Python API guide to say consecutive messages with the same role are combined into one turn, replacing the rule that user and assistant messages must alternate.
- 🔴 Changed the workflow approval preview to count `agent()` calls only outside comments and quoted strings, so examples there no longer inflate its agent count; real calls inside template-string expressions are also left out of the summary.
- 🔴 Enforced the 512 KiB workflow script-file limit in bytes instead of JavaScript string length, stopping after 512 KiB plus one byte; oversized saved workflows are skipped.
- 🔴 Reset each permission dialog when a different request takes its place, so local state such as an edited workflow script doesn't carry over from the previous request.
- 🟡 (2.1.199) Showed pull requests in `claude agents` rows as `#N` without the "PR" prefix.
- 🟡 (2.1.147) Fixed `/effort`'s status output and starting slider position to show the model's launch-default effort rather than a saved level that isn't being used.
- 🟢 Added Claude Opus 4.8 (1M context, up to 128K output tokens, adaptive thinking, xhigh and max effort, a January 2026 knowledge cutoff) on every provider, including `VERTEX_REGION_CLAUDE_4_8_OPUS` for Vertex, and made it the Opus default on the Anthropic API: `opus`, the default model, agent-team teammates and remapped Opus 4 and 4.1 picks ("Model updated to Opus 4.8") now use it, at high effort until you choose another level. Claude Platform on AWS stays on Opus 4.7, and `/model` lists Opus 4.7 and 4.6 as Legacy.
- 🟢 Replaced the Opus 4.7 launch notice with one for Opus 4.8 on the Anthropic API, shown up to eight times, which points to `/effort xhigh` when you're on Opus 4.8 and to `/model` otherwise.
- 🟢 Made fast mode on Opus 4.8 cost twice the standard rate ($10/$50 per million input/output tokens) instead of the $30/$150 that Opus 4.6 and 4.7 charge; `/fast` and `/model` show the price for the Opus model you're on.
- 🟢 Fixed the Default option in `/model` not showing fast mode pricing for pay-as-you-go API users when fast mode is on.
- 🟢 Turned dynamic workflows on by default: the remote switch that makes them available now defaults to on, so they're on for every plan except Pro (which can turn them on in `/config`) unless a setting, an environment variable or the `allow_workflows` policy turns them off.
- 🟢 Made the lean system prompt the default for Opus 4.8 on any provider and for models newer than Haiku, Sonnet and Opus 4.7 on the Anthropic API, Claude Platform on AWS or a gateway; older models still need a remote opt-in, and the lean prompt dropped the Opus 4.7-only sentence about text output. Every model using the lean prompt now gets the instruction to match the surrounding code's comment density, naming and idiom, which only Opus 4.7 got before.
- 🟢 Told Claude to use the multiple-choice question tool only when it's blocked on a decision that's genuinely yours to make, replacing the list of reasons to ask.
- 🟢 Changed `/simplify` into its own cleanup skill: four parallel agents review the changed code for reuse, simplification, efficiency and fixes made at the right depth, then the fixes are applied. It no longer runs `/code-review --fix`'s bug hunt and dropped its effort and `--comment` arguments.
- 🟢 Renamed the ends of the `/effort` slider from "Speed" and "Intelligence" to "Faster" and "Smarter".
- 🟢 Added shell sessions to `claude agents`: typing `!` and a command, or running `claude --bg --exec '<command>'`, starts it as a background session you can attach to.
- 🟢 Made `/logout` and `/heapdump` typed in `claude agents` run in the agents view itself (signing out and exiting, or writing a heap dump) instead of starting a background session.
- 🟢 Made `←←` open the agents view without first having used it or a remote switch being on, so it also works on Bedrock, Vertex, Foundry and with telemetry off.
- 🟢 Added browser selection to Claude in Chrome: `/chrome` shows the paired browser's name and a "Select browser…" picker, and Claude can ask you which one to use when several are connected.
- 🟢 Added `defaultEnabled` to plugin manifests and marketplace entries: a plugin set to `false` installs disabled, and install messages say how to enable it, while a dependency of an enabled plugin is still turned on.
- 🟢 Made the `/plugin` Discover tab list plugins whose relevance signals match the current directory first, marked "suggested for this directory".
- 🟢 Made tools start running while the response is still streaming for everyone; this was behind a remote switch that was off by default.
- 🟢 Gave stdio MCP servers `CLAUDE_CODE_SESSION_ID` and `CLAUDECODE=1` in their environment.
- 🟢 Changed `claude mcp list` and `claude mcp get` to show unapproved `.mcp.json` servers as pending approval without starting them, and connected servers whose tool list needs authentication as "! Needs authentication"; `get` also shows rejected servers.
- 🟢 Changed `/remote-control`'s description to "Disconnect Remote Control" while Remote Control is connected.
- 🟢 Updated the bundled `/claude-api` skill for Claude Opus 4.8, with a section on moving from Opus 4.7 and new material on mid-conversation system messages and `ant auth login` credentials.
- 🟢 Strengthened the auto mode classifier's rules on data leaving the trusted boundary: it now judges where data finally lands (including through CI pipelines and bulk copies of a repository), counts secrets written into any lasting artifact, soft-blocks destinations of unknown visibility, checks scripts the agent wrote before running them, and applies allow exceptions only to what they name. Custom `autoMode` lists that include `$defaults` get the new multi-line default rules whole.
- 🟢 Fixed auto mode blocking actions as unevaluable when the classifier ran out of output tokens while reasoning: that stage now gets 8,192 tokens instead of 4,096 and is told to reason as long as a hard case needs.
- 🟢 Fixed `rm -rf $HOME` and similar commands not being recognized as targeting a dangerous path when the home directory ends with a slash. The home-path comparison now ignores letter case as well.
- 🟢 Fixed `$TMPDIR` pointing at different folders for sandboxed and unsandboxed Bash and PowerShell commands in one session; unsandboxed commands now get the same session temp folder.
- 🟢 Fixed unreadable highlighted rows in `claude agents` when the Claude Code theme doesn't match the terminal background.
- 🟢 Fixed background-agent completion notices making the model think its own context was nearly full on some 1M-context models: subagent, workflow and task results now report usage as `subagent_tokens` instead of `total_tokens`.
- 🟢 Fixed the background-session classifier losing track of your request when a scheduled command fires, by skipping command output when it looks for the latest real request.
- 🟢 Fixed pinned background sessions respawning every minute after an update.
- 🟢 Fixed background sessions that stay blocked, running or working not retiring after the idle grace period.
- 🟢 Fixed subagents in background sessions writing to the shared checkout before the session isolated, and blocked any subagent running in its own worktree from editing the shared checkout's copy of a file.
- 🟢 Fixed orphaned `claude --bg-pty-host` processes running on after the daemon exits: a host whose parent changed and that has had no client for a minute now stops itself (`CLAUDE_PTY_ORPHAN_CHECK_MS` sets how often it checks).
- 🟢 Fixed number keys not choosing the "Chat about this" option below the divider in Claude's multiple-choice questions.
- 🟢 Fixed `worktree.baseRef: "head"` and `EnterWorktree` starting from the main checkout's HEAD instead of the current worktree's when run inside a linked worktree.
- 🟢 Fixed wrapped lines starting with a stray space when the previous line ended at the terminal width; copying across such a wrap keeps the space between the words.
- 🟢 Fixed intermittent rendering corruption in VS Code and other xterm.js terminals by limiting the colours drawn there: output uses 256 colours instead of truecolor (a remote switch, on by default, controls this), spinner and shimmer animations step through fewer colours, and a forced redraw also clears the terminal's glyph cache.
