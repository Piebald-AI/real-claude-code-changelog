# 2.1.144 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Brought back Ctrl+E on Bash and PowerShell permission prompts, missing in 2.1.142 and 2.1.143: it asks the model to explain the command, why Claude is running it and what could go wrong, with a low, medium or high risk rating; the `permissionExplainerEnabled` config setting turns it off.
- 🔴 Made permission prompts send a desktop notification and a `permission_prompt` Notification hook event after at least 6 seconds without interaction: "Claude needs your permission", or "Claude Code needs your approval for the plan" and "Claude Code wants to enter plan mode" for plan prompts (2.1.143 sent none, and 2.1.142 only for plan approval).
- 🔴 Made the Bash permission check ask before more kinds of commands: zsh `<N-M>` range globs, brace expansion holding `$((…))` arithmetic with spaces, such as `{1..$((2 + 3))}` (plain `{a,b}` and `{1..3}` already asked), `read`, `printf -v`, `getopts`, `mapfile` and similar commands that write `IFS`, `PATH`-like or special shell variables (that list now also has `HISTFILE`, `ZDOTDIR` and `NULLCMD`), `declare -n`/`-i`/`-a`/`-A` reached through a wrapper such as `command` or `builtin` (the plain form already asked), array subscripts holding `$` or backticks in operands of `printf`, `print`, `getopts`, `set` and similar builtins, `set -o` options outside a safe list, `print -P` with a substitution, `jobs -x`, `find` with glob characters (`[`, `]`, `*` or `?`, quoted or not) in a path or other argument outside its pattern options such as `-name`, a `[[ … ]]` test whose quoted operand holds `]]` followed by a command separator, zsh builtins such as `setopt`, `repeat` and `zcompile`, and commands whose heredoc or other text the parser couldn't fully read. Its analysis also now looks inside `if`, `while`, `for` and `case` bodies, functions and `|&` pipelines.
- 🔴 Fixed Bash permission parsing of quoted arguments: ANSI-C `$'…'` and locale `$"…"` quotes are now recognized inside joined arguments, and empty known-variable expansions don't make an otherwise unknown argument count as literal text. The brace checker no longer lets quotes in `#` comments affect later text, and the read-only glob/variable scan skips comments.
- 🔴 Made read-only and sandbox auto-approval stricter: a command containing a subshell or a `{ …; }` group no longer counts as a simple read-only command, file-changing commands such as `rm`, `mv`, `cp` and `sed -i` ask when a checked path comes from `$(…)` or an untracked variable, and sandbox auto-allow no longer approves shell builtins such as `printf`, `read`, `declare`, `export`, `test` or `set` whose arguments hold `$(…)`, backticks, `$'…'`, `${…:=…}`, a `$` variable together with a `-`, brace expansion or unmatched braces, nor `jobs -x` or `set -o` with an option outside a safe list. One sandbox check got looser: a `[` in the arguments of `printf`, `test`, `read`, `wait` or `unset` now stops auto-allow only when that argument also holds `$` or a backtick.
- 🔴 Stopped auto-approving read-only git commands such as `git log`, `git show` and `git rev-list` when `--format`, `--pretty` or `--sort` asks for signature details (`%G…` or `%(signature…)`), which makes git run its signature-checking program, or when that value comes from `$(…)` or an untracked variable.
- 🔴 Made zsh run Claude's commands with bare glob qualifiers turned off (`NO_BARE_GLOB_QUAL`), next to the existing `NO_EXTENDED_GLOB`.
- 🔴 Changed what happens when the sandbox can't start: with `sandbox.failIfUnavailable` (or when `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB` relies on the sandbox) commands fail with "Sandbox is required but failed to initialize: <reason>. Restart to retry."; otherwise the first command fails with "… Sandboxing is disabled for the rest of this session; restart to retry." and later commands run without the sandbox. Before, every command failed with "Sandbox failed to initialize."
- 🔴 Made background sessions take priority over `CLAUDE_CODE_NO_FLICKER=0`, `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN`, iTerm2's tmux integration (`tmux -CC`) and the Windows-over-SSH check when choosing fullscreen rendering; the `local-agent` entrypoint still stays out of fullscreen.
- 🔴 Stopped deleting a background session's transcript when the session is deleted from the agent view, undoing 2.1.143's change.
- 🔴 Removed the "last here … · /resume to continue" hint about your previous session, which showed only while a remote switch was on, and stopped saving that session's details to the global config after each prompt.
- 🔴 Let `/background <prompt>` (or `/bg <prompt>`) start from a conversation with no earlier user message; before, it refused with "Nothing to background yet — send a message first" even when you supplied the prompt.
- 🔴 Added a blank row above the header and session list in `claude agents`.
- 🔴 Added `/share` as another name for `/feedback`, now described as "Submit feedback, report a bug, or share your conversation"; the argument `public` opens it with an empty description.
- 🔴 Made `/feedback` use in-memory messages from in-process teammates in submitted reports and saved bundles, ahead of any transcript copy on disk.
- 🔴 Made `/usage` show "Failed to load usage data" with a retry option when the server returns nothing, instead of staying on "Loading usage data…".
- 🔴 Checked the bytes of images coming from Bash or PowerShell output (a `data:image/…;base64,` URL), notebook outputs and pasted file paths: anything that isn't a supported PNG, JPEG, GIF or WebP stays text or is refused. Pasted files and shell output also take their image type from the bytes rather than the label.
- 🔴 Kept a background session's worktree isolation choice and provider settings (`CLAUDE_CONFIG_DIR`, AWS and Google Cloud variables) when it's respawned, instead of taking them from whichever process restarts it.
- 🔴 Let plugins loaded with `--plugin-dir` be turned off: `claude plugin disable` (or `false` for `<name>@inline` in `enabledPlugins`) disables one, `claude plugin list` shows it as disabled, and `/plugin` offers Enable and Disable for it.
- 🔴 Fixed file permission checks failing with "path should be a `path.relative()`d string" when you have file path rules and the path checked is exactly the parent of the folder the rules apply to, such as the working folder's parent.
- 🔴 Stopped background subagents and in-process teammates from listing a message twice when it arrives again; the newer copy replaces the older one.
- 🔴 Let the server-sent notice shown above the conversation be marked persistent, so it appears in every session instead of once per notice.
- 🔴 Added a "Not for live watching" section to CronCreate's description that points Claude to the Monitor tool for watching logs, processes and command output, and reworded Monitor's search hint to match; both apply only when the Monitor tool is on (remote switch, off by default).
- 🔴 Updated the Bun runtime from `1.3.14+d29891451` to `1.3.14+521eedd6d`, with a newer WebKit build; native code grew by 32 bytes, with no sections, command-line options or `BUN_` variables added or removed and no changes to Bun's built-in JavaScript text. `Bun.serve`'s HTTP option errors now say `http1`/`http3` instead of `h1`/`h3`.
- 🟡 (2.1.121) Made `/usage` refresh an expired claude.ai sign-in before loading plan limits instead of skipping the request.
- 🟢 Added `/resume` support for background sessions: sessions started with `claude --bg` or from the agent view are listed with a `bg` tag, picking one that's still running says to open `claude agents` or run `claude --resume <id> --fork-session` to branch a copy, `/resume <id>` refuses a running one with a similar message, and `--continue` still skips background sessions.
- 🟢 Showed how long a background subagent ran in its completion notice (" · 3h 2m 5s").
- 🟢 Showed a plugin's "Last updated" date in the `/plugin` browse and discover details.
- 🟢 Made `/model` change the model for the current session only ("Set model to X for this session") and stopped saving model changes to your settings; press `d` in the model picker to save a default for new sessions ("… and saved as default"), and the model row in `/config` still saves one.
- 🟢 Renamed "extra usage" to "usage credits" in messages, menus and the fast-mode and rate-limit notices; `/extra-usage` is now `/usage-credits`, and the old name still works after a "/extra-usage is now /usage-credits" notice.
- 🟢 Gave Claude Code's own requests to Anthropic's account endpoints (sign-in checks, usage, billing and similar) a 15-second timeout when they had none, and 30 seconds to three billing actions, so an unreachable `api.anthropic.com` no longer stalls startup.
- 🟢 Fixed garbled output after a missed terminal resize: the renderer now compares its size with the terminal's at start and before each frame, and redraws when they differ.
- 🟢 Fixed display corruption in very long sessions once the table of text styles filled up: further style combinations are drawn without style instead of corrupting other cells.
- 🟢 Rounded the spinner's stalled-color fade to eighths, so it uses fewer colors (fewer glitches in VS Code's terminal).
- 🟢 Moved the cursor within a row by absolute column instead of a relative step, so wide characters such as CJK no longer leave ghost characters at the left edge when the terminal measures them differently.
- 🟢 Fixed an unrecoverable conversation after reading a file whose image extension doesn't match its content: the Read tool now refuses it, says what the bytes look like (an HTML page, JSON, a PDF…) and suggests reading it as text.
- 🟢 Counted `head` and `tail` file views run through Bash as reads for the read-before-edit check, and stopped reporting exit code 1 from `egrep`, `fgrep`, `git grep` ("No matches found") and `git diff` ("Files differ") as a failure.
- 🟢 Fixed `/branch` failing with "No conversation to branch" after entering a worktree, by reading the session's own transcript file.
- 🟢 Fixed Escape in AskUserQuestion's notes field ending the turn; it now returns to the answer choices.
- 🟢 Fixed model changes from the IDE's model picker or `applyFlagSettings` not taking effect: choosing the default model now means the default instead of falling back to the model in your settings.
- 🟢 Made resumed sessions, from the `claude --resume` picker and in print mode too, keep the model they last used rather than another session's choice, unless `--model` or `ANTHROPIC_MODEL` sets one or that model is retired or remapped (on Anthropic's API, Claude Platform on AWS and gateways).
- 🟢 Fixed Bedrock, Vertex AI and other endpoints missing "Opus (1M context)" in `/model`: Opus 4.7 now counts as a 1M-context model by default only on Anthropic's own endpoint, Claude Platform on AWS and Mantle.
- 🟢 Fixed remote-session sign-in failing with "Can't access this organization" when both `forceLoginMethod` and `forceLoginOrgUUID` are set: the organization is now enforced only for the matching sign-in method.
- 🟢 Fixed MCP servers whose `tools/list` is paginated losing every tool after the first page (up to 100 pages are read).
- 🟢 Fixed MCP images with unsupported types such as SVG breaking the conversation: they're saved to disk and referenced in the tool result. The inline-image format check now also accepts `image/jpg`, ignores case and strips MIME parameters when reading image resources.
- 🟢 Fixed running out of file descriptors when a build runs inside a skill folder: only changes to `.md` files trigger a skill reload.
- 🟢 Fixed session titles being made from task notifications, such as plugin monitor output, instead of your first prompt.
- 🟢 Fixed the Skill tool asking for permission ("Execute skill: …"), and so failing in headless mode, for skills that need no approval: a property every file-based skill carries was missing from the list of harmless skill properties.
- 🟢 Fixed plugins enabled in your own settings showing "not cached" errors on a fresh machine (they're looked up in the plugin caches first), and gave plugins enabled only by a project's `.claude/settings.json` the error "is enabled in project settings but isn't installed — run `claude plugin install <source> --scope project`".
- 🟢 Fixed `claude mcp list` saying no servers are configured when a config can't be read: it now shows the MCP config diagnostics, and a file with `"servers"` instead of `"mcpServers"` gets a message saying so.
- 🟢 Fixed background side requests on Mantle, which now use the main model unless `ANTHROPIC_DEFAULT_HAIKU_MODEL` is set, and with a custom `ANTHROPIC_BASE_URL` and a direct Anthropic API key, which now use Haiku.
- 🟢 Fixed a crash when the terminal closes while you're attached to a background session: the attach client now ignores a failed switch into or out of raw mode.
- 🟢 Fixed markdown links in attached background sessions rendering as plain text: link support now follows the attached terminal's capabilities as they change.
- 🟢 Made `/bg` and ← detach pass folders added with `/add-dir` on to the background session.
- 🟢 Fixed Edit and Write refusing with "background session hasn't isolated its changes yet" right after you send a session that was editing in place to the background: such sessions now keep editing in place, and the background instructions no longer cite the `worktree.bgIsolation` setting.
- 🟢 Fixed `claude respawn <id>` showing a stopped background session as stopped instead of starting it.
- 🟢 Fixed sessions forked or branched from a background session missing from the `/resume` picker.
- 🟢 Fixed opening a session from `claude agents` or running `claude logs <id>` hanging when the background service doesn't answer: after 10 seconds it says the service "did not respond — it may be stalled" with a restart hint.
- 🟢 Fixed completed or stopped background sessions that briefly fail to wake being marked as having crashed at startup. The background terminal host also now waits up to a second for a session's real exit code instead of reporting -1, and keeps its connection open for up to 5 seconds after the session ends, so a client that attaches late still gets the final screen and exit code.
- 🟢 Fixed custom `spinnerVerbs` showing up in the past-tense "Worked for 5s" line; it uses the built-in verbs again.
- 🟢 Made `claude agents` and `--bg` refusals say which gate applies: no interactive terminal (stdout is not a TTY), `CLAUDE_CODE_DISABLE_AGENT_VIEW` or the `disableAgentView` setting.
- 🟢 Made `claude --bg --name <label>` show the name in its "backgrounded" confirmation.
