# 2.1.161 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Made `/fork`, which starts a background agent that carries the whole conversation, available in local interactive sessions outside coordinator mode, and made pressing `f` on a side question fork that way instead of branching the conversation. Before, both needed `CLAUDE_CODE_FORK_SUBAGENT` or a remote rollout, and `/fork` otherwise ran `/branch`, which no longer has `fork` as an alias.
- 🔴 Showed more of the interface in `claude --remote` sessions: the permission-mode indicator, the terminal progress bar, usage-limit and usage-credit notices, model-deprecation warnings, the server-sent startup notice and "[Request interrupted by user]" markers. The hint after the first Ctrl+C now reads "detach (session keeps running)" instead of "exit".
- 🔴 Made `claude --remote` sessions skip loading the local MCP server configuration at startup, by marking the session as remote before that configuration is read.
- 🔴 Made `/model <name>` in a `claude --remote` session check organization model restrictions, 1M-context availability and whether the model exists before asking the cloud session to switch, and show the reason when it can't.
- 🔴 Made `claude --remote` sessions retry when connecting to the cloud session takes more than 30 seconds, and warn "Some earlier messages from this session could not be loaded after reconnecting." when the replay after a reconnect has a gap.
- 🔴 Moved several startup toasts into the counted "N setup issues · /doctor" startup notice: failed plugin marketplace installs and flagged plugins now count under plugins, and Claude in Chrome lacking a claude.ai subscription or its extension, an unavailable sandbox and a status line skipped for workspace trust get their own counts. The npm-to-native-installer warning and the model deprecation warning became startup notices too.
- 🔴 Moved the IDE selection indicator ("⧉ N lines selected", "⧉ In <file>"), the debug tag (now "Debug", was "Debug mode") and the cloud-session link (now "◉ cloud", was "◉ remote") from the status line into the row with the Remote Control status and mode labels; that row isn't drawn in fullscreen mode, so there they no longer appear. Stopped hiding the update-installed restart notice while an IDE file or text selection is active.
- 🔴 Added a hint to teammate pane failures caused by tmux having no room for another split: spawn fewer teammates, enlarge the terminal, or switch to in-process teammates in `/config`.
- 🔴 Renamed the teammate notices from "N agents spawned" and "N agents shut down" to "N teammates started" and "N teammates shut down", and dropped "swarm" from the `/color` and `/rename` refusals in teammate sessions.
- 🔴 Changed the usage-limit message for a monthly spend cap (`org_level_disabled_until`, or the new `org_spend_cap_reached`) to "You've hit your monthly spend limit" or "your org's monthly spend limit", with where to raise it (claude.ai/settings/usage, or claude.ai/admin-settings/usage on Team and Enterprise) or a request to ask an admin. `org_spend_cap_reached` also gets the cap wording in fast mode and the other limit messages, no longer clears the saved fast-mode preference or disables its saved organization eligibility, and reaches SDK hosts as `org_level_disabled_until`.
- 🔴 Skipped MCP tools whose input schema has a top-level `anyOf`, `oneOf` or `allOf`, which the Anthropic API rejects, with a message naming each skipped tool; the server's other tools stay available.
- 🔴 Reserved the MCP server names `claude-in-chrome` and `computer-use` next to `workspace`: servers with those names in settings, `.mcp.json` or `--mcp-config` (SDK servers excepted) are skipped with a "reserved MCP server name" error, where before config files loaded them and `--mcp-config` stopped Claude Code with an error.
- 🔴 Stopped approving a project's pending `.mcp.json` servers automatically in interactive sessions just because `skipDangerousModePermissionPrompt` is set; the session must now also run in bypass-permissions mode.
- 🔴 Made Bash permission checks ask before running `read` whose `-t`, `-n` or `-N` value isn't a plain number or whose `-p` comes with a subscripted name or command output, which zsh can evaluate as arithmetic and so run commands, and before `jq` filters that use `include` or `import`. `jq` with a combined `-f` or `-L` flag (such as `-rf`) is no longer auto-approved as read-only.
- 🔴 Narrowed sandbox auto-approval (`autoAllowBashIfSandboxed`): `find` arguments with `$` expansions or wildcard characters outside option values, and `jobs` or `set` arguments containing `$` (before `--` for `set`), now go through the normal permission flow. Option-looking arguments after `set --` no longer block sandbox auto-approval by being mistaken for options.
- 🔴 Blocked sandboxed commands from writing `.mcp.json` in the project folder and in the folders between the current one and the project folder, next to the existing protection for `.claude` settings, skills and hooks.
- 🔴 Tightened the PowerShell tool's guard against touching Git internals (`.git`, `HEAD`, `objects`, `refs`, `hooks`; opt-in on Linux with `CLAUDE_CODE_USE_POWERSHELL_TOOL`): every path is now resolved against the real working folder, following symlinks and ignoring case, after backtick line continuations are removed, where before only paths starting with `../`, `/` or a drive letter were resolved.
- 🔴 Treated a plugin's `UserPromptSubmit` hook whose script is missing (exit code 2 with "no such file") as a non-blocking error, as Stop hooks and similar already were, so it no longer blocks prompts; the message suggests reinstalling the plugin with `/plugin` or removing it from settings.
- 🔴 Stopped reporting a command hook as cancelled when the turn was interrupted after the hook's process had already exited; its output and exit status are used.
- 🔴 Raised the number of read files Claude Code keeps track of (for the read-before-edit and file-changed checks) from 100 to 5,000, still within 25 MB of content, including in `claude mcp serve`.
- 🔴 Extended the cleanup of old data under `cleanupPeriodDays` to agent team inbox files, saved remote-agent transcripts in session folders, and a project's `bagel` folder once everything in it is older than the cutoff.
- 🔴 Made sessions with Remote Control active, or running as a bridge environment (`CLAUDE_CODE_ENVIRONMENT_KIND=bridge`), compact at the usual threshold instead of waiting for the context to overflow, as cloud sessions already did.
- 🔴 Turned on by default the glyph reset for VS Code and other xterm.js terminals: Claude Code resets one terminal palette color when the terminal regains focus and after about 2,000 distinct styled characters, which clears corrupted glyphs (remote switch, now on by default).
- 🔴 Changed how a reply is cleaned up before it's sent back: a whitespace-only text block between two thinking blocks is now kept, and a duplicate tool call or an unmatched server/MCP tool call removed from between two thinking blocks is replaced by a "[Tool use removed]" text block, so the thinking blocks stay apart.
- 🔴 Fixed an error during a turn adding a second, error result to tool calls that had already finished, and removed the tool results of an abandoned attempt from the conversation on a streaming fallback or retry.
- 🔴 Gave resumed fork subagents the periodic progress summaries that newly started forks get.
- 🔴 Limited the models that a Cloud gateway's `/v1/models` list adds to `/model` to Claude-looking model IDs, dropping other vendors' models such as GPT, Gemini, Llama or Qwen.
- 🔴 Opened the feature-of-the-week campaign beyond Pro and Max: on Team plans, admins, owners and billing members can claim its usage credit while other members see it without the credit offer, and a campaign that carries no credit is shown that way to every claude.ai subscriber, Enterprise included, in the startup notice and a tip. The campaign comes from Anthropic's servers.
- 🔴 Stopped background sessions from redeeming feature-of-the-week credits, and made other interactive sessions attempt a claim only with an unexpired eligibility reply confirming the credit is available to them and giving its amount and currency. Running the featured command before that reply arrives no longer attempts a claim.
- 🔴 Reworded the notice shown when a safety-filter refusal switches models, from "Switched to X for this session." to "Switched to X." with a note that the first model sometimes flags safe, normal chats on sensitive topics (the switch sits behind a remote switch, off by default).
- 🔴 Colored the `/effort` slider's accented section on both sides of the marker, and the marker itself when it's inside that section.
- 🔴 Added skills served by MCP servers: a server with resources can list up to 100 `SKILL.md` files and 100 URL templates in `skill://index.json`, which appear as `/server:skill` commands (templates take arguments or a full URI) and to the Skill tool, without hooks or `allowed-tools` (remote switch, off by default).
- 🔴 Added an alternative opening for the shorter system prompt, telling Claude it works alongside the user and owns the outcome, with a shorter rule on confirming risky actions, behind `CLAUDE_CODE_OWNERSHIP_FRAME` or a remote switch, off by default. The existing model/rollout choice or `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=1` must select the shorter prompt.
- 🔴 Added a reworked footer behind a remote switch, off by default: a clickable "↳ N background" pill, the pull request status moved into the row with the IDE and Remote Control indicators, and "jobs" in place of "tasks" for MCP tasks.
- 🔴 Made the design-system project tool list all of a project's files, paging through up to 50 pages, instead of only the first page (`/design-sync`, which needs organization policy and a remote switch, off by default).
- 🔴 Changed the REPL tool's script sandbox to convert values with the sandbox's own `String` and `JSON.stringify`, to copy out objects that define their own `toJSON`, `toString`, `valueOf` or `Symbol.toPrimitive` as plain objects, and to ignore timer delays and ids that aren't numbers (the REPL tool needs `CLAUDE_CODE_REPL` or a remote switch, off by default).
- 🟡 (2.1.121) Removed `prompt=consent` from MCP OAuth sign-ins through Microsoft Entra ID (login.microsoftonline.com and its US government and China clouds, `*.b2clogin.com` and `*.ciamlogin.com`), keeping any other `prompt` value.
- 🟡 (2.1.128) Stopped showing the "/remote-control is active · Continue here, on your phone, or at …" line once Remote Control has disconnected or runs outbound-only, and stopped `--resume` and `--continue` from bringing back such lines from the earlier run.
- 🟡 (2.1.162) Shortened several startup notices to single dim lines: debug mode ("Debug mode enabled · logging to …"), the tmux session ("… · detach with …"), the model source ("Using … · /model") and the channels warning ("Channels (experimental) messages from … inject directly in this session · restart without … to stop"), which is now shown as information.
- 🟡 (2.1.280) Made Bash write, redirect and `cd` permission checks follow symlinks in the nearest existing part of a target path, up to the part before a wildcard. Creating a file through a symlink named with wildcard characters can now need approval when it points outside the working folders.
- 🟢 Added the entries of `OTEL_RESOURCE_ATTRIBUTES` to Claude Code's OpenTelemetry metric and event attributes; `OTEL_METRICS_INCLUDE_RESOURCE_ATTRIBUTES=false` leaves them out. Entries without one `=` are skipped; invalid key/value characters, excessive lengths or invalid percent escapes discard the list, and `user.*` and `identity.*` keys are skipped when a gateway login supplies identity attributes.
- 🟢 Fixed OpenTelemetry events logged before telemetry had finished starting being dropped with a warning; up to 100 are now held and sent once it's ready.
- 🟢 Added fanned-out work to `claude agents`: a session's row shows how many of its subagents, workflow agents, shells, monitors, MCP tasks and to-dos are done (`done/total ·`) once there are two or more, and its peek shows the longest-running item with its elapsed time, "and N more" and any token budget.
- 🟢 Folded claude.ai connectors that need sign-in or failed and have never connected behind a "Show unused connectors (N)" row in `/mcp`, and listed them as "unused claude.ai connectors" next to disabled items in the plugin manager instead of as failures.
- 🟢 Stopped a failing Bash or PowerShell command from cancelling the other tool calls in the same parallel batch ("Cancelled: parallel tool call … errored"); each call now returns its own result.
- 🟢 Changed copying on Linux to use `wl-copy` (with `WAYLAND_DISPLAY`) or `xclip` or `xsel` (with `DISPLAY`), to copy to the PRIMARY selection too for middle-click paste, and to report "copied N chars to clipboard". The OSC 52 copy message and the `/tui fullscreen` notes now say which key to hold for the terminal's own selection (Shift, Option or Fn, depending on the terminal).
- 🟢 Made more animations follow the reduce-motion setting: the `/effort` dialog's ultracode animation, animated progress-bar segments, the prompt keyword shimmer, color-cycling text and the rainbow border flash.
- 🟢 Stopped `forceLoginOrgUUID` and `forceLoginMethod` managed settings from refusing sessions on Bedrock, Vertex, Foundry, Mantle and other third-party providers that carry no Anthropic credential; the refusal now names an Anthropic API key, auth token or `apiKeyHelper` as the cause.
- 🟢 Fixed background subagents' progress events being printed into `claude -p` output in the text and JSON formats; they're now sent only with `--output-format stream-json` or an SDK connection.
- 🟢 Changed `/usage-credits`, and the usage-credits option of the rate-limit menu, for Team and Enterprise accounts to open or name the organization's usage page instead of starting a new login.
- 🟢 Fixed `/autofix-pr` checking the wrong folder's branch when the session is working in a git worktree or another repository; the "cannot run on the default branch" message now names the folder it checked.
- 🟢 Fixed the `--resume` session picker leaving out the current folder's sessions when that folder isn't one of the repository's git worktrees, such as a Jujutsu workspace.
- 🟢 Stopped `claude mcp list` and `get` from expanding `${VAR}` references when displaying server settings, so values supplied through environment variables aren't printed. `claude mcp add` now prints URLs without user info, query string or fragment and replaces secret-looking header values with `[REDACTED]`; literal values written in config can still appear in list/get output.
- 🟢 Fixed dynamic-workflow agents that run in their own git worktree being refused edits inside it: the worktree now counts as one of the agent's working folders.
- 🟢 Fixed background sessions started from `claude agents` picking up `ANTHROPIC_MODEL` from the background service's environment; they now get the value of the shell that started them, if it had one, and otherwise the model from settings applies.
- 🟢 Fixed a possible crash when showing a Write tool result after resuming a session in which the saved content isn't text.
- 🟢 Fixed a background subagent staying shown as running, with no completion notice, when an error hit after its result was final (during the handoff safety review or worktree cleanup); it now reports completed, killed or failed.
- 🟢 Fixed tools that create Unix sockets in `$TMPDIR` failing when `CLAUDE_CODE_TMPDIR` names a deep folder: when Claude Code's per-user temp path inside it is longer than 44 bytes, commands get `<system temp>/claude-<uid>` as `TMPDIR`, with a one-time warning in the debug log. `CLAUDE_CODE_TMPDIR` in their environment still names the original per-user folder inside the configured one, and the sandbox allows writes to both.
- 🟢 Sped up terminal rendering by restructuring the layout engine (cached layout values in typed arrays, shared preallocated buffers and index loops in place of per-node fields and fresh arrays); layouts are computed the same way.
- 🟢 Sped up showing large file writes: the Write tool's preview stops counting lines once a new file passes its ten-line limit, and a ten-line file ending in a newline is no longer marked as cut off.
- 🟢 Added a tip, shown at most five times in VS Code and other xterm.js terminals, suggesting turning off the terminal's GPU acceleration or running `/terminal-setup` when glyphs look corrupted.
