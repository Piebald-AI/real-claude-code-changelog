# 2.1.120 ◆◆◆◆

[Back to the changelog](../README.md#changelog)

- 🔴 Showed the end-of-turn duration line ("✻ Worked for 4s") after every response that called the model, not only after turns longer than 30 seconds; in focus view the line also says how many messages it hid ("3 messages hidden (/focus to show)").
- 🔴 Added `CLAUDE_CODE_LEAN_PROMPT` (or remote switches, off by default): with Claude Opus 4.7 it swaps most of the system prompt for a short "# Harness" section and sends much shorter descriptions of Bash, Read, Write, Edit, Grep, Glob, WebFetch, WebSearch, TodoWrite and Agent; with any model it trims the memory instructions to a short list of memory types and moves the full guide into a `memory-types` skill Claude loads before saving a memory.
- 🔴 Added a Keep/Undo check-in for memory files the main agent writes or edits directly inside its auto-memory folder, excluding `MEMORY.md` (remote switch, off by default; requires auto memory, telemetry and `allow_product_feedback`). By default, the panel hides after 8 seconds, leaves 30 seconds between panels and asks for a one-sentence summary above 5 lines; Undo restores an edit or deletes a new file and its index line unless the file changed meanwhile.
- 🔴 Told auto mode's classifier about your permission deny rules (all but `prompt:` rules) and asked it to block actions that get the same effect through another tool, such as editing a denied file with `sed -i` or a heredoc in Bash.
- 🔴 Made `claude remote-control` run as a server for several sessions for everyone, where a remote switch used to decide: it pre-creates a session in the current folder, starts in same-folder mode instead of single-session mode, accepts `--spawn same-dir|worktree|session`, `--capacity` and `--[no-]create-session-in-dir`, and `w` switches between same-folder and worktree mode.
- 🔴 Made Remote Control send presence updates for the session without a remote switch, and skip them while the terminal window isn't focused.
- 🔴 Made interactive sessions register the `claude-cli://` link handler by themselves, which a remote switch used to gate; `disableDeepLinkRegistration: "disable"` still stops it.
- 🔴 Changed Claude in Chrome's tools: added `browser_batch` (several browser actions in one call, stopping at the first error), `tabs_close_mcp` and `file_upload` (sends local files to a page's file input), removed `update_plan`, and capped the `computer` tool's `wait` at 10 seconds instead of 30.
- 🔴 Changed Claude in Chrome's bridge connection to use a 60-second response timer for tool calls (120 before, 2 for listing tabs), paused during permission prompts, and fail calls at once when the extension disconnects or the connection drops. Disconnect errors ask Claude to retry in a few seconds; timeouts suggest a lighter operation, pings run every 30 seconds with a 90-second silence limit, a connect stuck for 30 seconds starts over, sign-in failures retry, and tab lists from several extensions are no longer merged over the bridge.
- 🔴 Rewrote the Explore subagent's description so Claude uses it to find files and symbols, not for code review, design-doc audits or open-ended analysis, because it reads excerpts rather than whole files.
- 🔴 Added tips to the weekly-limit warning for Pro subscribers, which a remote switch used to gate: "try /model sonnet · ~2× runway" on Opus, or "try /effort medium" at high, xhigh or max effort.
- 🔴 Stopped automatic Git-worktree cleanup (Agent tool worktrees, stale agent worktrees, Remote Control and background-job worktrees) from deleting a worktree with uncommitted changes; removal requested through ExitWorktree or the exit dialog still goes ahead. The shared cleanup helper leaves hook-created worktrees to `WorktreeRemove`, but background-job deletion checks those worktrees for uncommitted Git changes first too.
- 🔴 Fixed every sandboxed Bash command leaving a file handle to Claude Code's own executable open.
- 🔴 Changed which branch a resumed session continues from when its transcript holds more than one: the transcript now records the latest message with the session's last prompt, `/update` records it explicitly before restarting, and resume continues from that message instead of whichever one was written last.
- 🔴 Made transcript loading also restore saved system and attachment entries chained below the selected message, including entries more than one child deep.
- 🔴 Queued the message an async hook sends when it wakes Claude (`asyncRewake` with exit code 2) at `next` priority instead of the default one.
- 🔴 Let you answer a multiple-choice question that has previews with only a note: Claude gets `(no option selected)` with the note, answers now come back in question order, and notes typed on such questions are passed on when you ask to clarify or to finish the plan interview.
- 🔴 Changed the ExitWorktree tool's activity text to "Cleaning up worktree" when it removes the worktree, and stopped printing the action word next to the call.
- 🔴 Renamed the prompt's "! for bash mode" hint to "! for shell mode".
- 🔴 Added PowerShell to simple mode (`CLAUDE_CODE_SIMPLE` or `--bare`) outside REPL mode when `CLAUDE_CODE_USE_POWERSHELL_TOOL` is enabled, alongside Bash, Read and Edit.
- 🔴 Added `statusLine.hideVimModeIndicator`, which hides the `-- INSERT --` and `-- VISUAL --` line below the prompt when a status line is configured, for scripts that show `vim.mode` themselves. The option is ignored in fullscreen windows shorter than 15 rows.
- 🔴 Moved clipboard images, `/copy`'s `response.md`, screenshots, exported transcripts, Remote Control debug logs and the PowerShell tool's working-directory file into `claude-<uid>` inside the temporary folder; the writers request owner-only directory access except the debug logger, whose directory permissions depend on the process's umask. Clipboard commands also quote the path for the shell.
- 🔴 Made plugin themes load in the background.
- 🔴 Stopped Shift+↑/↓ from switching between running agents or opening the background tasks panel when `CLAUDE_CODE_FORK_SUBAGENT` is set.
- 🔴 Made the fast mode shortcut in a remote session viewer say "Fast mode switching in remote sessions is coming soon — set at session creation for now" instead of toggling fast mode.
- 🔴 Stopped showing empty parentheses after a tool's name in its permission prompt when there are no arguments to show.
- 🔴 Restyled the "Waiting for team lead approval" heading of agent teams' permission prompts (bold, in the warning colour).
- 🔴 Reworked how a text selection follows scrolling in fullscreen mode, so it keeps its start and end columns while scrolled out of view and comes back intact.
- 🔴 Made Claude Code also reset the terminal's scroll region and clear the tab's progress indicator when it exits or hands over the terminal.
- 🔴 Changed `/update` to reset the terminal and finish its cleanup before starting the new version, then wait for that process and exit with its status (or the signal that ended it).
- 🔴 Changed the Claude Opus 4.7 auto-compaction notice to appear when compaction starts ("compacting at the auto … window · configure with /autocompact") instead of afterwards, and to stay for 12 seconds (remote switch, off by default).
- 🔴 Updated the saved account details (email, organization name and type, rate-limit tiers, seat tier) from the account data Claude Code fetches at startup when they differ.
- 🔴 Opened the `claude daemon` subcommands to accounts with the agents view switched on, where 2.1.119 refused all but `run`, and turned the agents view and `--bg` off for Bedrock, Vertex, Foundry, Claude Platform on AWS and Mantle and under `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` (remote switch, off by default).
- 🔴 Made the background daemon run on demand: `claude daemon install` needs a second remote switch and refuses to install when `CLAUDE_CONFIG_DIR` is nonempty, while `start` and `restart` are disabled; `stop --any` stops an on-demand daemon, `logs` works like `log`, `hub` works like `status`, and `list`, `scheduled`, `assistant` and `remote-control` are refused. Only heartbeat workers from `daemon.json` start, a daemon installed as a service no longer exits when no client is connected, and startup removes older service installations when using the default configuration on a supported system (remote switch, off by default).
- 🔴 Fixed background sessions refusing to start when a daemon with a missing control socket exited during restart; startup now continues after a failed stop unless the operating system reports a permission error (remote switch, off by default).
- 🔴 Made `claude daemon` report unknown subcommands instead of treating a bare word as a configuration file; use `run <file>` for a filename without `.`, `/`, `\` or `~` (requires the agents-view remote switch, off by default).
- 🔴 Added a question when a background session needs the daemon and none is running ("Install as a service now? [Y/n/never, or 'once' for this login session]"), set by `daemonColdStart` (`transient` or `ask`) or `CLAUDE_CODE_DAEMON_COLD_START`; it's asked only where service install is allowed, and `never` is remembered (remote switches, off by default).
- 🔴 Changed the agents view (`claude agents`): after an update it relaunches itself on the newest build once you've left it alone for an hour (at most once every 6 hours), its search box handles several lines (↑/↓ move between lines, Home/End go to the ends of a line, the cursor shows at the end of a line), and Ctrl+B on an empty prompt no longer acts like ←. Waiting and blocked jobs show in the warning colour instead of red and failed ones in red instead of grey; grouped by state (Ctrl+S), failed and waiting jobs go under Blocked and stopped ones under Done even with an open pull request, and an approved pull request that's only waiting on checks or a mergeability result no longer puts its job under "Ready for review"; failed checks, merge conflicts and a branch that's behind still do (remote switches, off by default).
- 🔴 Added folders from existing sessions to the agents view's `@folder` shortcuts and suggestions, including folders outside its starting directory; folder names with whitespace are skipped, and existing shortcuts win when names clash (remote switch, off by default).
- 🔴 Kept the agents view open while checking or restarting the selected session, showing an opening failure in the list instead of leaving the list first (remote switch, off by default).
- 🔴 Stopped agents-view refreshes from replacing a job's pending stop or reply state before that action finishes (remote switch, off by default).
- 🔴 Changed background sessions: outside a worktree, a second Ctrl+C says "detach (session keeps running)" when tasks are still running, or "stop session" otherwise; the footer shows the session's pull request, detaching restores its mouse and paste modes, and deleting a job keeps a worktree with uncommitted changes. Unattached finished sessions can shut down after 10 idle minutes when they have no tasks, queued work, session timers or routine, restart when attached, and no longer inherit the daemon's terminal variables unless the launching terminal supplied them (remote switch, off by default).
- 🔴 Fixed background jobs' status after interruptions: pressing Esc or a hook stopping a turn now marks the job idle instead of leaving it marked as working until a later turn finishes. A job waiting for your answer stays waiting after a successful process exit or while a crashed worker is restarting; a final crash can still mark it failed (remote switch, off by default).
- 🔴 Made the startup cleanup also delete `.json` files older than `cleanupPeriodDays` (30 days by default) from `~/.claude/jobs/settled` and `~/.claude/daemon/dispatch/rejected`, the folders holding records of finished background jobs and refused background dispatch requests, which nothing cleaned up before.
- 🔴 Updated the Bun runtime from `1.3.13+0aa3dbc9a` to `1.3.14+0a466a11e`: about 29 KB less native code, the same sections, command-line options and `BUN_` variables, and Bun's built-in JavaScript changed in streams, SQL queries, test `expect` messages and `bun build` output errors.
- 🟡 (2.1.121) Broke opening saved conversations and rewinding in interactive mode: both paths call a session-restoration callback that this build's hook doesn't provide.
- 🟡 (2.1.200) Stopped a newer `claude daemon` process that reuses a dead daemon's process ID from passing for the running background daemon: the daemon's lock file now records when its process started, and a starting daemon or a background session looking for one compares it (background sessions sit behind a remote switch, off by default).
- 🟡 (2.1.211) Added `save_to_disk` to Claude in Chrome's screenshot and zoom tool options, letting Claude request an image file and its path for attaching to a reply.
- 🟡 (2.1.218) Allowed `CLAUDE_CODE_USE_POWERSHELL_TOOL` from project settings during early startup, and stopped treating changes to that setting alone as a reason for the managed-settings execution-risk approval dialog.
- 🟡 (2.1.92) Showed the "~Nk uncached · /clear to start fresh" footer hint (a conversation of at least 50,000 tokens whose last reply is over an hour old) to every Pro subscriber, not only when a remote switch was on.
- 🟡 (2.1.222) Made errors from the theme, settings, skills, FileChanged and background-job watchers log a warning instead of going unhandled.
- 🟢 Set `AI_AGENT` for child processes so tools such as `gh` can tell traffic comes from Claude Code: `claude-code/<version>/harness` for hooks, MCP servers and other children, preserving an existing value unless it starts with `claude-code/`, and `claude-code/<version>/agent` for commands run through the shell executor, including Bash, PowerShell and Monitor.
- 🟢 Added `claude ultrareview [target]` to run a cloud review of the current branch, a PR number or a base branch from a script: it prints progress to stderr and the findings to stdout (`--json` for the raw payload), waits up to `--timeout` minutes (30 by default), exits 1 when the review fails, and respects the `allow_remote_sessions` policy. Requires the ultrareview remote configuration to be enabled; it's off by default.
- 🟢 Added `${CLAUDE_EFFORT}` to skill and custom command content, replaced with the current effort level.
- 🟢 Hid the spinner tips about creating skills or using `/agents` once you have your own, showed the `--agent` tip only when you do, and under WSL hid the desktop app tip once the app is installed.
- 🟢 Added a hint when the scroll wheel arrives as arrow keys (eight ↑ or ↓ presses within a tenth of a second): "Scroll wheel is sending arrow keys · use PgUp/PgDn to scroll", replacing the advice to run `/terminal-setup`.
- 🟢 Made sessions with many unauthorized claude.ai connectors start faster: a connector that needs sign-in is skipped for 4 hours instead of 15 minutes, that list is cleared only when you sign in again rather than on every refresh, and a server leaves it once it connects.
- 🟢 Linked the auto mode denial message to the documentation ("see https://code.claude.com/docs/s/claude-code-auto-mode") in place of "/feedback if incorrect".
- 🟢 Made `claude plugin validate` accept `$schema`, `version` and `description` at the top of `marketplace.json` (a top-level `description` also clears the missing-description warning) and `$schema` in `plugin.json`.
- 🟢 Fixed a marketplace failing to load when one plugin entry uses a source format this version doesn't know: that entry is kept and installing it says "This plugin uses a source type your Claude Code version does not support. Update Claude Code and try again."; an entry that can't be read at all is dropped with a warning.
- 🟢 Showed the auto-compact window as `auto` in `/autocompact` and the context summary, instead of a token count, when neither `CLAUDE_CODE_AUTO_COMPACT_WINDOW` nor settings set it.
- 🟢 Fixed an error on a stdio MCP server's connection, such as pressing Esc during one of its tool calls, closing the whole connection.
- 🟢 Fixed `/rewind` and other overlays ignoring keys after `claude --resume`: an overlay no longer sets up a second keybinding layer inside the existing one, and the chord handler takes focus back from a parent element.
- 🟢 Fixed scrollback filling with copies of the screen outside fullscreen mode: a full redraw now erases the visible rows in place instead of clearing the screen with `ESC[2J`, which many terminals push into scrollback.
- 🟢 Fixed usage metrics still being sent with `DISABLE_TELEMETRY` or `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` set.
- 🟢 Fixed multi-line Bash commands with a pipe and a redirect drawing false "Dangerous rm operation" prompts in auto mode: the command text checked without its output redirections keeps its line breaks instead of joining lines with spaces.
- 🟢 Fixed long selection menus running off the bottom of the terminal: their requested option count is capped at what fits (terminal rows minus 8, divided by the lines each option takes, rounded down with a minimum of one), and the focused option stays in view.
- 🟢 Fixed the Write tool's output collapsing instead of expanding when you click "+N lines" in fullscreen: a box whose maximum width or height is cleared now grows instead of shrinking to nothing.
- 🟢 Fixed the slash command picker jumping while you type, limited description highlights to continuous matches, and removed bold from matching text.
- 🟢 Fixed `find` in the Bash tool running out of file handles on large directory trees by making the built-in `bfs` search depth-first, and told Claude to search from `.` or a specific folder rather than `/`.
